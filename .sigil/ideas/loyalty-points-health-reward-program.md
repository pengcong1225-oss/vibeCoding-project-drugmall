# Loyalty Points & Health Reward Program

## Description

Patients earn loyalty points for platform actions: purchasing drugs, completing medication adherence streaks, submitting verified reviews, completing health metric logs, and referring new users. Points can be redeemed for: discounts on future purchases, free delivery, or small health-related items (vitamin samples, masks). A points dashboard shows balance, earning history, and available rewards. Points expire after 12 months of inactivity. The admin can configure earning rates and redemption thresholds per action type. Bonus point campaigns can be created for seasonal health events (flu shot season, allergy season).

## Rationale

DrugMall competes with other online pharmacies. A loyalty program increases retention, encourages health-positive behaviors (logging metrics, adherence), and creates a moat. The existing order and user infrastructure supports this with minimal new data modeling.
