# DrugMall V1.0 功能开发规约（完整版 - 三端覆盖）

## 1. 概述

### 1.1 目标
根据PRD和设计规范，完成DrugMall 1.0版本的**患者端、管理后台、医生端**三端核心功能开发。

**业务闭环说明**：
- **患者端**（C端）：用户购药、问诊的入口
- **管理后台**：平台运营人员管理药品、订单、用户、财务的中枢
- **医生端**：医生提供在线问诊、开具处方、管理患者的工具

**三者关系**：
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   患者端     │────▶│   医生端     │────▶│  管理后台    │
│  （购药/问诊）│◀────│ （问诊/处方） │◀────│ （运营管理） │
└─────────────┘     └─────────────┘     └─────────────┘
       │                   │                   │
       └───────────────────┴───────────────────┘
                          │
                    ┌─────▼─────┐
                    │  核心业务  │
                    │ 选药→问诊→开方→购药→配送
                    └───────────┘
```

### 1.2 范围
本规约覆盖以下三端核心功能模块：

**患者端**：
- 首页模块、分类模块、购物车模块、个人中心模块
- 搜索模块、药品详情模块、订单模块、用户认证模块

**管理后台**：
- 仪表盘、药品管理、订单管理、用户管理、财务管理
- 内容管理、系统设置、数据统计

**医生端**：
- 医生工作台首页、问诊管理、处方管理、患者管理
- 收入管理、个人中心

### 1.3 技术栈
- **前端**：Vue 3 + TypeScript + Vite
- **UI框架**：Element Plus（管理后台）+ 自定义组件（患者端/医生端）
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **样式**：SCSS
- **构建**：Vite
- **可视化**：ECharts（管理后台图表）

**功能需求：**

### 5.2 命名规范

**文件命名**
- 组件：PascalCase（如 DrugCard.vue）
- 工具/配置：camelCase（如 request.ts）
- 样式：kebab-case（如 variables.scss）

**变量命名**
- 常量：UPPER_SNAKE_CASE
- 变量/函数：camelCase
- 类/接口：PascalCase

### 5.3 代码规范

**Vue组件规范**
```vue
<script setup lang="ts">
// 1. 导入
import { ref, computed } from 'vue'
import type { Drug } from '@/types/drug'

// 2. Props/Emits
const props = defineProps<{
  drug: Drug
}>()

const emit = defineEmits<{
  click: [id: string]
  addCart: [drug: Drug]
}>()

// 3. 响应式数据
const loading = ref(false)
const count = ref(1)

// 4. 计算属性
const totalPrice = computed(() => {
  return count.value * props.drug.price
})

// 5. 方法
const handleClick = () => {
  emit('click', props.drug.id)
}

const handleAddCart = () => {
  emit('addCart', props.drug)
}
</script>
```
