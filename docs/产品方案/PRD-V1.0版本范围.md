## 二、版本概述

### 2.1 版本目标

DrugMall V1.0版本为产品首个上线版本，目标是实现用户在线购药和问诊的核心闭环，同时满足医药电商合规要求。

---

### 2.2 核心价值

- **核心价值验证**：验证"在线购药 + 问诊"模式可行性
- **业务闭环验证**：实现选药 → 问诊 → 开方 → 购药 → 配送完整流程
- **合规基础搭建**：搭建满足医药电商合规基础规范
- **数据积累**：积累用户行为数据，优化产品
