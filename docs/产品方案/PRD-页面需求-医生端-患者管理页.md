## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 患者管理 |
| 页面路径 | /doctor/patients |
| 页面类型 | 列表+详情管理页 |
| 访问权限 | 需登录，仅认证医生可访问 |
| 设计目标 | 为医生提供便捷的患者档案管理工具，支持查看患者历史病历、处方记录，支持随访管理和快速复诊 |

### 1.2 页面定位

患者管理页是DrugMall平台医生的核心患者管理工具，承担以下核心职责：
1. **患者档案管理中心**：集中管理所有接诊过的患者基本信息和健康档案
2. **历史病历查询**：快速查看患者的问诊记录、诊断结果和病历详情
3. **处方记录管理**：查看为患者开具的所有处方及其状态
4. **随访计划管理**：创建和管理患者随访计划，设置随访提醒
5. **患者分组管理**：通过标签和分组对患者进行分类管理
6. **快速复诊入口**：一键为患者发起复诊问诊或开具处方

## 4. 交互说明

### 4.1 页面加载

| 场景 | 交互说明 |
|------|----------|
| 首次加载 | 显示骨架屏，患者列表渐显，数据概览卡片动画入场 |
| 下拉刷新 | 下拉距离>60px触发刷新，显示刷新动画，刷新完成后回弹 |
| 上拉加载 | 列表滑动到底部触发加载更多，显示加载动画 |
| 筛选切换 | 筛选条件变化时列表重新加载，显示加载状态 |

### 4.2 搜索交互

| 操作 | 交互说明 |
|------|----------|
| 聚焦搜索框 | 搜索框获得焦点，展开为全屏搜索页面 |
| 输入关键词 | 实时搜索，显示匹配结果列表，延迟300ms防抖 |

## 8. 性能要求

### 8.1 加载性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首屏加载时间 | ≤1.5秒 | 患者列表和数据概览完全渲染 |
| 可交互时间 | ≤2秒 | 用户可以开始交互 |
| 完全加载时间 | ≤3秒 | 所有资源加载完成 |
| 筛选响应时间 | ≤500ms | 筛选条件切换后列表更新 |
| 搜索响应时间 | ≤300ms | 搜索关键词输入后结果返回 |

### 8.2 渲染性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 滚动帧率 | ≥60fps | 患者列表流畅滚动 |
| 动画帧率 | ≥60fps | 卡片展开/收起动画流畅 |
| 内存占用 | ≤100MB | 避免OOM |
| 列表优化 | 虚拟滚动 | 患者数量超过50时使用虚拟滚动 |

### 8.3 网络优化

| 优化项 | 说明 |
|--------|------|
| 数据缓存 | API响应缓存，减少重复请求 |
| 增量更新 | 只请求变化的数据（如新患者） |
| 图片懒加载 | 患者头像进入视口前不加载 |
| 数据预加载 | 预测用户行为，提前加载可能查看的档案 |
| 断线重连 | 网络断开后自动重连，恢复未完成操作 |
