## 1. 页面概述

### 1.1 页面定位

我的收入页是医生端的核心功能页面之一，为注册医生提供完整的收入管理解决方案。该页面帮助医生实时掌握个人问诊收入情况，支持收入明细查询、趋势分析、账单管理和提现操作，是连接医生服务与收益结算的关键枢纽。

### 1.2 目标用户

| 用户角色 | 描述 | 核心诉求 |
|----------|------|----------|
| 注册医生 | 在平台提供在线问诊服务的执业医师 | 清晰了解收入情况、便捷提现、收入趋势分析 |
| 多点执业医生 | 在多个平台执业的医生 | 统一查看本平台收入、快速提现到账 |

### 1.3 页面价值

- **收入透明化**：实时展示收入数据，让医生对劳动成果一目了然
- **操作便捷化**：一键提现、账单导出，简化收入管理流程
- **决策数据化**：趋势图表、收入构成分析，辅助医生优化服务策略

### 2.2 功能模块详细说明

#### 2.2.1 顶部导航栏

| 元素 | 类型 | 说明 |
|------|------|------|
| 返回按钮 | IconButton | 返回上一页 |
| 页面标题 | Text | "我的收入"，居中显示 |
| 帮助入口 | IconButton | 点击显示收入说明和提现规则弹窗 |

**帮助入口弹窗内容：**
- 收入构成说明
- 结算周期说明
- 提现规则
- 税务说明
- 常见问题FAQ

#### 2.2.2 收入总览卡片

**第一行：三大核心指标**

| 指标 | 显示格式 | 说明 |
|------|----------|------|
| 账户余额 | ¥X,XXX.00 大字号 | 可提现金额，当前可用余额 |
| 本月收入 | ¥X,XXX.00 | 本月累计收入，环比上月（上升/下降X%） |
| 累计总收入 | ¥XX,XXX.00 | 历史累计收入总额 |

**交互：**
- 账户余额卡片显示"提现"按钮，点击跳转提现流程
- 本月收入显示环比变化趋势（上升绿色箭头/下降红色箭头）
- 数字金额默认隐藏（显示***），点击眼睛图标可显示/隐藏

**第二行：快捷数据**

| 指标 | 显示格式 | 说明 |
|------|----------|------|
| 今日收入 | ¥XXX.XX | 今日实时收入 |
| 本周收入 | ¥X,XXX.XX | 本周累计收入 |
| 待结算金额 | ¥X,XXX.XX | 平台结算中，暂不可提现 |
| 累计提现金额 | ¥XX,XXX.XX | 历史累计提现总额 |

#### 2.2.3 收入趋势区

**时间筛选：**
- 选项：本周 / 本月 / 本年 / 自定义
- 默认选中：本周
- 自定义：支持选择日期范围（开始日期、结束日期）

**收入趋势图（折线图）：**
- 横轴：日期（日/月）
- 纵轴：收入金额
- 支持维度切换：收入金额 / 问诊量
- 支持对比模式：环比 / 同比
- 数据点悬浮显示具体金额和日期
- 支持手势缩放（移动端）

**收入构成饼图：**
- 图文问诊收入占比
- 复诊开方收入占比
- 其他收入占比
- 悬浮显示具体金额和占比
- 点击图例可隐藏/显示对应分类

#### 2.2.4 收入来源列表

**收入明细列表筛选：**
- 收入类型：全部 / 图文问诊 / 复诊开方 / 其他
- 时间范围：近7天 / 30天 / 90天 / 自定义
- 搜索：患者姓名（支持模糊搜索）

**收入记录卡片：**

| 字段 | 显示说明 |
|------|----------|
| 收入类型图标 | 图文问诊/复诊开方/其他，不同图标区分 |
| 收入金额 | 收入显示绿色+，退款显示红色- |
| 患者姓名 | 隐私脱敏，如"李*" |
| 收入来源 | "图文问诊"/"复诊开方"文字说明 |
| 收入时间 | 格式：MM-DD HH:mm |
| 订单状态 | 待结算/已结算/已提现标签 |
| 查看详情 | 点击进入收入详情弹窗 |

**列表交互：**
- 下拉刷新加载最新数据
- 上拉加载更多（分页加载）
- 空状态显示："暂无收入记录" + 引导问诊图标

**收入详情弹窗：**

| 字段 | 说明 |
|------|------|
| 收入单号 | 唯一标识，如 INC202404070001 |
| 问诊单号 | 关联的问诊订单，可点击进入问诊详情 |
| 患者信息 | 姓名(脱敏)、性别、年龄 |
| 问诊类型 | 图文问诊/复诊开方 |
| 问诊时长 | 如：15分钟 |
| 收入金额（平台分成前） | ¥XX.00 |
| 平台分成比例 | XX% |
| 实际收入（医生分成） | ¥XX.00（加粗高亮） |
| 收入时间 | YYYY-MM-DD HH:mm:ss |
| 结算状态 | 待结算/已结算/已提现 |
| 结算时间 | 已结算时显示 |

#### 2.2.5 账单明细

**账单汇总：**
- 按日/按周/按月账单切换
- 账单月份选择器
- 账单金额汇总（收入合计/平台分成/实际收入）

**账单明细列表：**
- 日期/周期
- 问诊次数
- 收入金额
- 平台分成
- 实际收入
- 结算状态
- 查看明细入口

**导出功能：**
- 导出账单PDF按钮
- 支持选择日期范围
- 生成PDF账单（包含收入明细汇总）

#### 2.2.6 提现功能

**提现入口：**
- 提现申请按钮（余额>0时高亮显示）
- 提现规则说明入口

**提现规则说明：**
- 最低提现金额：¥100
- 提现到账时间：1-3个工作日
- 支持提现方式：银行卡/支付宝
- 每月提现次数限制（如每月最多5次）
- 节假日顺延说明
- 个人所得税代扣代缴说明

**提现申请弹窗：**

| 字段 | 说明 |
|------|------|
| 可提现金额 | 显示当前可提现余额 |
| 提现金额输入框 | 数字输入，带¥符号，支持小数点后2位 |
| 全部提现按钮 | 快捷填入全部可提现金额 |
| 提现方式选择 | 银行卡/支付宝单选 |
| 银行卡选择 | 已绑定的银行卡列表，支持添加新卡 |
| 支付宝账号输入 | 输入支付宝绑定的手机号/邮箱 |
| 提现确认按钮 | 二次确认弹窗后提交 |

**提现申请流程：**
1. 点击提现按钮打开弹窗
2. 输入提现金额（或点击全部提现）
3. 选择提现方式（银行卡/支付宝）
4. 选择/输入收款账户
5. 点击确认提现
6. 二次确认弹窗显示提现金额和到账方式
7. 确认后提交申请，显示"提现申请已提交"提示
8. 更新可提现余额，刷新提现记录列表

**提现记录：**

*Tab切换：* 收入明细 / 提现记录

*提现记录筛选：*
- 全部 / 处理中 / 已到账 / 已拒绝

*提现记录卡片：*

| 字段 | 说明 |
|------|------|
| 提现金额 | ¥X,XXX.XX |
| 提现方式图标 | 银行卡/支付宝图标 |
| 提现状态 | 处理中/已到账/已拒绝标签（不同颜色） |
| 申请时间 | YYYY-MM-DD HH:mm |
| 到账时间 | 已到账时显示 |
| 拒绝原因 | 已拒绝时显示具体原因 |

**提现状态说明：**
- 处理中（蓝色）：已提交申请，正在处理中
- 已到账（绿色）：资金已到账
- 已拒绝（红色）：提现申请被拒绝，显示拒绝原因

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 页面加载时间 | < 2s | 从进入页面到可交互 |
| 收入列表加载 | < 1s | 下拉刷新或上拉加载更多 |
| 图表渲染 | < 1.5s | 趋势图、饼图渲染完成 |
| 提现申请提交 | < 2s | 从点击确认到提交完成 |

### 4.2 兼容性要求

- 支持 iOS 12+ / Android 8+
- 支持微信内置浏览器
- 支持主流移动端浏览器（Safari、Chrome、UC等）
- 响应式布局，适配不同屏幕尺寸

### 4.3 安全要求

- 金额等敏感数据脱敏显示，默认隐藏具体数字
- 提现操作需要二次确认，防止误操作
- 提现申请接口防重复提交
- 敏感接口增加防重放攻击校验

### 4.4 可用性要求

- 页面断网时显示网络异常提示，支持重试
- 接口错误时显示友好的错误提示
- 空状态提供明确的引导（如"暂无收入记录，快去接诊吧"）
- 金额显示统一格式（¥X,XXX.XX）

## 5. 接口需求

### 5.1 收入总览接口

```
GET /api/v1/doctor/income/overview

Response:
{
  "code": 200,
  "data": {
    "balance": 5000.00,              // 账户余额（可提现）
    "monthIncome": 8500.00,          // 本月收入
    "monthIncomeRatio": 15.2,        // 环比上月%
    "totalIncome": 128000.00,        // 累计总收入
```
