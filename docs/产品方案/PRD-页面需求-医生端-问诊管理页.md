## 2. 页面概述

### 2.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 医生端问诊管理页 |
| 页面路径 | /doctor/consultation |
| 页面类型 | 功能管理页 |
| 访问权限 | 需登录，仅认证医生可访问 |
| 设计目标 | 为医生提供完整的问诊管理功能，包括问诊列表、详情查看、聊天沟通、处方开具等 |

### 2.2 页面定位

问诊管理页是DrugMall平台医生的核心业务功能页面，承担以下核心职责：
1. **问诊列表管理**：展示所有问诊请求，支持按状态筛选和快捷操作
2. **问诊详情查看**：展示单个问诊的完整信息和患者资料
3. **在线沟通聊天**：医生与患者进行实时在线沟通
4. **病历管理**：查看患者历史病历和诊疗记录
5. **处方开具**：在线开具电子处方
6. **问诊结束管理**：完成问诊流程并归档

## 4. 功能模块详细说明

### 4.1 问诊列表页

#### 4.1.1 页面概述

问诊列表页是医生端问诊管理的入口页面，展示医生所有的问诊请求，支持按状态筛选和快捷操作。

#### 4.1.2 页面结构

| 模块 | 元素名称 | 类型 | 说明 |
|------|---------|------|------|
| 顶部导航 | 返回按钮 | Button | 返回上级页面 |
| 顶部导航 | 页面标题 | Text | "问诊管理" |
| 顶部导航 | 消息按钮 | Button | 查看系统消息 |
| 顶部导航 | 设置按钮 | Button | 页面设置选项 |
| 状态标签栏 | 待接诊标签 | Tab | 显示待接诊数量（红点提示） |
| 状态标签栏 | 接诊中标签 | Tab | 显示接诊中数量（红点提示） |
| 状态标签栏 | 已完成标签 | Tab | 已完成问诊列表 |
| 状态标签栏 | 已结束标签 | Tab | 已结束问诊列表 |
| 搜索筛选区 | 搜索框 | Input | 搜索患者姓名、手机号、病情 |
| 搜索筛选区 | 筛选按钮 | Button | 打开筛选面板 |
| 搜索筛选区 | 时间筛选 | Dropdown | 选择时间范围 |
| 搜索筛选区 | 类型筛选 | Dropdown | 选择问诊类型 |
| 问诊列表区 | 问诊卡片列表 | List | 展示问诊卡片 |
| 问诊卡片 | 患者头像 | Image | 患者头像 |
| 问诊卡片 | 患者姓名 | Text | 脱敏处理的患者姓名 |
| 问诊卡片 | 患者性别 | Tag | 男/女 |
| 问诊卡片 | 患者年龄 | Text | 患者年龄 |
| 问诊卡片 | 问诊类型 | Tag | 图文/视频/复诊 |
| 问诊卡片 | 状态标识 | Tag | 加急、复诊、首诊等 |
| 问诊卡片 | 等待时间 | Text | 显示等待时长 |
| 问诊卡片 | 病情摘要 | Text | 病情描述摘要 |
| 问诊卡片 | 剩余时间 | Text | 剩余接诊时间倒计时 |
| 问诊卡片 | 操作按钮组 | ButtonGroup | 接诊/回复/查看等操作 |
| 加载更多 | 加载更多按钮 | Button | 加载更多问诊卡片 |
| 空状态 | 空状态提示 | Empty | 无数据时显示 |

#### 4.1.3 问诊卡片状态样式

| 状态 | 视觉表现 | 操作按钮 |
|------|---------|---------|
| 待接诊-加急 | 红色边框、闪烁红点 | 立即接诊、查看详情 |
| 待接诊-普通 | 正常样式 | 接诊、查看详情 |
| 待接诊-即将超时 | 橙色边框 | 立即接诊、查看详情 |
| 接诊中 | 蓝色边框、呼吸灯效果 | 进入会话、查看详情 |
| 已完成 | 灰色边框 | 查看详情、评价患者 |
| 已结束 | 灰色边框、透明度降低 | 查看详情 |

#### 4.1.4 交互说明

| 交互 | 触发方式 | 响应效果 | 备注 |
|------|---------|---------|------|
| 切换状态标签 | 点击标签 | 切换列表内容，标签下划线动画 | 切换时显示加载状态 |
| 点击问诊卡片 | 点击卡片主体 | 进入问诊详情页 | - |
| 点击操作按钮 | 点击按钮 | 执行对应操作 | 按钮有防重触发处理 |
| 下拉刷新 | 下拉列表 | 刷新问诊列表 | 显示刷新动画 |
| 上拉加载更多 | 上拉列表底部 | 加载更多数据 | 显示加载动画 |
| 搜索输入 | 输入关键词 | 实时搜索并展示结果 | 500ms防抖 |
| 打开筛选面板 | 点击筛选按钮 | 从右侧滑出筛选面板 | 支持手势关闭 |

### 4.6 结束问诊

#### 4.6.1 功能概述

结束问诊功能允许医生在完成问诊流程后，正式结束当前问诊会话，生成问诊记录并归档。

#### 4.6.2 结束问诊流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 点击结束按钮 | 在聊天室或详情页点击结束问诊按钮 |
| 2 | 填写结束原因 | 选择结束原因类型 |
| 3 | 填写诊断结果 | 输入本次问诊的初步诊断 |
| 4 | 确认处方状态 | 确认是否已开具处方 |
| 5 | 邀请评价 | 选择是否邀请患者评价 |
| 6 | 提交结束 | 确认并提交结束问诊 |
| 7 | 系统处理 | 系统生成问诊记录并归档 |

#### 4.6.3 结束原因类型

| 原因类型 | 说明 | 适用场景 |
|---------|------|---------|
| 已解决 | 患者问题已得到解决 | 患者病情已明确，已给出诊断和建议 |
| 已开处方 | 已开具处方，患者可购药 | 需要用药治疗的情况 |
| 建议就医 | 建议患者到线下医院就诊 | 病情需要面诊或检查 |
| 已转诊 | 已为患者安排转诊 | 需要转诊到其他科室或医院 |
| 其他 | 其他原因 | 不属于以上类别的情况 |

| 数据加密 | 传输层TLS 1.3加密，存储层AES-256加密 |
| 身份认证 | 多因子认证，支持短信/邮箱/APP验证 |
| 权限控制 | RBAC权限模型，最小权限原则 |
| 会话管理 | Token有效期控制，异常登录检测 |
| 数据脱敏 | 敏感信息脱敏展示，日志脱敏存储 |
| 审计日志 | 完整操作审计，支持追溯和报表 |
| 漏洞防护 | 防SQL注入、XSS、CSRF等攻击 |
| 合规要求 | 符合《个人信息保护法》《数据安全法》等法规 |
