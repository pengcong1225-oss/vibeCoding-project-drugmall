## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 医生工作台-首页 |
| 页面路径 | /doctor/home 或 /doctor/workbench |
| 页面类型 | 工作台仪表盘（Dashboard） |
| 访问权限 | 需登录，仅认证医生可访问 |
| 设计目标 | 为医生提供一站式工作入口，快速查看待办事项、接诊患者、管理收入 |

### 1.2 页面定位

医生端首页是DrugMall平台医生的核心工作入口，承担以下核心职责：
1. **工作概览中心**：展示医生当日工作数据（待接诊、接诊中、已完成）
2. **待办事项提醒**：集中展示待回复咨询、待审核处方等任务
3. **快捷功能入口**：一键进入常用功能（接诊、处方、患者管理）
4. **消息提醒中心**：患者咨询消息实时推送和快速响应
5. **收入数据展示**：收入概览和趋势分析，支持快速提现

## 4. 交互说明

### 4.1 页面加载

| 场景 | 交互说明 |
|------|----------|
| 首次加载 | 显示骨架屏，按区块顺序渐显：导航区→数据概览→快捷功能→待办事项 |
| 下拉刷新 | 下拉距离>60px触发刷新，显示刷新动画，刷新完成后回弹 |
| 数据更新 | 实时推送消息时，对应区块数据自动更新（如待接诊数+1） |
| 错误重试 | 网络错误时显示错误页面，点击重试按钮重新加载 |

### 4.2 滚动行为

| 场景 | 交互说明 |
|------|----------|
| 滚动导航区 | 页面向下滚动>50px，导航区背景变为白色并添加阴影 |
| 快速回顶 | 双击首页Tab回到顶部并刷新 |
| 区块定位 | 长按Tab可唤起快速导航菜单，定位到指定区块 |

## 8. 性能要求

### 8.1 加载性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首屏加载时间 | ≤1.5秒 | 首屏内容完全渲染 |
| 可交互时间 | ≤2秒 | 用户可以开始交互 |
| 完全加载时间 | ≤3秒 | 所有资源加载完成 |
| 数据更新延迟 | ≤300ms | 新消息等实时数据推送延迟 |

### 8.2 渲染性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 滚动帧率 | ≥60fps | 流畅滚动无卡顿 |
| 动画帧率 | ≥60fps | 动画流畅 |
| 内存占用 | ≤100MB | 避免OOM |
| 数据列表 | 虚拟滚动 | 长列表使用虚拟滚动优化 |

### 8.3 网络优化

| 优化项 | 说明 |
|--------|------|
| 数据缓存 | API响应缓存，减少重复请求 |
| 增量更新 | 只请求变化的数据 |
| 图片懒加载 | 头像等图片进入视口前不加载 |
| WebSocket | 消息实时推送，减少轮询 |
| 断线重连 | 网络断开后自动重连 |
