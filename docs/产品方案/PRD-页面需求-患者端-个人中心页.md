## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 个人中心 |
| 页面路径 | /user/profile |
| 页面类型 | 功能聚合、导航页 |
| 访问权限 | 需要登录 |
| 设计目标 | 整合用户资产、订单和服务功能，提供便捷的个人账户管理中心 |

### 1.2 页面定位

个人中心是DrugMall患者端的核心入口页面，承担以下职责：
1. **用户身份展示**：展示用户头像、昵称、会员等级等身份信息
2. **资产信息聚合**：整合账户余额、优惠券、积分、医保余额等资产数据
3. **订单快捷入口**：提供各状态订单的快速跳转入口
4. **服务功能导航**：聚合健康档案、处方管理、问诊记录等医药特色服务
5. **个性化推荐**：基于用户健康数据提供健康周报、用药提醒等个性化功能
6. **家庭健康管理**：支持亲情账号管理，实现家庭成员健康数据共享

## 3. 模块详细说明

### 3.1 用户信息区
#### 3.1.1 功能说明

展示用户基本信息，提供快速编辑入口和个人名片功能。

#### 3.1.2 包含元素

| 元素名称 | 元素类型 | 说明 |
|----------|----------|------|
| 用户头像 | Image | 圆形头像，点击可更换 |
| 用户昵称 | Text | 显示用户昵称，默认显示手机号脱敏后格式 |
| 会员等级 | Tag | 显示会员等级标识，如"普通会员"、"银卡会员"、"金卡会员" |
| 编辑资料 | Button | 跳转到个人资料编辑页 |
| 消息中心 | Button | 跳转到消息通知列表，有未读消息时显示红点 |
| 二维码名片 | Button | 点击弹出二维码名片，可分享或扫码添加 |
| 设置入口 | Button | 跳转到设置页面 |

#### 3.1.3 会员等级说明

| 等级 | 等级名称 | 成长值要求 | 主要权益 |
|------|----------|------------|----------|
| Lv1 | 普通会员 | 0-999 | 基础权益 |
| Lv2 | 银卡会员 | 1000-4999 | 9.8折优惠、生日礼券 |
| Lv3 | 金卡会员 | 5000-19999 | 9.5折优惠、免运费券 |
| Lv4 | 白金会员 | 20000-49999 | 9折优惠、专属客服 |
| Lv5 | 钻石会员 | 50000+ | 8.5折优惠、健康管理 |

### 3.2 资产信息区
#### 3.2.1 功能说明

聚合展示用户在平台的各类资产数据，提供快速查看和跳转入口。

#### 3.2.2 包含元素

| 元素名称 | 元素类型 | 说明 |
|----------|----------|------|
| 账户余额 | DataDisplay | 显示账户可用余额，保留2位小数 |
| 优惠券 | DataDisplay | 显示可用优惠券数量 |
| 积分 | DataDisplay | 显示当前积分余额 |
| 医保余额 | DataDisplay | 显示已绑定医保账户余额，未绑定显示"去绑定" |

#### 3.2.3 数据展示规则

| 数据项 | 展示格式 | 特殊处理 |
|--------|----------|----------|
| 账户余额 | ¥0.00 | 为零时显示"¥0.00"，支持点击查看明细 |
| 优惠券 | 3张 | 为零时显示"0张"，点击跳转到优惠券列表 |
| 积分 | 280分 | 为零时显示"0分"，点击跳转到积分详情 |
| 医保余额 | ¥128.50/去绑定 | 已绑定显示余额，未绑定显示"去绑定"引导 |

### 3.3 订单导航区
#### 3.3.1 功能说明

提供订单状态的快捷入口，方便用户快速查看不同状态的订单。

#### 3.3.2 包含元素

| 元素名称 | 元素类型 | 说明 |
|----------|----------|------|
| 模块标题 | Text | "我的订单"，右侧显示"查看全部订单"入口 |
| 待付款 | NavItem | 显示待付款订单数量角标 |
| 待发货 | NavItem | 显示待发货订单数量角标 |
| 待收货 | NavItem | 显示待收货订单数量角标 |
| 待评价 | NavItem | 显示待评价订单数量角标 |
| 退款/售后 | NavItem | 显示退款/售后订单数量角标 |

#### 3.3.3 角标显示规则

| 数量范围 | 显示方式 |
|----------|----------|
| 0 | 不显示角标 |
| 1-99 | 显示具体数字 |
| 99+ | 显示"99+" |

### 3.4 健康特色服务区
#### 3.4.1 功能说明

聚合药品电商平台特有的健康服务功能入口。

#### 3.4.2 包含元素

### 3.6 特色功能卡片区
#### 3.6.1 功能说明

## 4. 交互说明

### 4.1 页面加载

| 场景 | 交互说明 |
|------|----------|
| 页面首次进入 | 从底部向上滑入，同时加载用户数据和资产信息 |
| 下拉刷新 | 支持下拉刷新，刷新用户资产和订单状态数据 |
| 页面返回 | 从左侧向右滑出，返回上一页 |

### 4.2 点击交互

| 点击区域 | 交互说明 |
|----------|----------|
| 用户头像 | 进入头像更换页面，支持拍照或从相册选择 |
| 编辑资料 | 进入个人资料编辑页，可修改昵称、性别、生日等 |
| 二维码名片 | 弹出二维码名片弹窗，支持保存到相册或分享给好友 |
| 消息中心 | 进入消息通知列表页 |
| 设置 | 进入设置页面 |
| 资产项（余额/优惠券/积分/医保） | 跳转到对应资产管理详情页 |
| 订单状态项 | 跳转到订单列表页并自动筛选对应状态 |
| 查看全部订单 | 跳转到全部订单列表页 |
| 健康服务区 | 跳转到对应健康服务页面 |
| 功能服务区 | 跳转到对应功能页面 |
| 特色卡片 | 跳转到对应特色功能页面 |
| 底部导航区 | 切换到对应功能模块 |

### 4.3 滑动交互

| 滑动方向 | 交互说明 |
|----------|----------|
| 下拉 | 触发页面刷新，刷新用户资产和订单数据 |
| 上滑 | 页面内容向上滚动，顶部导航栏可出现返回顶部按钮 |

## 5. 状态说明

### 5.1 页面状态

| 状态 | 说明 | 表现 |
|------|------|------|
| 加载中 | 页面数据正在加载 | 显示骨架屏或加载动画 |
| 加载完成 | 数据加载成功 | 正常显示页面内容 |
| 加载失败 | 数据加载失败 | 显示错误提示和重试按钮 |
| 未登录 | 用户未登录 | 显示游客态，提示登录 |
| 网络异常 | 网络连接失败 | 显示网络异常提示 |

### 5.2 数据状态

| 数据项 | 状态说明 | 展示规则 |
|--------|----------|----------|
| 会员等级 | 根据成长值计算 | 显示对应等级图标和名称 |
| 资产数据 | 实时查询 | 为零时显示默认值，不为零时显示具体数值 |
| 订单角标 | 根据订单数量 | 为零不显示，大于零显示具体数字 |
| 消息红点 | 根据未读消息数 | 为零不显示，大于零显示红点或数字 |

### 5.3 会员等级状态

| 等级 | 图标 | 颜色 |
