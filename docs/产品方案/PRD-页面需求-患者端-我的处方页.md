## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 我的处方页 |
| 页面路径 | /prescription/list |
| 页面类型 | 管理页 |
| 访问权限 | 需要登录 |
| 设计目标 | 用户管理个人处方记录，展示平台问诊开具的电子处方和历史处方，支持凭处方购药 |
| 入口来源 | 个人中心-我的处方、问诊详情页-查看处方、订单确认页-选择处方 |
| 出口目标 | 处方详情页、凭处方购药流程、订单确认页 |

### 1.2 页面定位

我的处方页是DrugMall用户处方管理的统一入口，承担以下关键职责：

1. **处方集中管理**：集中展示用户在平台的所有处方记录，包括问诊开具的电子处方和用户自行上传的纸质处方
2. **处方状态追踪**：清晰展示处方当前状态（待使用、已使用、已过期），帮助用户了解处方可用性
3. **便捷购药入口**：支持凭处方直接购药，自动匹配平台可售药品，简化购药流程
4. **处方合规管理**：支持处方分享给监管药师审核，确保处方流转合规性
5. **到期提醒服务**：主动提醒用户即将过期的处方，避免处方失效造成的不便

### 1.3 业务规则

| 规则类型 | 规则描述 |
|----------|----------|
| 处方来源 | 支持两种来源：平台问诊开具的电子处方、用户拍照上传的纸质处方 |
| 处方有效期 | 电子处方有效期30天，纸质处方以医生标注有效期为准，默认30天 |
| 处方使用次数 | 每张处方只能使用一次，使用后状态变为"已使用" |
| 处方药购买 | 处方药必须凭有效处方购买，系统校验处方状态和使用权限 |
| 处方分享 | 支持生成处方二维码或链接分享给药师审核，分享有效期24小时 |
| 到期提醒 | 处方即将过期（7天内）时推送提醒，已过期处方保留展示30天后归档 |
| 处方下载 | 支持下载PDF格式处方，包含完整处方信息和电子签名 |
| 隐私保护 | 处方列表脱敏展示，详情页完整展示，分享时患者信息加密处理 |

## 5. 凭处方购药流程

### 5.1 流程概述

用户凭有效处方购买处方药的完整流程：

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 选择处方 │ -> │ 药品匹配 │ -> │ 确认购买 │ -> │ 支付完成 │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

### 5.2 详细流程

#### 步骤1：选择处方

- 在"我的处方"页选择待使用的处方
- 点击"凭处方购药"按钮
- 或从问诊详情页直接进入购药流程

   **同成分替代药建议：**
   - 原药品：某某特效药 50mg
   - 替代药品：某某仿制药 50mg（已通过一致性评价）
   - 价格对比：￥128.00 vs ￥28.00
   - 操作：[使用替代药]

3. **操作按钮：**
   - [全部加入购物车]（匹配成功的药品）
   - [继续选购其他药品]
   - [返回处方列表]

**交互说明：**
- 药品卡片显示平台售价与医院售价对比（如有数据）
- 点击药品名称进入药品详情页
- 库存不足时显示"库存紧张"或"暂时缺货"
- 匹配失败的药品提供同成分替代药建议
- 用户可选择部分药品加入购物车

#### 步骤3：确认购买

从购物车或直接购买进入订单确认页面：

**订单确认页包含：**
1. 收货地址选择
2. 处方信息展示（关联的处方单号）
3. 药品清单确认
4. 配送方式选择
5. 优惠券选择
6. 支付方式选择
7. 订单金额明细
8. [提交订单]按钮

**特殊说明：**
- 处方药订单必须关联有效处方
- 收货人姓名需与处方患者姓名一致（实名验证）
- 处方会随药品一起配送（纸质处方复印件）

#### 步骤4：支付完成

- 支付成功后，处方状态变为"已使用"
- 订单详情页可查看关联的处方信息
- 可在"我的处方"页查看已使用的处方及关联订单

## 6. 处方分享功能

### 6.1 分享场景

1. **分享给监管药师审核**
   - 用户购买处方药前，可分享处方给平台药师进行合规性审核
   - 确保处方真实有效，符合购药要求

2. **分享给家人查看**
   - 患者可将处方分享给家属，方便家属协助购药

3. **分享给医生复诊**
   - 复诊时可向医生展示历史处方

### 6.2 分享方式

| 分享方式 | 说明 | 有效期 |
|----------|------|--------|
| 生成二维码 | 生成处方二维码图片 | 24小时 |
| 复制链接 | 生成处方查看链接 | 24小时 |
| 微信分享 | 调用微信分享SDK | 24小时 |
| 短信分享 | 发送处方链接短信 | 24小时 |

### 6.3 分享安全

- 分享链接包含加密token，防止暴力破解
- 分享页面脱敏展示患者隐私信息
- 分享有效期限制为24小时
- 可随时撤销已分享的处方链接

## 7. 处方提醒机制

### 7.1 提醒类型

| 提醒类型 | 触发条件 | 提醒方式 | 提醒内容 |
|----------|----------|----------|----------|
| 即将过期 | 处方7天内过期 | App推送、短信 | "您的处方(单号：XXX)将在X天后过期，请及时使用" |
| 已过期 | 处方过期当天 | App推送 | "您的处方已过期，如需购药请重新问诊开方" |
| 可使用 | 新处方开具后 | App推送 | "医生已为您开具处方，可凭处方购药" |
| 购药提醒 | 处方15天未使用 | App推送、短信 | "您的处方已开具15天，还有15天即将过期" |

### 7.2 提醒设置

- 用户可在设置中开启/关闭处方提醒
- 可设置提醒时间（提前7天、3天、1天）
- 可选择提醒方式（App推送、短信、微信）

### 11.2 处方数据结构

```typescript
// 处方基础信息
interface Prescription {
  id: string;                    // 处方ID
  prescriptionNo: string;        // 处方单号
  status: PrescriptionStatus;    // 处方状态
  type: PrescriptionType;        // 处方类型
  
  // 患者信息
  patientInfo: {
    name: string;               // 患者姓名
    gender: Gender;             // 性别
    age: number;                // 年龄
    idCard: string;             // 身份证号（加密）
    allergyHistory: string;       // 过敏史
  };
  
  // 医生信息
  doctorInfo: {
    id: string;                 // 医生ID
    name: string;               // 医生姓名
    title: string;              // 职称
    hospital: string;           // 执业医院
    department: string;         // 科室
    licenseNo: string;          // 执业编号
    signature: string;          // 电子签名
  };
  
  // 处方时间信息
  createTime: string;           // 开具时间
  expireTime: string;           // 有效期至
  useTime?: string;             // 使用时间（已使用时）
  
  // 问诊关联
  inquiryId?: string;           // 关联问诊ID
  inquiryNo?: string;           // 问诊单号
  
  // 诊断信息
  diagnosis: {
    western: string;            // 西医诊断
    traditional?: string;       // 中医诊断
  };
  
  // 药品列表
  drugs: PrescriptionDrug[];
  
  // 医嘱
  instructions: {
    usage: string;              // 用法用量说明
    precautions: string;        // 注意事项
  };
  
  // 药师审核
  pharmacistReview?: {
    result: 'pass' | 'reject';  // 审核结果
    opinion?: string;           // 审核意见
    name?: string;              // 药师姓名
    time?: string;              // 审核时间
  };
  
  // 关联订单（已使用时）
  orderId?: string;             // 关联订单ID
  orderNo?: string;             // 订单编号
  
  // 扩展信息
  extra?: {
    attachments?: string[];     // 附件（上传处方的图片）
    remarks?: string;           // 备注
  };
}

// 处方药品
interface PrescriptionDrug {
  id: string;                   // 药品ID
  name: string;                 // 药品名称
  genericName?: string;         // 通用名
  brandName?: string;           // 商品名
  specification: string;        // 规格
  dosage: string;               // 单次剂量
  usage: string;                // 用法
  frequency: string;            // 频次
  quantity: number;             // 数量
  unit: string;                 // 单位
  remarks?: string;             // 备注
  // 平台匹配信息
  platformMatch?: {
    skuId?: string;             // 平台SKU
    stock?: number;             // 库存
    price?: number;             // 售价
    matched: boolean;           // 是否匹配成功
  };
}

// 处方状态
enum PrescriptionStatus {
  UNUSED = 'unused',           // 待使用
  USED = 'used',               // 已使用
  EXPIRED = 'expired',         // 已过期
  CANCELLED = 'cancelled'      // 已作废
}

// 处方类型
enum PrescriptionType {
  ELECTRONIC = 'electronic',   // 电子处方
  UPLOAD = 'upload'            // 上传处方
}
```
