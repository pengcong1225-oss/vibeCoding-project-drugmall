## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 搜索页 |
| 页面路径 | /search |
| 页面类型 | 功能页 |
| 访问权限 | 公开访问（无需登录） |
| 设计目标 | 提供高效便捷的药品搜索功能，帮助用户快速找到所需药品 |

### 1.2 页面定位

搜索页是DrugMall患者端的核心功能页面，承担以下职责：
1. **搜索入口**：提供关键词搜索、语音搜索、扫码搜索等多种搜索方式
2. **智能联想**：根据用户输入实时联想药品名称、症状、品牌等
3. **历史记录**：保存用户搜索历史，方便快速重新搜索
4. **热门推荐**：展示热门搜索词，引导用户发现热门药品
5. **结果筛选**：提供多维度筛选排序功能，帮助用户精准定位目标药品

## 3. 页面元素详细说明

### 3.1 顶部状态栏

同首页，44px高度，iOS系统状态栏。

### 3.2 顶部搜索栏

| 项目 | 说明 |
|------|------|
| 高度 | 56px |
| 背景色 | 白色 |
| 布局 | 左侧返回按钮，中间搜索框，右侧扫描和语音按钮 |
| 返回按钮 | 40px×40px，点击返回上一页 |
| 搜索框 | flex:1，高度40px，圆角20px，背景#F5F5F5 |
| 搜索框内容 | 左侧🔍图标，中间输入文字，右侧清除按钮（有内容时显示） |
| 扫描按钮 | 40px×40px，📷图标，点击唤起扫码 |
| 语音按钮 | 40px×40px，🎤图标，点击唤起语音输入 |
| 边框 | 底部1px #E8E8E8边框 |

**交互说明：**
- 返回按钮：点击返回上一页（首页/搜索结果页等）
- 搜索框：
  - 聚焦时显示光标，软键盘自动弹出
  - 输入时实时显示联想结果
  - 有内容时显示清除按钮，点击清空输入
  - 点击键盘搜索按钮执行搜索
- 扫描按钮：点击唤起相机，扫描药品条形码
- 语音按钮：点击唤起语音输入，识别后自动填入搜索框

### 3.3 搜索联想区

| 项目 | 说明 |
|------|------|
| 显示时机 | 搜索框有输入内容时显示 |
| 背景色 | 白色 |
| 布局 | 垂直列表 |
| 联想项 | 每个联想项一行 |
| 联想项内容 | 🔍图标 + 联想文字 + 类型标签 |
| 类型标签 | 药品、症状、品牌、店铺等 |

**联想项类型：**

| 类型 | 图标 | 说明 | 示例 |
|------|------|------|------|
| 药品 | 💊 | 药品名称联想 | 阿莫西林胶囊 |
| 症状 | 🏥 | 症状关键词联想 | 感冒发热吃什么药 |
| 品牌 | 🏷️ | 品牌名称联想 | 999感冒药 |
| 店铺 | 🏪 | 店铺名称联想 | 同仁堂大药房 |
| 通用名 | 💉 | 药品通用名联想 | 阿莫西林 |

**交互说明：**
- 输入时实时请求联想接口，显示联想结果
- 点击联想项，将联想内容填入搜索框并执行搜索
- 支持键盘上下键选择联想项，回车确认
- 无联想结果时显示"暂无相关推荐"

### 3.4 历史搜索区

| 项目 | 说明 |
|------|------|
| 显示时机 | 搜索框无输入内容且未执行搜索时显示 |
| 背景色 | 白色 |
| 标题 | "历史搜索" + 右侧"清空"按钮 |
| 布局 | 横向滚动标签 |
| 历史项 | 圆角标签，内边距8px 12px |
| 历史项内容 | 搜索关键词文字 |
| 最大数量 | 最多显示10条历史记录 |

**交互说明：**
- 点击历史项，将该关键词填入搜索框并执行搜索
- 点击"清空"按钮，弹出确认对话框，确认后清空所有历史记录
- 长按历史项，弹出删除该条记录的选项
- 历史记录按时间倒序排列，最新的在最前面
- 相同关键词只保留最近的一次

### 3.5 热门搜索区

| 项目 | 说明 |
|------|------|
| 显示时机 | 搜索框无输入内容且未执行搜索时显示（历史搜索下方） |
| 背景色 | 白色 |
| 标题 | "热门搜索" |
| 布局 | 2列网格，每行2个 |
| 热门项 | 圆角卡片，内边距12px |
| 热门项内容 | 序号（1-8）+ 搜索关键词 + 热度标识 |
| 数量 | 固定显示8个热门搜索词 |

**热度标识：**

| 排名 | 标识 | 颜色 |
|------|------|------|
| 1-3 | 🔥 | #FF4D4F |
| 4-6 | 温 | #FF9500 |
| 7-8 | - | #999999 |

**交互说明：**
- 点击热门项，将该关键词填入搜索框并执行搜索
- 热门搜索词每日更新，由后台运营配置
- 展示最近24小时内搜索量最高的关键词
- 点击"换一换"按钮，刷新显示另一批热门搜索词（如有）

### 3.6 搜索结果列表

| 项目 | 说明 |
|------|------|
| 显示时机 | 执行搜索后显示（隐藏历史/热门搜索区） |
| 背景色 | #F5F5F5（列表背景） |
| 布局 | 垂直列表 |
| 筛选栏 | 固定在顶部，高度44px |
| 结果项 | 白色背景卡片，间距12px |
| 分页加载 | 上拉加载更多，每页20条 |
| 无结果 | 显示无结果提示页 |

**筛选栏：**

| 筛选项 | 类型 | 选项 | 默认 |
|--------|------|------|------|
| 综合 | 单选 | 综合、销量、价格、评分 | 综合 |
| 销量 | 排序 | 从高到低 | - |
| 价格 | 排序 | 从低到高、从高到低 | - |
| 筛选 | 多选 | 处方药、OTC、医保、促销、包邮等 | 全部 |

**结果项内容：**

| 元素 | 说明 |
|------|------|
| 图片 | 左侧100px×100px，圆角8px |
| 标题 | 药品名称，16px，#333，最多两行 |
| 规格 | 规格信息，12px，#999 |
| 价格 | 现价18px，#FF4D4F，加粗；原价12px，#999，删除线 |
| 标签 | 处方药、OTC、医保、促销等标签 |
| 销量 | 已售数量，12px，#999 |
| 店铺 | 药店名称，12px，#999 |

**交互说明：**
- 点击结果项，进入药品详情页
- 点击筛选栏选项，切换排序或筛选条件，重新加载结果
- 上拉到底部，自动加载下一页结果
- 下拉刷新，重新加载当前搜索结果
- 无结果时，显示"没有找到相关药品"，推荐相似药品或提供反馈入口

## 4. 页面交互流程

### 4.1 搜索流程

```
用户输入关键词
    ↓
实时显示联想结果（防抖300ms）
    ↓
用户选择联想项或点击搜索
    ↓
保存搜索历史
    ↓
显示搜索结果列表
    ↓
用户筛选/排序/点击结果项
```

### 4.2 扫码搜索流程

```
点击扫描按钮
    ↓
唤起相机/扫码界面
    ↓
扫描药品条形码
    ↓
识别成功 → 自动搜索并显示结果
    ↓
识别失败 → 提示"未识别到药品信息"
```

### 4.3 语音搜索流程

```
点击语音按钮
    ↓
唤起语音输入界面
    ↓
用户说话
    ↓
语音识别 → 自动填入搜索框 → 执行搜索
    ↓
识别失败 → 提示"未听清，请重试"
```

## 5. 页面状态

### 5.1 正常状态

页面正常显示所有内容，搜索功能可用，结果列表正常加载。

### 5.2 加载状态

| 场景 | 表现形式 |
|------|----------|
| 首次加载 | 显示骨架屏，从上到下渐显 |
| 搜索中 | 搜索按钮显示加载动画，结果区显示骨架屏 |
| 加载更多 | 底部显示加载动画，旋转圆圈+"正在加载更多..." |
| 加载失败 | 显示错误提示，提供重试按钮 |

### 5.3 空状态

| 场景 | 表现形式 |
|------|----------|
| 无搜索结果 | 显示"没有找到相关药品"，推荐相似药品，提供反馈入口 |
| 无历史记录 | 显示"暂无搜索历史"，提示开始搜索 |
| 无网络 | 显示"网络连接失败"，提供重试按钮 |

### 5.4 错误状态

| 场景 | 表现形式 |
|------|----------|
| 搜索失败 | 提示"搜索失败，请稍后重试"，保留上次结果或显示空状态 |
| 加载失败 | 提示"加载失败"，提供重试按钮 |
| 服务异常 | 提示"服务繁忙，请稍后重试"，提供客服联系方式 |

## 6. 数据埋点

### 6.1 关键埋点事件

| 事件名称 | 事件ID | 触发时机 | 采集参数 |
|----------|--------|----------|----------|
| 搜索页曝光 | search_page_view | 页面加载完成 | page_title, load_time |
| 搜索框聚焦 | search_box_focus | 搜索框获得焦点 | position |
| 搜索输入 | search_input | 输入关键词 | keyword, input_duration |
| 搜索联想 | search_suggest | 显示联想结果 | keyword, suggest_count |
| 联想点击 | search_suggest_click | 点击联想项 | keyword, suggest_position |
| 搜索执行 | search_execute | 执行搜索 | keyword, search_type |
| 搜索结果曝光 | search_result_view | 搜索结果展示 | keyword, result_count |
| 结果点击 | search_result_click | 点击结果项 | keyword, result_position, product_id |
| 筛选点击 | search_filter_click | 点击筛选条件 | keyword, filter_type, filter_value |
| 排序切换 | search_sort_change | 切换排序方式 | keyword, sort_type |
| 历史点击 | search_history_click | 点击历史记录 | keyword, history_position |
| 热门点击 | search_hot_click | 点击热门搜索 | keyword, hot_position |
| 清空历史 | search_history_clear | 清空历史记录 | history_count |
| 加载更多 | search_load_more | 加载更多结果 | keyword, page_num |

### 6.2 埋点数据用途

| 数据用途 | 说明 |
|----------|------|
| 搜索转化率分析 | 分析搜索到点击的转化率，优化搜索结果排序 |
| 用户搜索行为分析 | 了解用户搜索习惯，优化搜索算法 |
| 热门关键词分析 | 识别热门搜索词，优化药品推荐和库存 |
| 搜索失败分析 | 分析无结果搜索词，补充缺失药品 |
| 筛选排序偏好 | 了解用户筛选排序偏好，优化默认排序 |
