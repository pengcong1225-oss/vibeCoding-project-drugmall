## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 药品详情 |
| 页面路径 | /product/:id |
| 页面类型 | 详情页 |
| 访问权限 | 公开访问（无需登录） |
| 设计目标 | 展示药品完整信息，支持规格选择，引导用户加入购物车 |

### 1.2 页面定位

药品详情页是用户了解和购买药品的核心页面，承担以下职责：

1. **信息展示**：完整展示药品的基本信息、适应症、用法用量等
2. **规格选择**：支持选择不同的规格和包装
3. **购买引导**：提供加入购物车和立即购买的入口
4. **决策辅助**：通过评价、问答等帮助用户做出购买决策

## 3. 页面元素详细说明

### 3.1 顶部状态栏

同首页，44px高度，iOS系统状态栏。

### 3.2 顶部导航栏

| 项目 | 说明 |
|------|------|
| 高度 | 44px |
| 背景色 | 白色 |
| 左侧 | 返回按钮（箭头图标），点击返回上一页 |
| 中间 | 页面标题"药品详情"，16px，#333，居中 |
| 右侧 | 分享按钮（分享图标）、更多按钮（三点图标） |
| 边框 | 底部1px #E8E8E8边框 |

**交互说明：**
- 返回按钮：点击返回上一页（首页/搜索结果/分类页等）
- 分享按钮：点击弹出分享菜单（微信、朋友圈、复制链接等）
- 更多按钮：点击弹出更多操作菜单（举报、反馈等）

### 3.3 图片轮播区

| 项目 | 说明 |
|------|------|
| 高度 | 375px（正方形，宽高比1:1） |
| 背景色 | #F5F5F5（图片加载前显示） |
| 图片显示 | 居中显示，object-fit: contain |
| 轮播指示器 | 底部居中，圆点样式，当前高亮 |
| 左右滑动 | 支持左右滑动切换图片 |
| 图片数量 | 显示"1/5"这样的计数 |

**交互说明：**
- 左右滑动：切换图片
- 点击放大：双击或双指放大查看图片
- 指示器点击：跳转到对应图片
- 自动轮播：不自动轮播，用户主动浏览

## 5. 页面状态

### 5.1 正常状态

页面正常显示所有内容，各区块数据加载完成，交互正常。

### 5.2 加载状态

| 场景 | 表现形式 |
|------|----------|
| 首次加载 | 显示骨架屏，从上到下渐显 |

### 5.3 空状态

| 场景 | 表现形式 |

| 商品售罄 | 显示"该商品已售罄"，支持到货提醒 |

| 场景 | 表现形式 |
