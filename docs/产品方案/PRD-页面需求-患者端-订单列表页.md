## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 订单列表 |
| 页面路径 | /orders |
| 页面类型 | 功能页 |
| 访问权限 | 需要登录 |
| 设计目标 | 管理用户所有订单，支持订单查询、筛选、状态跟踪和操作处理 |

### 1.2 页面定位

订单列表页是DrugMall患者端的核心交易管理页面，承担以下职责：
1. **订单全景管理**：集中展示用户所有订单，按状态分类管理
2. **订单状态跟踪**：实时显示订单状态，支持物流跟踪
3. **订单操作处理**：支持支付、确认收货、评价、售后等操作
4. **订单查询筛选**：支持关键词搜索、时间范围、订单类型筛选
5. **处方药标识**：清晰标识处方药订单及处方审核状态
6. **医保订单标识**：标识医保支付订单及结算状态

| 待付款 | 订单已提交未支付 | 有待付款订单时显示数量 |

- 点击标签切换对应状态订单列表
- 当前选中标签底部显示主色下划线

### 5.2 状态详细说明

| 订单状态 | 状态说明 | 用户可操作 | 自动流转条件 |
|----------|----------|------------|--------------|
| 待付款 | 订单已提交，等待用户支付 | 去支付、取消订单 | 超时未支付自动取消（默认24小时） |
| 待发货 | 用户已支付，等待商家发货 | 申请退款、提醒发货 | - |
| 待收货 | 商家已发货，等待用户确认收货 | 查看物流、确认收货 | 发货后N天自动确认收货（默认7天） |
| 待评价 | 用户已确认收货，等待评价 | 评价、再次购买、删除订单 | 超时未评价自动好评（默认15天） |
| 已完成 | 订单已完成，包含已评价订单 | 再次购买、删除订单、查看评价 | - |
| 已取消 | 用户主动取消或超时未支付 | 再次购买、删除订单 | - |
| 退款中 | 用户申请退款，正在处理中 | 查看退款进度、联系客服 | - |
| 已退款 | 退款已完成 | 再次购买、删除订单 | - |

## 7. 异常处理

### 7.1 网络异常

| 异常场景 | 处理方式 | 提示信息 |
|----------|----------|----------|
| 无网络连接 | 显示网络异常页面，提供重试按钮 | "网络开小差了，请检查网络后重试" |
| 请求超时 | 显示Toast提示，保留当前数据 | "请求超时，请稍后重试" |
| 服务器错误 | 显示错误页面，提供重试按钮 | "服务器繁忙，请稍后重试" |

### 7.2 数据异常

| 异常场景 | 处理方式 | 提示信息 |
|----------|----------|----------|
| 订单数据为空 | 显示空状态页面 | "暂无订单，快去选购心仪的药品吧~" |
| 订单状态异常 | 显示错误提示，建议刷新 | "订单状态异常，请刷新后重试" |
| 权限不足 | 跳转登录页或提示无权限 | "请先登录后查看订单" |

### 7.3 操作异常

| 异常场景 | 处理方式 | 提示信息 |
|----------|----------|----------|
| 取消订单失败 | 显示Toast提示失败原因 | "取消订单失败，请稍后重试" |
| 确认收货失败 | 显示Toast提示失败原因 | "确认收货失败，请稍后重试" |
| 删除订单失败 | 显示Toast提示失败原因 | "删除订单失败，请稍后重试" |
| 重复操作 | 防抖处理，显示提示 | "操作过于频繁，请稍后再试" |
