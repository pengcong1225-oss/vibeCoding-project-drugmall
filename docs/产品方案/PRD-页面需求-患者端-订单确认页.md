## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 订单确认页 |
| 页面路径 | /order/confirm |
| 页面类型 | 交易页 |
| 访问权限 | 需要登录 |
| 设计目标 | 引导用户完成订单信息确认并提交订单 |
| 入口来源 | 购物车-去结算、商品详情-立即购买、问诊购药、处方购药 |
| 出口目标 | 订单详情页、支付收银台 |

### 1.2 页面定位

订单确认页是DrugMall交易流程中的核心环节，承担以下关键职责：

1. **信息聚合展示**：汇总订单所需的全部信息，包括地址、商品、优惠、费用等
2. **决策支持**：提供配送方式、优惠券等可选项，辅助用户做出最优选择
3. **合规校验**：验证处方药需处方、实名认证等合规要求
4. **医保结算**：支持医保在线结算，展示医保支付明细
5. **订单提交**：确认所有信息后提交订单，进入支付流程

### 1.3 业务规则

| 规则类型 | 规则描述 |
|----------|----------|
| 处方规则 | 处方药必须有有效处方才能购买，处方药单独分单 |
| 医保规则 | 医保结算订单需先绑定医保卡并完成实名认证 |
| 配送规则 | 处方药仅支持到店自取，部分药品不支持快递配送 |
| 优惠券规则 | 优惠券按品类、品牌、订单金额等条件筛选可用券 |
| 库存规则 | 提交订单时实时校验库存，库存不足提示并标记 |
| 限购规则 | 部分药品有购买数量限制，超限无法提交 |
| 金额规则 | 订单实付金额需大于0元，支持部分医保支付的混合支付 |

## 3. 页面元素详细说明

### 3.1 顶部导航栏
| 元素 | 说明 |
|------|------|
| 返回按钮 | 左侧箭头图标，点击返回上一页（购物车或商品详情） |
| 页面标题 | "订单确认"，居中显示 |
| 客服入口 | 右侧耳机/客服图标，点击进入客服会话 |

**交互说明**
- 返回按钮点击后需弹出确认提示（如已修改配送方式、地址）
- 客服入口点击后传递当前订单上下文信息

### 3.2 收货地址卡片

| 元素 | 说明 |
|------|------|
| 位置图标 | 左侧地图/位置标记图标 |
| 收件人姓名 | 显示收货人姓名（如：张晓明） |
| 联系电话 | 显示脱敏手机号（如：138****8888） |
| 详细地址 | 显示省市区详细地址 |
| 右箭头 | 点击进入地址选择/管理页 |

**异常状态**

| 状态 | 显示方式 |
|------|----------|
| 无地址 | 显示"+ 添加收货地址"按钮，突出显示 |
| 地址超范围 | 显示"当前地址不在配送范围"警告提示 |
| 处方药到店自取 | 显示门店地址而非收货地址 |

**交互说明**
- 点击整行区域进入地址列表页
- 首次进入页面时自动选中默认地址

### 3.3 配送方式选择

| 元素 | 说明 |
|------|------|
| 模块标题 | "配送方式" |
| 配送方式选项 | 快递配送、同城配送、到店自取 |
| 运费显示 | 各选项下方显示对应运费 |
| 预计送达 | 显示预计送达日期和时间段 |

**配送方式规则**

| 配送方式 | 适用场景 | 费用规则 | 时效 |
|----------|----------|----------|------|
| 快递配送 | 普通订单 | 满99元免邮，否则8元 | 2-3天 |
| 同城配送 | 紧急用药 | 基础费12元+距离费 | 1-4小时 |
| 到店自取 | 处方药、用户选择 | 免费 | 当天可取 |

**特殊处理**

| 场景 | 处理方式 |
|------|----------|
| 处方药订单 | 强制选择"到店自取"，其他选项置灰 |
| 冷链药品 | 显示冷链配送说明，运费额外+5元 |
| 医保订单 | 配送方式不影响医保结算 |

**交互说明**
- 点击选项卡切换配送方式
- 切换后实时重新计算运费和订单总额
- 到店自取显示门店地图入口

| 单价 | 商品单价 |

### 3.5 优惠信息

| 元素 | 说明 |
|------|------|
| 优惠券选择 | 显示可用优惠券数量，点击进入优惠券列表 |

**优惠券模块**

| 元素 | 说明 |
|------|------|
| 入口标题 | "优惠券" |
| 状态显示 | 未选时显示"请选择"、X张可用，已选显示优惠券名称 |
| 右箭头 | 点击进入优惠券选择页 |
| 优惠金额 | 右侧显示预计可优惠金额（选券后更新） |

**优惠券选择页规则**

- 列表展示当前订单可用的所有优惠券
- 按优惠金额从大到小排序
- 不可用的券置灰显示，标注不可用原因
- 支持单选，选中后返回订单确认页
- 显示优惠券详情：使用条件、有效期、适用范围

**会员折扣模块**

| 元素 | 说明 |
|------|------|
| 入口标题 | "会员折扣" |
| 会员标识 | 显示会员等级图标和名称（如：黄金会员） |
| 折扣信息 | 显示折扣力度（如：享95折） |
| 节省金额 | 显示本次已省金额 |

**积分抵扣模块**

| 元素 | 说明 |
|------|------|
| 入口标题 | "积分抵扣" |
| 积分状态 | 显示可用积分总数 |

| 积分规则 | 点击可查看积分使用规则 |

**抵扣优先级规则**

抵扣金额计算顺序（从高到低优惠）：
1. 会员折扣（先计算折扣后金额）
2. 优惠券（满减/折扣券）
3. 积分抵扣（抵扣剩余金额）

### 3.6 费用明细

| 元素 | 说明 |
|------|------|
| 商品总额 | 所有商品小计之和 |
| 运费 | 各配送方式对应的运费 |
| 优惠券抵扣 | 使用优惠券减免金额（负数显示） |
| 会员折扣 | 会员折扣减免金额（负数显示） |
| 积分抵扣 | 积分抵扣金额（负数显示） |
| 分隔线 | 分隔上方明细和下方订单金额 |
| 订单金额 | 实付金额（商品总额+运费-所有优惠） |

**费用明细展示样式**

```
商品总额                        ¥49.50
运费                           + ¥8.00
优惠券                         - ¥5.00
会员折扣                       - ¥2.48
积分抵扣                       - ¥0.00
─────────────────────────────────────
订单金额                        ¥50.02
```

**金额计算规则**

| 计算项 | 公式 |
|--------|------|
| 商品总额 | Σ(商品单价 × 数量) |
| 运费 | 根据配送方式计算 |
| 优惠券抵扣 | 根据优惠券规则计算 |
| 会员折扣 | 商品总额 × (1 - 折扣率) |
| 积分抵扣 | 可用积分 ÷ 100（1积分=0.01元） |
| 订单金额 | 商品总额 + 运费 - 优惠券 - 会员折扣 - 积分抵扣 |

**金额精度规则**
- 所有金额保留2位小数
- 中间计算过程保留4位小数，最终展示四舍五入到2位
- 订单金额必须大于0

## 4. 交互说明

### 4.1 页面加载流程

```
用户点击"去结算"
      ↓
页面加载中
      ↓
获取订单初始化数据
      ↓              ↓
              渲染页面（地址、商品、优惠券等）
              计算订单金额（商品总额、运费、优惠）
              页面加载完成，可交互
```

**加载状态处理**

| 状态 | 处理方式 |
|------|----------|
| 加载中 | 显示骨架屏或loading动画 |
| 加载成功 | 渲染页面内容 |
| 加载失败 | 显示错误提示，提供重试按钮 |
| 部分失败 | 显示已加载内容，失败部分显示占位 |

### 4.2 地址选择交互

```
点击地址卡片
      ↓
跳转地址列表页
      ↓
用户选择/新增/编辑地址
      ↓
返回订单确认页
      ↓
更新地址信息，重新计算运费
      ↓
更新订单金额
```

**地址变更影响**

| 变更类型 | 影响范围 |
|----------|----------|
| 切换地址 | 运费重新计算、配送方式可用性检查 |
| 地址超范围 | 提示配送范围外，需更换地址 |
| 处方药自取 | 地址固定为门店地址，不可修改 |

### 4.3 配送方式切换交互
```
点击配送方式选项
      ↓
切换选中状态
      ↓
更新预计送达时间
      ↓
重新计算运费
      ↓
更新订单金额
```

**配送方式限制**

| 场景 | 处理方式 |
|------|----------|
| 处方药订单 | 强制"到店自取"，其他选项置灰不可选 |
| 冷链药品 | 仅支持快递配送、同城配送 |
| 地址超范围 | "快递配送"可用，"同城配送"置灰 |
| 门店休息 | "到店自取"置灰，显示营业时间 |

### 4.4 优惠券选择交互

```
点击优惠券入口
      ↓
打开优惠券选择弹窗/页面
      ↓
展示可用/不可用券列表
      ↓
用户选择优惠券
      ↓
关闭弹窗，返回订单确认页
      ↓
更新优惠金额，重新计算订单金额
```

**优惠券选择规则**

| 规则 | 说明 |
|------|------|
| 互斥规则 | 一张订单只能使用一张优惠券 |
| 默认选中 | 自动选择优惠力度最大的可用券 |
| 不选优惠 | 用户可选择"不使用优惠券" |
| 不可用券 | 置灰显示，标注不可用原因（如：满减条件不满足） |

**优惠券计算顺序**
- 先计算会员折扣（基于商品总额）
- 再应用优惠券（基于折扣后金额）
- 最后计算积分抵扣（基于优惠券后金额）

### 4.5 积分抵扣交互

```
默认开启积分抵扣
      ↓
自动计算最大可抵扣金额
      ↓
显示"已抵扣XX元"或"当前未使用"
      ↓
用户可关闭/开启抵扣开关
      ↓
更新订单金额
```

**积分抵扣规则**

| 规则 | 说明 |
|------|------|
| 抵扣比例 | 100积分=1元，可抵扣订单金额的10% |
| 最低抵扣 | 最低100积分起抵扣 |
| 抵扣上限 | 单笔订单最多抵扣50元 |
| 积分不足 | 显示可用积分，按实际可用抵扣 |

### 4.6 订单提交交互

```
点击"提交订单"按钮
      ↓
前置校验（地址、库存、处方等）
      ↓
校验通过？
      ↓否          ↓是
显示错误提示，定位到问题项
      ↓
校验通过
      ↓
按钮置为"提交中..."状态
      ↓
调用创建订单API
      ↓
创建成功？
      ↓否          ↓是
显示错误提示（库存不足、价格变动等）
      ↓
创建成功
      ↓
跳转订单详情页或支付页
```

**前置校验规则**

| 校验项 | 校验规则 | 失败提示 |
|--------|----------|----------|
| 收货地址 | 必须选择有效地址 | "请选择收货地址" |
| 配送方式 | 必须选择配送方式 | "请选择配送方式" |
| 处方药处方 | 处方药必须有有效处方 | "处方药需凭处方购买，请先上传处方" |
| 库存校验 | 所有商品库存充足 | "XXX商品库存不足，请调整数量" |
| 实名认证 | 处方药、医保订单需实名认证 | "购买处方药需完成实名认证" |
| 医保绑定 | 医保订单需绑定有效医保卡 | "请绑定医保卡后再使用医保结算" |
| 金额校验 | 实付金额>0 | "订单金额异常，请刷新重试" |

**提交中状态处理**

| 场景 | 处理方式 |
|------|----------|
| 网络超时 | 显示"网络超时，请重试"，保留页面状态 |
| 价格变动 | 提示"商品价格已变动，请确认后重新提交" |
| 库存不足 | 提示"XXX商品库存不足"，标记缺货商品 |
| 优惠券失效 | 提示"优惠券已失效"，自动选中最优券或取消优惠 |
| 处方过期 | 提示"处方已过期，请重新上传处方" |

### 4.7 异常状态处理
**网络异常**

| 场景 | 处理方式 |
|------|----------|

| 接口超时 | 自动重试1次，仍失败则提示用户手动刷新 |
| 弱网环境 | 显示加载进度，允许用户取消操作 |

**数据异常**

|------|----------|

| 价格异常 | 提示"价格异常，请刷新后重试" |

## 8. 性能要求

### 8.1 加载性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首屏加载时间 | ≤1.5秒 | 从进入页面到首屏内容可见 |
| 接口响应时间 | ≤800ms | 订单初始化接口响应时间 |
| 页面可交互时间 | ≤2秒 | 页面元素可点击响应 |
| 金额计算响应 | ≤100ms | 切换配送方式、优惠券后的金额更新 |

### 8.2 渲染性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 滚动帧率 | ≥50fps | 页面滚动流畅度 |
| 动画流畅度 | ≥50fps | 金额变动、切换动画流畅 |
| 内存占用 | ≤150MB | 页面运行时内存占用 |

### 8.3 优化策略

| 优化项 | 策略 |
|--------|------|
| 接口优化 | 订单初始化接口合并多个数据源，减少请求次数 |
| 数据缓存 | 地址、优惠券等数据本地缓存，减少重复请求 |
| 懒加载 | 图片懒加载，非首屏内容延迟加载 |
| 计算优化 | 金额计算使用防抖，避免频繁计算 |
| 骨架屏 | 页面加载时显示骨架屏，提升感知性能 |

### 11.1 接口说明

#### 订单初始化接口
```
GET /api/v1/order/init

Request:
{
  "cartIds": ["123", "456"],        // 购物车ID列表
  "productId": null,                 // 立即购买时使用
  "quantity": null,
  "prescriptionId": null             // 问诊购药处方ID
}

Response:
{
  "code": 200,
  "data": {
    "addressList": [],               // 地址列表
    "defaultAddress": {},            // 默认地址
    "storeList": [                   // 药店列表
      {
        "storeId": "",
        "storeName": "",
        "products": [],              // 商品列表
        "prescription": {},          // 处方信息（处方药）
        "subtotal": 0,
        "deliveryFee": 0
      }
    ],
    "availableCoupons": [],          // 可用优惠券
    "memberInfo": {},                // 会员信息
    "integralInfo": {},              // 积分信息
    "medicalInsurance": {},          // 医保信息
    "deliveryOptions": []            // 配送方式选项
  }
}
```

#### 创建订单接口

```
POST /api/v1/order/create

Request:
{
  "addressId": "",                   // 收货地址ID
  "deliveryType": "EXPRESS",         // 配送方式
  "storeOrders": [                   // 各药店订单
    {
      "storeId": "",
      "productIds": [],
      "prescriptionId": "",          // 处方药处方ID
      "couponId": ""                 // 优惠券ID
    }
  ],
  "useIntegral": true,               // 是否使用积分
  "integralAmount": 100,             // 使用积分数
  "remark": "",                      // 订单备注
  "medicalInsurance": {              // 医保结算信息
    "useMi": true,
    "miCardId": ""
  }
}

Response:
{
  "code": 200,
  "data": {
    "orderId": "",                   // 订单ID
    "orderNo": "",                   // 订单编号
    "totalAmount": 0,                // 订单总金额
    "payAmount": 0,                  // 实付金额
    "medicalInsuranceAmount": 0,     // 医保支付金额
    "createTime": "",                // 创建时间
    "payTimeout": 1800               // 支付超时时间（秒）
  }
}
```

```
GET /api/v1/order/delivery-fee
```
