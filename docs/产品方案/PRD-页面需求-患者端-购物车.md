## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 购物车 |
| 页面路径 | /cart |
| 页面类型 | 功能页 |
| 访问权限 | 需要登录 |
| 设计目标 | 管理用户选购的药品，支持批量操作和结算 |

### 1.2 页面定位

购物车是DrugMall患者端的核心交易页面，承担以下职责：
1. **商品管理**：管理用户选购的药品，支持增删改查
2. **批量操作**：支持批量选择、删除、移动等操作
3. **价格计算**：实时计算商品总价、优惠、运费等
4. **结算入口**：提供去结算按钮，跳转到订单确认页
5. **智能分单**：根据药品类型自动分单（处方药/非处方药）

## 3. 功能需求

### 3.1 商品管理功能

#### 3.1.1 添加商品到购物车
- **触发条件**：用户在商品详情页点击"加入购物车"
- **业务规则**：
  - 处方药需要验证处方信息
  - 同一商品不同规格视为不同商品
  - 购物车最多保存50种商品
  - 单个商品最多购买99件

#### 3.1.2 修改商品数量
- **操作方式**：点击 +/- 按钮或输入数量
- **业务规则**：
  - 数量范围：1-99
  - 不能超过库存数量
  - 处方药数量不能超过处方剂量

#### 3.1.3 删除商品
- **操作方式**：
  - 单条删除：左滑删除或编辑模式删除
  - 批量删除：编辑模式下多选删除
- **确认机制**：删除前弹出确认对话框

#### 3.1.4 商品失效处理
- **失效场景**：
  - 商品下架
  - 库存不足
  - 规格停售
  - 价格变动（可选）
- **处理方式**：
  - 自动移至失效商品区
  - 不参与结算计算
  - 提供一键清空功能

### 3.2 价格计算功能

#### 3.2.1 价格组成

| 价格类型 | 说明 | 计算方式 |
|----------|------|----------|
| 商品总价 | 选中商品的单价×数量之和 | Σ(单价×数量) |
| 优惠金额 | 促销优惠、会员折扣等 | 根据活动规则计算 |
| 运费 | 配送费用 | 根据配送方式和地址计算 |
| 应付金额 | 最终支付金额 | 商品总价 - 优惠金额 + 运费 |

#### 3.2.2 实时计算规则
- 商品选中状态变化时重新计算
- 数量修改时重新计算
- 每分钟同步一次最新价格

### 3.3 结算功能

#### 3.3.1 结算前置校验
- 用户登录状态校验
- 收货地址完整性校验
- 处方药处方有效性校验
- 库存充足性校验
- 商品有效性校验

#### 3.3.2 智能分单规则

| 分单类型 | 条件 | 说明 |
|----------|------|------|
| 处方药订单 | 包含处方药 | 需要处方审核 |
| OTC订单 | 仅包含OTC药品 | 普通订单流程 |
| 混合订单 | 同时包含两类 | 拆分为两个订单 |

#### 3.3.3 结算流程
```
1. 点击"去结算"按钮
2. 执行前置校验
3. 根据分单规则生成订单
4. 跳转到订单确认页
5. 等待用户确认并支付
```

### 3.4 编辑模式功能

#### 3.4.1 进入编辑模式
- 点击顶部"编辑"按钮进入
- 页面切换为编辑状态

#### 3.4.2 编辑模式功能
- **批量选择**：支持多选商品
- **批量删除**：删除选中的商品
- **移至收藏**：将商品移入收藏夹
- **完成编辑**：点击"完成"退出编辑模式

## 5. 数据需求

### 5.1 接口需求

#### 5.1.1 获取购物车列表
```
GET /api/cart/list
请求参数：
- userId: 用户ID

响应数据：
{
  "code": 200,
  "data": {
    "validItems": [...],  // 有效商品列表
    "invalidItems": [...], // 失效商品列表
    "totalCount": 10,      // 商品总数
    "selectedCount": 3     // 选中商品数
  }
}
```

#### 5.1.2 更新商品数量
```
POST /api/cart/updateQuantity
请求参数：
- cartItemId: 购物车项ID
- quantity: 新数量

响应数据：
{
  "code": 200,
  "data": {
    "newQuantity": 5,
    "subtotal": 62.50
  }
}
```

#### 5.1.3 删除购物车商品
```
POST /api/cart/delete
请求参数：
- cartItemIds: [1, 2, 3]  // 购物车项ID数组

响应数据：
{
  "code": 200,
  "message": "删除成功"
}
```

#### 5.1.4 选中/取消选中
```
POST /api/cart/select
请求参数：
- cartItemId: 购物车项ID（不传则全选/全不选）
- selected: true/false

响应数据：
{
  "code": 200,
  "data": {
    "totalAmount": 125.00,
    "discountAmount": 10.00
  }
}
```

### 5.2 数据模型

#### 5.2.1 购物车商品项
```typescript
interface CartItem {
  id: number;              // 购物车项ID
  productId: number;       // 商品ID
  productName: string;     // 商品名称
  productImage: string;    // 商品图片
  specification: string;   // 规格
  manufacturer: string;    // 生产厂家
  price: number;           // 单价
  quantity: number;        // 数量
  maxQuantity: number;     // 最大可购买数量
  drugType: 'RX' | 'OTC';  // 药品类型
  prescriptionId?: number; // 处方ID（处方药）
  selected: boolean;       // 是否选中
  valid: boolean;          // 是否有效
  invalidReason?: string;  // 失效原因
}
```

#### 5.2.2 购物车汇总
```typescript
interface CartSummary {
  totalCount: number;          // 商品总数
  selectedCount: number;       // 选中商品数
  totalAmount: number;         // 商品总价
  discountAmount: number;      // 优惠金额
  shippingFee: number;         // 运费
  payableAmount: number;       // 应付金额
}
```

## 7. 安全需求

1. **数据校验**：所有提交数据需进行服务端校验
2. **防篡改**：价格等敏感数据需加密传输
3. **限购控制**：防止恶意刷单，限制购买频率
4. **库存锁定**：结算时临时锁定库存，防止超卖
5. **操作日志**：记录关键操作日志，便于审计
