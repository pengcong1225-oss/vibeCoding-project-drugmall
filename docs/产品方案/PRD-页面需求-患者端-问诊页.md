## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 在线问诊 |
| 页面路径 | /consultation（医生列表）/consultation/doctor/:id（医生详情）/consultation/chat/:id（问诊聊天室）/consultation/records（问诊记录） |
| 页面类型 | 功能页 |
| 访问权限 | 需要登录（实名认证后可问诊） |
| 设计目标 | 连接患者与医生，提供便捷的在线问诊服务，支持问诊后购药闭环 |

### 1.2 页面定位

在线问诊是DrugMall患者端的核心医疗服务入口，承担以下职责：
1. **医生发现**：帮助患者快速找到合适的医生，支持多维度筛选
2. **在线沟通**：提供图文问诊、语音问诊等多种沟通方式
3. **病情记录**：记录患者病情描述和医生诊断，便于后续跟踪
4. **处方流转**：支持电子处方开具和处方购药闭环
5. **健康档案**：建立患者问诊历史，形成个人健康档案

## 4. 交互说明

### 4.1 页面加载

| 场景 | 交互说明 |
|------|----------|
| 首次加载 | 显示骨架屏，医生列表渐显 |
| 下拉刷新 | 下拉距离>60px触发刷新，显示刷新动画 |
| 上拉加载 | 列表滑动到底部触发加载更多 |
| 筛选切换 | 筛选条件变化时列表重新加载 |

### 4.2 搜索交互

| 操作 | 交互说明 |
|------|----------|
| 聚焦搜索框 | 搜索框获得焦点，展开为全屏搜索页面 |
| 输入关键词 | 实时搜索，显示匹配结果列表，延迟300ms防抖 |
| 点击结果 | 跳转到医生详情页或医生列表页 |
| 清空输入 | 点击清除按钮清空输入内容 |

### 4.3 问诊流程

| 步骤 | 交互说明 |
|------|----------|
| 1.选择医生 | 在医生列表页点击医生卡片或"立即问诊"按钮 |
| 2.填写病情 | 进入病情描述页，填写主诉、病史等信息 |
| 3.上传资料 | 上传检查报告、症状图片等资料（可选） |
| 4.确认支付 | 确认问诊费用，选择支付方式完成支付 |
| 5.开始问诊 | 进入聊天室，等待医生接诊 |
| 6.在线沟通 | 与医生进行图文/语音沟通 |
| 7.接收处方 | 医生开具处方后，查看处方详情 |
| 8.结束问诊 | 问诊结束，可选择购药或结束服务 |

### 4.4 聊天交互

| 操作 | 交互说明 |
|------|----------|
| 发送消息 | 输入文字后点击发送或回车发送 |
| 发送图片 | 点击附件按钮选择图片或拍照发送 |
| 发送语音 | 长按语音按钮录制语音，松开发送 |
| 查看处方 | 点击处方卡片查看处方详情 |
| 购买药品 | 点击药品推荐卡片加入购物车 |
| 结束问诊 | 点击结束按钮确认结束问诊 |

## 5. 页面状态

### 5.1 正常状态

页面正常显示所有内容，医生列表加载完成，交互正常。

### 5.2 加载状态

| 场景 | 表现形式 |
|------|----------|
| 首次加载 | 显示骨架屏，按区块渐显 |

| 场景 | 表现形式 |
|------|----------|
| 搜索无结果 | 显示"未找到相关医生"，推荐相似医生 |
| 筛选无结果 | 显示"该筛选条件下暂无医生" |

|------|----------|

| 支付失败 | 提示"支付失败"，提供重新支付入口 |
