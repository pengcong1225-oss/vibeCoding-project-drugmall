## 1. 页面概述

### 1.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 患者端首页 |
| 页面路径 | /home 或 / |
| 页面类型 | 首页/门户页 |
| 访问权限 | 无需登录，游客可浏览部分功能 |
| 设计目标 | 为患者提供便捷的药品购买入口，展示核心功能和推荐内容 |

### 1.2 页面定位

患者端首页是DrugMall平台患者用户的核心入口页面，承担以下核心职责：
1. **流量分发中心**：引导用户到搜索、分类、购物车等核心功能
2. **内容展示窗口**：展示Banner活动、热门药品、附近药店等
3. **快捷功能入口**：提供问诊、处方、订单等快捷入口
4. **个性化推荐**：基于用户位置和行为推荐相关内容

## 5. 页面状态

### 5.1 正常状态

页面正常显示所有内容，各区块数据加载完成，交互正常。

### 5.2 加载状态

| 场景 | 表现形式 |
|------|----------|
| 首次加载 | 显示骨架屏，按区块渐显 |
| 下拉刷新 | 顶部显示刷新动画，旋转箭头+"松开立即刷新"/"正在刷新..." |
| 上拉加载 | 底部显示加载动画，旋转圆圈+"正在加载更多..." |
| 图片加载 | 图片区域显示灰色占位图，加载完成后渐显 |

### 5.3 空状态

| 场景 | 表现形式 |
|------|----------|
| 无定位权限 | 显示"请开启定位权限，发现附近药店"，提供手动选择城市入口 |
| 附近无药店 | 显示"附近暂无合作药店"，推荐最近药店或配送服务 |
| 搜索无结果 | 显示"未找到相关药品"，推荐相似药品或提供缺货登记 |
| 网络错误 | 显示"网络连接失败"，提供重试按钮 |

### 5.4 错误状态

| 场景 | 表现形式 |
|------|----------|
| 定位失败 | 提示"定位失败，请手动选择城市"，自动弹出城市选择器 |
| 加载失败 | 提示"加载失败，请稍后重试"，显示重试按钮 |
| 服务异常 | 提示"服务繁忙，请稍后重试"，提供客服联系方式 |

## 8. 性能要求

### 8.1 加载性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首屏加载时间 | ≤1.5秒 | 首屏内容完全渲染 |
| 可交互时间 | ≤2秒 | 用户可以开始交互 |
| 完全加载时间 | ≤3秒 | 所有资源加载完成 |

### 8.2 渲染性能

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 滚动帧率 | ≥60fps | 流畅滚动无卡顿 |
| 动画帧率 | ≥60fps | 动画流畅 |
| 内存占用 | ≤100MB | 避免OOM |

### 8.3 网络优化

| 优化项 | 说明 |
|--------|------|
| 图片懒加载 | 图片进入视口前不加载 |
| 图片压缩 | 使用WebP格式，质量80% |
| 数据缓存 | API响应缓存，减少重复请求 |
| CDN加速 | 静态资源使用CDN分发 |
| 预加载 | 预加载下一页可能用到的资源 |
