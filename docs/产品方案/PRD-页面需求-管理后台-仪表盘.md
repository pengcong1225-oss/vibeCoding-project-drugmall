## 2. 页面概述

### 2.1 页面定位

管理后台-仪表盘是DrugMall药品电商平台运营管理的核心入口页面，面向平台管理员、运营人员、财务人员等不同角色，提供全局业务数据可视化展示、实时监控、快捷操作等功能，是日常运营决策的重要支撑工具。

### 2.2 目标用户

| 用户角色 | 使用场景 | 关注重点 |
|----------|----------|----------|
| 超级管理员 | 全局监控、战略决策 | 全部核心指标、系统健康度 |
| 运营经理 | 业务运营分析、活动效果评估 | GMV、订单量、用户增长、商品销售 |
| 运营专员 | 日常运营监控、问题处理 | 待办事项、实时监控、快捷操作 |
| 财务人员 | 财务对账、收入分析 | 交易金额、退款数据、对账报表 |
| 客服人员 | 客服工作监控、问题响应 | 咨询量、投诉处理、用户反馈 |

### 2.3 设计目标

1. **信息聚合**：在一个页面内展示核心业务数据，减少页面切换
2. **实时监控**：关键业务数据实时更新，及时发现问题
3. **决策支持**：通过数据可视化辅助运营决策
4. **效率提升**：提供快捷操作入口，简化日常工作流程
5. **权限适配**：根据用户角色展示对应的数据和功能

### 2.4 页面特性

| 特性 | 说明 |
|------|------|
| 响应式布局 | 支持1920px、1440px、1366px等常见分辨率自适应 |
| 数据实时性 | 实时数据5秒刷新，准实时数据1分钟刷新 |
| 交互丰富性 | 支持图表联动、数据钻取、筛选切换等交互 |
| 可配置性 | 支持看板布局自定义、指标自定义显示/隐藏 |
| 权限控制 | 基于RBAC模型的数据权限和功能权限控制 |

   ├── 请求用户信息和权限

   ├── 渲染KPI卡片区

## 7. 状态说明

### 7.1 页面状态定义

| 状态名称 | 状态说明 | 视觉表现 |
|----------|----------|----------|
| 初始加载中 | 页面首次加载，所有数据请求中 | 显示全局Loading动画(骨架屏或Spin) |
| 部分加载中 | 部分数据已返回，部分仍在加载 | 已加载数据显示，未加载区域显示局部Loading |
| 加载完成 | 所有数据加载完毕 | 显示完整页面内容，所有交互可用 |
| 数据刷新中 | 定时刷新或手动刷新时 | 显示轻微Loading指示(顶部进度条或组件Spin) |
| 加载失败 | 数据请求失败 | 显示错误占位图，提供重试按钮 |
| 空数据状态 | 数据返回成功但内容为空 | 显示空状态插画和引导文字 |
| 离线状态 | 网络连接断开 | 显示离线提示条，部分功能不可用 |

| 数据更新失败 | ✕ 错误标识 | 灰色文字+重试按钮 |
