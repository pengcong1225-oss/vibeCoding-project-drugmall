## 3. 文档概述

### 3.1 文档目的

本文档描述了 DrugMall 药品电商平台管理后台中「处方管理页」的产品需求，包括页面功能、交互逻辑、数据要求等，为 UI 设计和前后端开发提供详细的需求依据。

### 3.2 目标读者

- **产品经理**：了解功能需求和验收标准
- **UI/UX 设计师**：设计界面和交互流程
- **前端开发工程师**：实现页面功能
- **后端开发工程师**：提供数据接口
- **测试工程师**：编写测试用例

### 3.3 术语定义

| 术语 | 定义 |
|------|------|
| 处方 | 由执业医师开具的、包含药品信息和用药指导的医疗文书 |
| 电子处方 | 通过数字化方式开具和流转的处方 |
| 复诊处方 | 患者在复诊时开具的延续性处方 |
| 处方审核 | 药师对处方进行合理性审核的过程 |
| 处方状态 | 处方在流转过程中所处的阶段状态 |

## 4. 业务背景

### 4.1 业务场景

处方管理页是 DrugMall 药品电商平台管理后台的核心功能模块之一，主要面向平台药师和运营管理人员，用于对平台上所有处方进行统一管理、审核和跟踪。

### 4.2 业务目标

1. 实现处方全流程可视化管理
2. 提高处方审核效率和准确性
3. 确保处方合规性和用药安全性
4. 支持处方数据的多维度统计分析

### 4.3 用户角色

| 角色 | 权限范围 | 操作功能 |
|------|----------|----------|
| 药师 | 处方审核 | 查看处方、审核处方、驳回处方 |
| 运营 | 处方查询 | 查看处方、导出处方、打印处方 |
| 管理员 | 全部权限 | 全部操作 + 删除处方、编辑处方 |

## 6. 功能需求详细说明

### 6.1 页面头部

| 元素 | 类型 | 说明 |
|------|------|------|
| 面包屑 | 导航 | 首页 / 处方管理 / 处方列表，可点击返回上级 |
| 页面标题 | 文本 | 处方管理 |
| 页面描述 | 文本 | 管理系统所有处方信息，支持审核、查询、导出等功能 |

### 6.2 快捷数据卡片区

#### 6.2.1 卡片布局

| 卡片 | 名称 | 说明 |
|------|------|------|
| 卡片1 | 待审核处方 | 显示当前待审核的处方数量，点击可筛选待审核处方 |
| 卡片2 | 今日新开具 | 显示今日新开具的处方数量 |
| 卡片3 | 审核通过率 | 显示近30天处方审核通过率 |
| 卡片4 | 即将过期 | 显示7天内即将过期的处方数量，点击可筛选即将过期处方 |

#### 6.2.2 卡片交互

- **悬停效果**：鼠标悬停时卡片阴影加深，轻微上浮
- **点击交互**：点击卡片自动应用对应筛选条件
- **红点提示**：待审核处方数大于0时显示红点数字角标

#### 6.2.3 数据计算规则

| 指标 | 计算规则 |
|------|----------|
| 待审核处方数 | 状态为"待审核"且未删除的处方数量 |
| 今日新开具数 | 开具时间在今日00:00-23:59之间的处方数量 |
| 审核通过率 | 近30天(审核通过数)/(审核通过数+审核拒绝数)*100% |
| 即将过期数 | 有效期在7天内且状态不为"已使用"的处方数量 |

### 6.3 筛选区

#### 6.3.1 搜索框

| 属性 | 说明 |
|------|------|
| 占位符 | 搜索处方单号/患者姓名/医生姓名 |
| 输入限制 | 最多50个字符 |
| 搜索方式 | 输入后按Enter或点击搜索按钮触发 |
| 模糊搜索 | 支持模糊匹配，不区分大小写 |

#### 6.3.2 筛选条件

| 筛选项 | 类型 | 选项 | 默认值 |
|--------|------|------|--------|
| 处方状态 | 下拉多选 | 草稿/待审核/审核通过/审核拒绝/已失效/已使用/全部 | 全部 |
| 处方类型 | 下拉多选 | 电子处方/复诊处方/纸质处方/全部 | 全部 |
| 医生 | 搜索选择 | 可搜索选择具体医生 | 全部 |
| 患者 | 搜索选择 | 可搜索选择具体患者 | 全部 |
| 开具时间 | 日期范围 | 开始日期-结束日期 | 近30天 |
| 过期时间 | 下拉选择 | 全部/即将过期(7天内)/已过期 | 全部 |

#### 6.3.3 筛选交互

- **即时筛选**：选择筛选条件后自动触发列表刷新
- **重置按钮**：点击重置按钮清空所有筛选条件，恢复默认值
- **条件展示**：已选择的筛选条件以标签形式展示，可单独删除

### 6.4 操作按钮区

| 按钮 | 功能 | 权限 | 说明 |
|------|------|------|------|
| 批量通过 | 批量审核通过 | 药师/管理员 | 选中处方后批量标记为审核通过 |
| 批量拒绝 | 批量审核拒绝 | 药师/管理员 | 选中处方后批量标记为审核拒绝 |
| 导出 | 导出处方数据 | 运营/管理员 | 导出当前列表数据为Excel/CSV |
| 打印 | 打印处方 | 全部 | 打印选中处方或当前列表 |

### 6.5 处方列表表格

#### 6.5.1 表格列定义

| 列名 | 字段 | 类型 | 宽度 | 说明 |
|------|------|------|------|------|
| 复选框 | checkbox | 选择框 | 50px | 可多选行 |
| 处方单号 | prescriptionNo | 链接文本 | 140px | 点击打开详情弹窗 |
| 状态 | status | 标签 | 100px | 带颜色状态标签 |
| 类型 | type | 标签 | 90px | 处方类型标签 |
| 患者信息 | patient | 文本 | 120px | 姓名/性别/年龄 |
| 医生信息 | doctor | 文本 | 120px | 医生姓名/医院 |
| 诊断结果 | diagnosis | 文本 | 150px | 截断显示，悬停展示完整 |
| 处方金额 | amount | 金额 | 100px | 右对齐，保留两位小数 |
| 开具时间 | createTime | 时间 | 150px | 格式：YYYY-MM-DD HH:mm |
| 有效期至 | validTo | 日期 | 100px | 过期时标红提示 |
| 关联订单 | orderNo | 链接 | 120px | 关联订单号，可跳转 |
| 操作 | operation | 按钮组 | 180px | 查看/审核/编辑/删除 |

#### 6.5.2 状态标签颜色定义

| 状态 | 颜色 | 背景色 | 说明 |
|------|------|--------|------|
| 草稿 | 灰色 | #909399 | 处方草稿状态 |
| 待审核 | 橙色 | #E6A23C | 等待药师审核 |
| 审核通过 | 绿色 | #67C23A | 审核通过，可购药 |
| 审核拒绝 | 红色 | #F56C6C | 审核不通过 |
| 已失效 | 灰色 | #C0C4CC | 处方已过期或作废 |
| 已使用 | 蓝色 | #409EFF | 处方已用于购药 |

#### 6.5.3 表格交互

- **排序**：点击表头支持按该列排序（开具时间、金额等）
- **列宽调整**：可拖拽列边框调整列宽
- **列显示**：可配置显示/隐藏某些列
- **行点击**：点击整行可打开详情弹窗
- **右键菜单**：右键行显示快捷操作菜单
- **分页**：底部显示分页器，支持自定义每页条数

#### 6.5.4 空状态

- 无数据时显示空状态插图
- 提示文案："暂无处方数据"
- 提供"重置筛选条件"按钮

## 7. 交互说明

### 7.1 页面加载

1. 页面初始化时自动加载处方列表（默认显示近30天数据）
2. 同时加载快捷数据卡片的统计数据
3. 列表数据加载过程中显示骨架屏或loading动画
4. 加载完成后平滑过渡到真实数据

### 7.2 列表交互

#### 7.2.1 行悬停效果
- 鼠标悬停在行上时，该行背景色变深
- 操作按钮在悬停时才显示（避免视觉干扰）

#### 7.2.2 行点击
- 点击整行可打开处方详情弹窗
- 点击操作列的按钮执行对应操作

#### 7.2.3 复选框
- 表头复选框可全选/取消全选当前页
- 行复选框可多选处方
- 选中数量在批量操作按钮旁显示

#### 7.2.4 排序
- 点击表头可切换排序方向
- 支持排序的列：开具时间、有效期至、处方金额
- 当前排序列显示上下箭头

### 7.3 筛选交互
- 搜索框支持输入关键词后按Enter或点击搜索按钮触发
- 下拉筛选支持多选，选项以标签形式展示在筛选区
- 时间范围选择器支持快捷选择（今日/本周/本月/自定义）
- 点击"重置"按钮清空所有筛选条件并刷新列表

### 7.4 批量操作

1. 选中多条处方记录后，批量操作按钮由禁用变为可用状态
2. 点击批量操作按钮弹出确认对话框
3. 确认后执行批量操作，显示操作进度
4. 操作完成后显示成功/失败提示，并刷新列表

### 7.5 详情弹窗

- 点击处方单号或"查看"按钮打开详情弹窗
- 弹窗宽度为屏幕宽度的80%，最小宽度800px
- 弹窗内容过多时支持滚动
- 支持ESC键关闭弹窗
- 点击遮罩层可关闭弹窗（需二次确认有未保存的审核意见时）

### 7.6 审核操作

1. 对待审核处方点击"审核"按钮
2. 弹出详情弹窗并自动定位到审核操作区
3. 选择审核结果（通过/拒绝）
4. 如选择拒绝，需选择/填写拒绝原因
5. 填写审核意见
6. 进行电子签名
7. 点击提交审核
8. 审核完成后弹窗关闭，列表自动刷新

### 7.7 导出/打印

- 点击"导出"按钮，支持导出当前筛选条件下的全部数据
- 导出格式支持Excel和CSV
- 点击"打印"按钮，打开打印预览页面
- 支持选择打印模板（标准模板/简化模板）

## 8. 状态说明

### 8.1 处方状态流转图

```
                              ┌─────────────┐
                              │   草稿      │
                              │  (Draft)    │
                              └──────┬──────┘
                                     │ 提交审核
                                     ▼
                              ┌─────────────┐
                              │  待审核     │
                              │ (Pending)   │
                              └──────┬──────┘
                    ┌────────────────┼────────────────┐
                    │                │                │
                    ▼                ▼                ▼
            ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
            │  审核通过   │  │  审核拒绝   │  │   已失效    │
            │ (Approved)  │  │ (Rejected)  │  │ (Expired)   │
            └──────┬──────┘  └──────┬──────┘  └──────┬──────┘
                   │                │                │
                   │                │ 重新提交       │
                   ▼                └────────────────┘
            ┌─────────────┐
            │   已使用    │
            │   (Used)    │
            └─────────────┘
```

### 8.2 状态定义

| 状态 | 定义 | 触发条件 | 后续状态 |
|------|------|----------|----------|
| 草稿 | 处方正在编辑，尚未提交审核 | 医生创建处方后保存为草稿 | 待审核 |
| 待审核 | 处方已提交，等待药师审核 | 医生提交处方审核 | 审核通过/审核拒绝/已失效 |
| 审核通过 | 处方已通过药师审核，可用于购药 | 药师审核通过 | 已使用/已失效 |
| 审核拒绝 | 处方未通过审核，需要修改 | 药师审核拒绝 | 待审核（重新提交） |
| 已使用 | 处方已用于购买药品 | 用户凭处方成功下单 | - |
| 已失效 | 处方已过期或被作废 | 超过有效期/医生或药师作废 | - |

## 11. 非功能需求

### 11.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 列表加载时间 | <= 2秒 | 每页20条数据的列表加载时间 |
| 详情加载时间 | <= 1秒 | 处方详情弹窗加载时间 |
| 审核提交时间 | <= 3秒 | 审核操作提交响应时间 |
| 导出响应时间 | <= 5秒 | 1000条以内数据导出时间 |
| 并发支持 | 100+ | 支持100+用户同时使用 |

### 11.2 安全要求

1. **数据脱敏**：患者身份证号、手机号等敏感信息脱敏显示
2. **权限控制**：严格按照角色权限控制操作权限
3. **操作审计**：所有审核操作记录操作日志
4. **数据加密**：敏感数据传输使用HTTPS加密
5. **电子签名**：审核通过需要药师电子签名

### 11.3 兼容性要求

1. **浏览器兼容**：支持Chrome 80+、Firefox 75+、Edge 80+、Safari 13+
2. **分辨率适配**：支持1366x768及以上分辨率
3. **响应式适配**：支持窗口大小调整时自适应布局

### 11.4 可用性要求

1. **界面语言**：中文界面
2. **时间显示**：使用北京时间（东八区）
3. **数字格式**：金额保留两位小数，千分位分隔
4. **日期格式**：YYYY-MM-DD HH:mm:ss
5. **错误提示**：操作失败时给出明确的错误提示
