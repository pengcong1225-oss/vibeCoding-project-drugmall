## 2. 页面概述

### 2.1 页面定位

管理后台-数据统计页是DrugMall药品电商平台的深度数据分析中心，面向平台管理员、运营经理、数据分析师、财务人员等不同角色，提供全方位、多维度的业务数据报表、趋势分析、对比分析和数据导出功能，是精细化运营决策和战略规划的核心数据支撑工具。

### 2.2 目标用户

| 用户角色 | 使用场景 | 关注重点 |
|----------|----------|----------|
| 超级管理员 | 全局数据分析、战略决策支持 | 全平台数据概览、核心指标趋势 |
| 运营经理 | 业务运营分析、活动策划评估 | GMV、转化率、用户增长、商品销售 |
| 数据分析师 | 深度数据挖掘、专项分析报告 | 多维度交叉分析、自定义报表 |
| 财务人员 | 收入对账、财务分析 | 交易流水、退款分析、结算报表 |
| 客服主管 | 服务质量分析、问题趋势 | 咨询量、投诉分析、响应时间 |

### 2.3 设计目标

1. **数据全面性**：覆盖销售、订单、用户、商品、医生、财务六大核心维度
2. **分析深度**：支持多维度交叉分析、同比环比对比、趋势预测
3. **操作便捷**：灵活的筛选条件、自定义报表、一键导出
4. **实时性强**：关键指标准实时更新，支持实时监控
5. **可视化优**：丰富的图表类型，直观展示数据洞察

### 2.4 页面特性

| 特性 | 说明 |
|------|------|
| 多维度分析 | 支持时间、门店、品类、渠道等多维度交叉分析 |
| 灵活筛选 | 丰富的筛选条件，支持自定义组合 |
| 实时数据 | 核心指标准实时更新(1-5分钟) |
| 图表丰富 | 折线、柱状、饼图、漏斗、热力图等多种图表 |
| 数据导出 | 支持Excel、PDF、CSV等多种格式导出 |
| 报表订阅 | 支持定时报表推送(邮件) |
| 权限控制 | 基于角色的数据权限和功能权限控制 |

## 5. 交互说明

### 5.1 页面加载流程

```
1. 页面初始化
   ├── 加载页面框架布局
   ├── 初始化顶部导航和左侧菜单
   ├── 解析URL参数(如指定Tab、筛选条件)
   └── 显示内容区loading状态

2. 数据加载阶段(并行)
   ├── 请求当前Tab的指标卡数据
   ├── 请求图表数据
   ├── 请求表格数据(第一页)
   └── 请求筛选条件下拉选项数据

3. 页面渲染阶段
   ├── 渲染指标卡片(数字动画)
   ├── 渲染趋势图表
   ├── 渲染分布图表(如有)
   ├── 渲染数据明细表格
   ├── 渲染分页组件
   └── 隐藏loading，显示完整页面

4. 定时刷新启动
   ├── 启动指标卡定时器(60秒)
   └── 启动图表数据定时器(5分钟)
```

### 5.2 核心交互流程

#### 5.2.1 Tab切换交互

| 交互场景 | 交互说明 |
|----------|----------|
| Tab点击 | 点击Tab切换内容，当前Tab底部显示蓝色下划线 |
| 切换动画 | 内容区淡入淡出过渡(200ms) |
| 数据加载 | 切换后加载对应Tab的数据，显示局部loading |
| 状态保持 | 返回已访问Tab时恢复之前的筛选条件和滚动位置 |
| URL同步 | Tab切换同步更新URL参数，支持刷新后保持当前Tab |

#### 5.2.2 筛选交互

| 交互场景 | 交互说明 |
|----------|----------|
| 条件变更 | 任何筛选条件变更后，防抖300ms后自动触发数据刷新 |
| 筛选加载 | 显示局部loading，图表和表格数据平滑过渡更新 |
| 重置筛选 | 点击「重置」按钮，一键恢复默认筛选条件并刷新 |
| 条件记忆 | 记住用户的筛选偏好，下次访问时自动应用 |
| URL同步 | 筛选条件同步到URL参数，支持分享和收藏 |

#### 5.2.3 图表交互

| 导出操作 | 点击导出按钮，选择导出图片或数据 |

#### 5.2.4 表格交互

### 5.3 错误处理与异常场景

| 异常场景 | 处理方案 |
|----------|----------|
| 数据加载失败 | 显示「数据加载失败」占位图，提供「重新加载」按钮 |
| 网络中断 | 检测网络状态，离线时显示「网络异常」提示，恢复后自动刷新 |
| 权限不足 | 尝试访问无权限数据时，显示「暂无权限」提示，引导申请权限 |
| 数据为空 | 显示「暂无数据」占位图，根据场景提供引导操作 |
| 服务器错误 | 显示「服务暂不可用」提示，记录错误日志，自动重试机制 |
| 超时处理 | 数据请求超过10秒未返回，显示「加载超时」并提供重试 |
| 部分数据失败 | 多接口并行请求时，部分失败不影响整体，失败模块显示重试按钮 |
| 大数据量卡顿 | 数据量过大时自动启用分页或采样，提示用户缩小筛选范围 |

## 6. 状态说明

### 6.1 页面状态定义

| 状态名称 | 状态说明 | 视觉表现 |
|----------|----------|----------|
| 初始加载中 | 页面首次加载，所有数据请求中 | 显示全局Loading动画(骨架屏或Spin) |
| 部分加载中 | 部分数据已返回，部分仍在加载 | 已加载数据显示，未加载区域显示局部Loading |
| 加载完成 | 所有数据加载完成 | 显示完整页面内容，所有交互可用 |
| 数据刷新中 | 定时刷新或手动刷新时 | 显示轻微Loading指示(顶部进度条或组件Spin) |
| 加载失败 | 数据请求失败 | 显示错误占位图，提供重试按钮 |
| 空数据状态 | 数据返回成功但内容为空 | 显示空状态插画和引导文字 |
| 离线状态 | 网络连接断开 | 显示离线提示条，部分功能不可用 |
| 筛选中 | 用户正在调整筛选条件 | 筛选区高亮，准备刷新数据 |
| 导出中 | 数据导出进行中 | 显示导出进度条，支持取消 |

### 6.2 数据状态标识

| 状态场景 | 状态标识 | 视觉样式 |
|----------|----------|----------|
| 数据正常 | 无特殊标识 | 正常显示 |
| 数据上升(环比) | ↑ + 百分比 | 绿色文字(#52c41a) |
| 数据下降(环比) | ↓ + 百分比 | 红色文字(#ff4d4f) |
| 数据持平 | - | 灰色文字(#8c8c8c) |
| 数据异常(过高/过低) | ⚠️ 警告标识 | 橙色/红色高亮 |
| 数据计算中 | Loading小图标 | 灰色转圈动画 |
| 数据更新失败 | ❌ 错误标识 | 灰色文字+重试按钮 |
| 数据预览(未确认) | 👁️ 预览标识 | 浅灰色文字提示 |

### 6.3 实时数据状态

| 数据类型 | 更新频率 | 状态指示 |
|----------|----------|----------|
| 核心指标卡数据 | 60秒 | 数据更新时轻微闪烁提示 |
| 趋势图表数据 | 5分钟 | 刷新时平滑过渡动画 |
| 实时在线数据 | 不展示本页面 | - |
| 表格数据 | 手动刷新或切换分页 | 加载时显示局部loading |
| 导出任务状态 | 实时轮询 | 进度条实时更新 |
| 筛选条件下拉选项 | 页面加载时 | 缓存，支持手动刷新 |

## 9. 性能要求

### 9.1 加载性能

| 指标项 | 目标值 | 说明 |
|--------|--------|------|
| 首屏加载时间 | ≤3秒 | 从进入页面到首屏内容渲染完成 |
| 指标卡数据加载 | ≤0.5秒 | 筛选条件变更后指标卡数据更新 |
| 图表数据加载 | ≤2秒 | 筛选条件变更后图表数据更新 |
| 表格数据加载 | ≤0.5秒 | 分页/排序/筛选后表格数据更新 |
| 导出任务创建 | ≤1秒 | 点击导出到任务创建完成 |

### 9.2 运行时性能

| 指标项 | 目标值 | 说明 |
|--------|--------|------|
| 页面流畅度 | ≥55fps | 页面滚动、动画流畅无卡顿 |
| 图表交互响应 | ≤100ms | hover、点击等交互的响应时间 |
| 内存占用 | ≤200MB | 页面长期运行内存占用 |
| 定时刷新性能 | 无感知 | 后台数据刷新不影响用户操作 |

### 9.3 数据性能

| 指标项 | 目标值 | 说明 |
|--------|--------|------|
| 单次查询数据量 | ≤50万条 | 单次查询返回数据量上限 |
| 聚合查询响应 | ≤3秒 | 复杂聚合统计查询响应时间 |
| 导出数据上限 | 100万条 | 单次导出数据量上限 |
| 历史数据查询 | ≤5秒 | 查询1年以上历史数据响应时间 |
