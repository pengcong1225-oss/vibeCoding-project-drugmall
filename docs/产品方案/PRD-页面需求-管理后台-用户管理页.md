## 4. 页面概述

### 4.1 页面定位

用户管理页是DrugMall管理后台的核心功能页面之一，为平台运营人员提供完整的用户管理能力，包括用户信息查看、编辑、实名认证审核、状态管理等功能。

### 4.2 页面价值

1. **运营效率**：集中管理所有用户信息，提升运营效率
2. **合规保障**：严格的实名认证审核流程，确保平台合规运营
3. **用户体验**：及时处理用户问题，提升用户满意度
4. **数据洞察**：通过用户数据分析，支持业务决策

### 4.3 页面入口

- 主入口：管理后台左侧菜单栏 -> "用户管理" -> "用户列表"
- 快捷入口：
  - 仪表盘快捷操作区
  - 其他页面用户ID/用户名链接跳转

### 4.4 权限要求

| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 所有操作权限 |
| 运营管理员 | 用户查看、编辑、认证审核（不能删除） |
| 客服专员 | 用户查看、编辑（不能审核、删除） |
| 数据分析师 | 仅查看权限（不能编辑、删除） |

## 6. 页面详细需求

### 6.1 页面布局

#### 6.1.1 整体布局

| 属性 | 描述 |
|------|------|
| 布局模式 | 左右分栏布局 |
| 左侧菜单 | 固定宽度 220px，与仪表盘一致 |
| 右侧主内容区 | 自适应宽度，最小宽度 800px |
| 顶部面包屑 | 高度 48px，固定在主内容区顶部 |
| 内容区域 | 高度自适应，超出可滚动 |
| 底部版权信息 | 固定在页面底部，高度 40px |

#### 6.1.2 响应式适配

| 断点 | 布局调整 |
|------|----------|
| >= 1200px | 标准布局，左侧菜单 220px |
| 992px - 1199px | 左侧菜单 180px |
| < 992px | 左侧菜单收起为图标模式，点击展开抽屉 |

### 6.2 筛选区

#### 6.2.1 组件说明

| 组件 | 类型 | 功能说明 |
|------|------|----------|
| 搜索框 | Input | 支持手机号/用户名/真实姓名模糊搜索 |
| 用户类型 | Select | 普通用户/会员用户筛选 |
| 认证状态 | Select | 未认证/认证中/已认证/认证失败筛选 |
| 注册时间 | DateRange | 支持选择注册时间范围 |
| 查询按钮 | Button | 触发筛选查询 |
| 重置按钮 | Button | 清空所有筛选条件 |

#### 6.2.2 交互规则

| 交互场景 | 行为描述 |
|----------|----------|
| 搜索框输入 | 支持实时搜索（防抖300ms），输入时显示loading |
| 筛选条件变化 | 自动触发查询（防抖500ms） |
| 点击查询 | 显示loading，查询完成后更新列表 |
| 点击重置 | 清空所有条件，恢复默认查询 |
| 快捷键支持 | Enter触发查询，ESC重置条件 |

#### 6.2.3 数据规则

| 字段 | 规则 |
|------|------|
| 搜索框 | 支持手机号(11位数字)/用户名(2-20字符)/真实姓名(2-10字符) |
| 用户类型 | 1-普通用户, 2-会员用户, 0-全部 |
| 认证状态 | 0-未认证, 1-认证中, 2-已认证, 3-认证失败, -1-全部 |
| 注册时间 | 支持今天、近7天、近30天、自定义范围 |

### 6.3 操作按钮区

#### 6.3.1 组件说明

| 组件 | 类型 | 功能说明 | 权限要求 |
|------|------|----------|----------|
| 新增用户 | Primary Button | 打开新增用户弹窗 | 超级管理员、运营管理员 |
| 批量导出 | Default Button | 导出选中/当前筛选结果 | 所有角色 |
| 批量认证通过 | Success Button | 批量通过实名认证 | 超级管理员、运营管理员 |
| 批量认证拒绝 | Danger Button | 批量拒绝实名认证 | 超级管理员、运营管理员 |

#### 6.3.2 交互规则

| 交互场景 | 行为描述 |
|----------|----------|
| 新增用户 | 点击打开新增用户弹窗，表单验证通过后提交 |
| 批量导出 | 如有选中则导出选中，否则导出当前筛选结果 |
| 批量认证 | 需先选择用户，弹出确认对话框，确认后执行 |
| 按钮禁用 | 当没有选中用户时，批量操作按钮禁用 |

#### 6.4.1 表格结构

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 复选框 | 50px | 居中 | 支持批量选择 |

#### 6.4.2 数据展示规则

| 字段 | 展示规则 |
|------|----------|
| 用户头像 | 60px圆形，默认显示系统默认头像，hover显示用户昵称tooltip |
| 手机号 | 显示格式：138****8888，脱敏中间4位 |
| 真实姓名 | 显示格式：张**，脱敏最后一位 |
| 身份证号 | 显示格式：110101********1234，脱敏中间8位 |
| 认证状态 | 未认证(灰色)/认证中(橙色)/已认证(绿色)/认证失败(红色) |
| 用户类型 | 普通用户(蓝色标签)/会员用户(金色标签) |
| 时间字段 | 显示相对时间(今天/昨天/前天)或绝对时间，tooltip显示完整时间 |
| 空值处理 | 显示"-"或"暂无"，不参与排序 |

#### 6.4.3 排序规则

| 默认排序 | 注册时间倒序（最新注册在前） |
|----------|---------------------------|
| 支持排序字段 | 用户ID、注册时间、最后登录时间 |
| 排序方式 | 单击升序，再单击降序，三击取消 |
| 排序图标 | 升序↑、降序↓、默认- |

#### 6.4.4 行操作规则

| 操作按钮 | 图标 | 权限 | 说明 |
|----------|------|------|------|
| 查看 | <i class="el-icon-view"></i> | 所有角色 | 打开用户详情弹窗 |
| 编辑 | <i class="el-icon-edit"></i> | 超级管理员、运营管理员 | 打开编辑弹窗 |
| 禁用 | <i class="el-icon-lock"></i> | 超级管理员、运营管理员 | 禁用账号（确认后执行） |
| 启用 | <i class="el-icon-unlock"></i> | 超级管理员、运营管理员 | 启用账号（确认后执行） |
| 删除 | <i class="el-icon-delete"></i> | 仅超级管理员 | 软删除（确认后执行） |

#### 6.4.5 批量操作规则

| 批量操作 | 触发条件 | 执行流程 | 权限要求 |
|----------|----------|----------|----------|
| 批量导出 | 选择用户或全部 | 导出选中用户数据为Excel | 所有角色 |
| 批量认证通过 | 选择认证中用户 | 确认对话框 -> 批量通过 | 超级管理员、运营管理员 |
| 批量认证拒绝 | 选择认证中用户 | 确认对话框 -> 批量拒绝 | 超级管理员、运营管理员 |
| 批量禁用 | 选择正常用户 | 确认对话框 -> 批量禁用 | 超级管理员、运营管理员 |

#### 6.8.3 审核流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 查看材料 | 仔细查看身份证正反面照片和人脸识别照片 |
| 2 | 核对信息 | 核对OCR识别的身份信息是否准确 |
| 3 | 选择结果 | 选择通过或拒绝 |
| 4 | 填写原因 | 拒绝时必填拒绝原因，可选择预设原因或自定义 |

| 选项 | 说明 |

| 人脸识别不匹配 | 人脸识别照片与身份证照片不符 |

| 身份证信息被冒用 | 怀疑身份信息被冒用 |
