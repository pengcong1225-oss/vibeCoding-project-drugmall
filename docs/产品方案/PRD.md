## 文档使用说明

### 如何阅读本文档

1. **初次了解项目**：先阅读 [PRD-产品概述](./PRD-产品概述.md) 了解项目背景、目标用户和核心价值
2. **了解功能范围**：查看 [PRD-功能需求](./PRD-功能需求.md) 和 [PRD-V1.0版本范围](./PRD-V1.0版本范围.md)
3. **理解业务流程**：阅读 [PRD-流程设计](./PRD-流程设计.md) 掌握核心业务流程
4. **查看界面设计**：参考 [PRD-页面需求](./PRD-页面需求.md) 了解页面布局和交互
5. **技术实现参考**：查看 [PRD-数据需求](./PRD-数据需求.md) 和 [PRD-非功能需求](./PRD-非功能需求.md)

### 文档更新规范

根据《AGENTS.md》产品文档输出规则：

1. **分模块更新**：当单个模块内容超过500行时，应拆分为更细粒度的子模块
2. **版本控制**：每次更新需更新文档版本号和修改日期
3. **变更记录**：在文档末尾添加变更记录，说明本次修改内容
4. **交叉引用**：模块之间通过链接引用，避免内容重复
