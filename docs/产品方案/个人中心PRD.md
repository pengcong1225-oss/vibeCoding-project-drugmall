## 1. 文档概述

### 1.1 文档目的
本文档详细描述DrugMall患者端个人中心页面的产品需求，包括页面结构、功能模块、交互逻辑、数据需求和业务规则，为UI设计、前端开发、后端开发及测试提供明确的需求依据。

### 1.2 适用范围
本文档适用于：
- UI/UX设计师：页面视觉设计和交互设计
- 前端开发工程师：页面功能实现
- 后端开发工程师：接口设计和数据支持
- 测试工程师：测试用例编写和功能验证
- 产品经理：需求确认和迭代管理

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 健康卡 | 平台推出的付费会员服务，购药享受专属优惠 |
| 红包 | 平台发放的优惠券或现金抵扣券 |
| 处方 | 医生开具的电子处方，用于购买处方药 |
| 问诊 | 用户与医生在线交流的医疗咨询服务 |

## 2. 页面概述

### 2.1 页面基本信息

| 项目 | 内容 |
|------|------|
| 页面名称 | 个人中心 |
| 页面路径 | /user/profile |
| 页面类型 | 功能聚合、导航页 |
| 访问权限 | 需要登录 |
| 设计目标 | 整合用户资产、订单和服务功能，提供便捷的个人账户管理中心 |

### 2.2 页面定位

个人中心是DrugMall患者端的核心入口页面，承担以下职责：
1. **用户身份展示**：展示用户头像、问候语、用户ID等身份信息
2. **会员权益推广**：推广健康卡会员服务，展示会员专属权益
3. **营销活动入口**：聚合平台营销活动，提升用户参与度
4. **资产信息聚合**：整合红包、优惠券、会员卡等资产数据
5. **订单快捷入口**：提供购物车、全部订单、退款/售后的快速跳转
6. **健康服务导航**：聚合家庭健康档案、处方病历、问诊咨询等医药特色服务

### 2.3 用户场景

| 场景 | 用户需求 | 页面支持 |
|------|----------|----------|
| 查看账户信息 | 了解个人基本信息和会员状态 | 用户信息区展示头像、ID、问候语 |
| 管理订单 | 快速查看和处理各类订单 | 快捷入口提供订单相关功能 |
| 使用优惠券 | 查看和使用红包/优惠券 | 资产统计展示优惠券数量 |
| 健康服务 | 管理健康档案和处方 | 健康服务区提供相关功能入口 |
| 会员服务 | 了解和使用会员权益 | 健康卡推广区展示会员权益 |

## 4. 模块详细说明

### 4.1 顶部导航栏

#### 4.1.1 功能说明
提供页面导航和功能入口，包括返回、消息通知、设置等功能。

#### 4.1.2 包含元素

| 元素名称 | 元素类型 | 位置 | 说明 |
|----------|----------|------|------|
| 返回按钮 | IconButton | 左侧 | 点击返回上一页 |
| 消息入口 | IconButton | 右侧 | 显示未读消息数量角标，点击进入消息中心 |
| 设置入口 | IconButton | 最右侧 | 点击进入设置页面 |

#### 4.1.3 交互逻辑

| 交互 | 说明 |
|------|------|
| 点击返回按钮 | 返回上一页，使用浏览器/APP返回逻辑 |
| 点击消息 | 跳转到消息中心页面 (/user/messages) |
| 点击设置 | 跳转到设置页面 (/user/settings) |

#### 4.1.4 数据需求

| 数据项 | 数据类型 | 数据来源 | 说明 |
|--------|----------|----------|------|
| 未读消息数 | Integer | /api/user/messages/unread-count | 实时获取，为0时不显示角标 |

#### 4.1.5 角标显示规则

| 数量范围 | 显示方式 |
|----------|----------|
| 0 | 不显示角标 |
| 1-99 | 显示红色圆形角标，内含具体数字 |
| 99+ | 显示红色圆形角标，内含"99+" |

### 4.2 用户信息区

#### 4.2.1 功能说明
展示用户基本信息，包括头像、动态问候语和用户ID。

#### 4.2.2 包含元素

| 元素名称 | 元素类型 | 说明 |
|----------|----------|------|
| 用户头像 | Image | 圆形头像，点击可进入个人资料页 |
| 问候语 | Text | 根据当前时间动态显示"上午好!/下午好!/晚上好!" |
| 用户ID | Text | 显示用户唯一标识，如"MBI808642777" |

#### 4.2.3 交互逻辑

| 交互 | 说明 |
|------|------|
| 点击头像 | 跳转到个人资料编辑页 (/user/profile/edit) |
| 长按ID | 支持复制用户ID到剪贴板 |

#### 4.2.4 数据需求

| 数据项 | 数据类型 | 数据来源 | 说明 |
|--------|----------|----------|------|
| 用户头像 | String(URL) | /api/user/info | 用户头像URL，未设置显示默认头像 |
| 用户ID | String | /api/user/info | 用户唯一标识 |

#### 4.2.5 问候语规则

| 时间段 | 问候语 | 示例 |
|--------|--------|------|
| 06:00-11:59 | 上午好! | 上午好! |
| 12:00-17:59 | 下午好! | 下午好! |
| 18:00-05:59 | 晚上好! | 晚上好! |

> 注：问候语根据用户设备本地时间动态计算

## 6. 状态说明

### 6.1 页面状态

| 状态 | 说明 | 表现 |
|------|------|------|
| 加载中 | 页面数据正在加载 | 显示骨架屏或加载动画 |

### 6.2 数据状态

| 数据项 | 状态说明 | 展示规则 |
|--------|----------|----------|
| 消息角标 | 根据未读消息数 | 为零不显示，大于零显示数字角标 |
| 会员状态 | 根据用户会员状态 | 未开通显示"去开通"，已开通显示"查看权益" |
| 资产数据 | 实时查询 | 为零时显示默认值，不为零时显示具体数值 |

## 9. 异常处理

### 9.1 网络异常

| 场景 | 处理方式 |
|------|----------|
| 页面加载失败 | 显示网络异常提示，提供"重新加载"按钮 |
| 数据加载失败 | 使用本地缓存数据，提示"数据可能不是最新的" |
| 图片加载失败 | 显示默认占位图 |

### 9.2 数据异常

| 场景 | 处理方式 |
|------|----------|
| 用户未登录 | 跳转登录页，登录成功后返回当前页 |
| 数据为空 | 显示空状态提示，如"暂无优惠券" |
| 数据格式错误 | 记录日志，显示默认数据或错误提示 |
