# DrugMall 在线药品商城产品方案

## 1. 产品概述

### 1.1 产品定位
DrugMall是一个专注于药品零售的B2C在线商城，对标美团看病买药模块，提供便捷、安全、专业的药品购买服务，同时整合健康咨询、医疗服务预约等功能，打造一站式健康服务平台。

### 1.2 目标用户
- **核心用户**：需要购买药品的普通消费者（家庭常备药、慢性病用药等）
- **潜在用户**：需要健康咨询、医疗服务预约的用户
- **特殊用户**：需要购买处方药的患者

### 1.3 核心价值主张
- **便捷性**：线上下单，快速配送（30分钟达）
- **安全性**：正规药店供货，药品来源可追溯
- **专业性**：提供药品咨询、用药指导服务
- **经济性**：支持医保支付，降低购药成本

## 3. 产品功能规划

### 3.1 核心功能模块

#### 3.1.1 药品搜索与浏览
- **关键词搜索**：药品名称、症状、品牌、成分搜索
- **图像识别搜索**：拍照识别药品
- **智能推荐**：基于浏览历史、购买记录推荐
- **药品分类**：OTC、处方药、家庭常备药、慢性病用药等
- **药品详情**：药品说明、成分、用法用量、注意事项、不良反应等

#### 3.1.2 药店服务
- **附近药店**：LBS定位，显示附近药店
- **药店筛选**：按距离、价格、品牌、24小时服务筛选
- **药店详情**：药店资质、营业时间、联系方式

#### 3.1.3 购物车与结算
- **购物车管理**：添加、删除、修改数量
- **库存显示**：实时库存状态
- **价格计算**：药品价格、配送费、优惠后总价
- **支付方式**：
  - 医保支付（个人账户）
  - 在线支付（微信、支付宝、银行卡）
  - 货到付款

#### 3.1.4 订单管理
- **订单创建**：提交订单、选择配送时间
- **订单跟踪**：实时查看配送状态
- **订单历史**：查看历史订单记录
- **订单操作**：取消订单、申请退款、评价

#### 3.1.5 用户中心
- **个人信息**：姓名、身份证、联系方式
- **医保绑定**：医保电子凭证绑定
- **健康档案**：个人健康信息、用药记录
- **收货地址**：地址管理、默认地址设置
- **优惠券**：优惠券领取、使用记录
- **积分管理**：积分获取、兑换记录

#### 3.1.6 医保服务
- **医保专区**：集中展示医保可支付药品
- **医保余额查询**：查看医保个人账户余额
- **医保支付流程**：授权、支付、明细查询

#### 3.1.7 处方药服务
- **电子处方**：上传纸质处方或通过在线问诊获取电子处方
- **处方审核**：执业药师审核处方
- **处方药购买**：凭处方购买处方药

#### 3.1.8 健康咨询
- **在线问诊**：与执业药师、医生在线咨询
- **用药指导**：专业用药建议
- **健康资讯**：疾病预防、健康养生知识

### 3.2 扩展功能模块

#### 3.2.1 会员体系
- **会员等级**：普通会员、银卡会员、金卡会员、钻石会员
- **会员权益**：折扣、免配送费、专属客服、优先配送
- **积分规则**：购物积分、签到积分、分享积分

#### 3.2.2 社区功能
- **用户评论**：药品、服务评价
- **健康问答**：用户提问、专业解答
- **健康分享**：用户健康经验分享

#### 3.2.3 医疗服务预约
- **医生预约**：预约线下门诊
- **体检预约**：预约体检服务
- **疫苗预约**：预约疫苗接种

## 4. 用户流程设计

### 4.1 药品购买流程

1. **搜索药品**：用户通过关键词或图像搜索药品
2. **选择药品**：浏览药品详情，选择规格、数量
3. **加入购物车**：将药品加入购物车
4. **提交订单**：确认收货地址、配送时间
5. **选择支付方式**：选择医保支付或在线支付
6. **完成支付**：医保用户授权医保支付，其他用户完成在线支付
7. **订单配送**：药店接单，骑手取药配送
8. **确认收货**：用户确认收货，评价服务

### 4.2 医保支付流程

1. **绑定医保**：首次使用医保支付的用户绑定医保电子凭证
2. **选择医保药品**：选购带有医保标识的药品
3. **医保支付**：在支付页面选择医保支付
4. **授权验证**：跳转至医保系统进行身份验证
5. **支付完成**：医保账户扣除相应费用，现金支付剩余费用（如配送费）

### 4.3 处方药购买流程

1. **选择处方药**：浏览处方药详情
2. **提供处方**：上传纸质处方或通过在线问诊获取电子处方
3. **处方审核**：执业药师审核处方
4. **购买药品**：审核通过后，用户购买药品
5. **完成支付**：选择支付方式完成支付

## 5. 技术架构设计

### 5.1 系统架构

- **前端**：Vue 3 + TypeScript + Element Plus
- **后端**：Spring Boot + Spring Cloud + MyBatis Plus
- **数据库**：MySQL（主从复制）+ Redis（缓存）+ Elasticsearch（搜索）
- **中间件**：
  - Nginx（负载均衡）
  - RabbitMQ（消息队列）
  - Redis（缓存、会话管理）
  - MinIO（文件存储）
- **第三方服务**：
  - 地图服务（高德/百度地图）
  - 支付服务（微信支付、支付宝）
  - 医保接口（各地医保系统）
  - 配送服务（美团配送、饿了么配送）

### 5.2 核心技术亮点

- **微服务架构**：各功能模块独立部署，便于扩展和维护
- **分布式缓存**：Redis缓存热点数据，提高系统性能
- **搜索引擎**：Elasticsearch实现高效药品搜索
- **消息队列**：异步处理订单、通知等业务
- **容器化部署**：Docker + Kubernetes实现容器化部署，提高部署效率
- **监控系统**：Prometheus + Grafana监控系统性能
