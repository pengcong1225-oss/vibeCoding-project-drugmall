**文档版本**: v1.0  
**创建日期**: 2026-04-22  
**文档状态**: 待评审

---

## 一、需求背景

### 1.1 现状问题

- 医生端（frontend-doctor）缺乏统一管理后台
- 医生入驻审核流程线下进行，效率低
- 医生排班、评价等数据无法可视化管理
- 科室管理缺乏系统支持

### 1.2 需求目标

- 实现医生全生命周期管理（入驻、审核、排班、评价）
- 规范医生入驻审核流程，确保资质合规
- 提供医生数据统计，支撑运营决策

## 三、功能详细设计

### 3.1 医生列表

#### 3.1.1 功能说明

展示平台所有医生信息，支持搜索、筛选和状态管理。

#### 3.1.2 列表字段

| 字段 | 说明 |
|------|------|
| 医生ID | 唯一标识 |
| 头像 | 医生头像预览 |
| 姓名 | 医生姓名 |
| 性别 | 男/女 |
| 科室 | 所属科室 |
| 职称 | 主任医师/副主任医师/主治医师等 |
| 医院 | 所在医院 |
| 评分 | 平均评分（5分制） |
| 服务次数 | 累计问诊次数 |
| 响应时间 | 平均响应时间（分钟） |
| 状态 | 待审核/正常/停诊/禁用 |
| 入驻时间 | 审核通过时间 |
| 操作 | 查看详情、编辑、禁用、查看排班 |

#### 3.1.3 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 医生姓名 | 文本搜索 | 模糊匹配 |
| 手机号 | 文本搜索 | 精确匹配 |
| 科室 | 下拉多选 | 按科室筛选 |
| 职称 | 下拉多选 | 按职称筛选 |
| 医院 | 文本搜索 | 模糊匹配 |
| 状态 | 下拉多选 | 待审核/正常/停诊/禁用 |
| 评分区间 | 范围选择 | 如3-5分 |
| 入驻时间 | 日期范围 | 按时间筛选 |

#### 3.1.4 操作功能

| 操作 | 说明 |
|------|------|
| 查看详情 | 跳转医生详情页 |
| 编辑 | 编辑医生基本信息 |
| 禁用/启用 | 切换医生状态 |
| 查看排班 | 跳转排班管理 |
| 批量操作 | 批量启用/禁用/导出 |

#### 3.1.5 列表排序

- 默认按入驻时间倒序
- 支持按评分、服务次数、响应时间排序

### 3.2 医生详情

#### 3.2.1 功能说明

展示医生完整信息，包括基本信息、执业信息、统计数据、评价等。

#### 3.2.2 页面结构

```
医生详情
├── 基本信息
│   ├── 头像、姓名、性别、年龄
│   ├── 手机号、邮箱
│   ├── 状态、入驻时间
│   └── 编辑按钮
├── 执业信息
│   ├── 科室、职称、医院
│   ├── 医师资格证书编号
│   ├── 医师执业证书编号
│   ├── 执业范围
│   └── 证书图片预览
├── 统计数据
│   ├── 累计问诊量
│   ├── 平均评分
│   ├── 平均响应时间
│   ├── 本月收入
│   └── 好评率
├── 问诊记录
│   └── 最近问诊列表（可跳转详情）
├── 处方记录
│   └── 最近处方列表（可跳转详情）
├── 评价记录
│   └── 最近评价列表
└── 排班信息
    └── 最近排班日历
```

#### 3.2.3 统计数据说明

| 指标 | 计算方式 |
|------|---------|
| 累计问诊量 | 历史完成问诊总数 |
| 平均评分 | 所有评价评分的平均值 |
| 平均响应时间 | 问诊响应时间的平均值 |
| 本月收入 | 当月问诊收入总和 |
| 好评率 | 4星及以上评价占比 |

### 3.3 入驻审核

#### 3.3.1 功能说明

管理医生入驻申请审核流程。

#### 3.3.2 审核流程

```
医生提交申请 → 资质初审 → 执业证书验证 → 审核通过/驳回 → 开通账号
```

#### 3.3.3 待审核列表

**列表字段：**
| 字段 | 说明 |
|------|------|
| 申请ID | 唯一标识 |
| 姓名 | 医生姓名 |
| 手机号 | 联系电话 |
| 科室 | 申请科室 |
| 职称 | 申请职称 |
| 医院 | 所在医院 |
| 提交时间 | 申请提交时间 |
| 审核状态 | 待审核/审核中/已通过/已驳回 |
| 操作 | 审核、查看详情 |

**筛选条件：**
- 审核状态
- 提交时间范围
- 科室

#### 3.3.4 审核详情

**展示内容：**

**基本信息：**
| 字段 | 说明 |
|------|------|
| 姓名 | 医生真实姓名 |
| 性别 | 男/女 |
| 年龄 | 年龄 |
| 手机号 | 联系电话 |
| 邮箱 | 电子邮箱 |
| 身份证 | 身份证号（脱敏） |

**执业信息：**
| 字段 | 说明 |
|------|------|
| 科室 | 申请科室 |
| 职称 | 申请职称 |
| 医院 | 所在医院 |
| 医师资格证书编号 | 证书编号 |
| 医师执业证书编号 | 证书编号 |
| 执业范围 | 执业范围描述 |
| 工作年限 | 从业年限 |
| 个人简介 | 医生自我介绍 |

**资质材料：**
| 材料 | 说明 |
|------|------|
| 身份证正面 | 图片预览 |
| 身份证反面 | 图片预览 |
| 医师资格证书 | 图片预览 |
| 医师执业证书 | 图片预览 |
| 职称证书 | 图片预览（如有） |
| 医院在职证明 | 图片预览（如有） |
| 医生头像 | 图片预览 |

#### 3.3.5 审核操作

**审核表单：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 审核结果 | 单选 | 是 | 通过/驳回 |
| 审核意见 | 文本域 | 条件 | 驳回时必填，最多500字 |
| 医生账号 | 文本 | 条件 | 通过时自动生成或手动设置 |
| 初始密码 | 文本 | 条件 | 通过时自动生成 |

**审核通过后：**
- 自动创建医生端账号
- 发送审核通过通知（短信/站内消息）
- 医生状态变更为"正常"

**审核驳回后：**
- 医生状态保持"待审核"
- 发送驳回通知，说明驳回原因
- 医生可修改后重新提交

#### 3.3.6 审核记录

| 字段 | 说明 |
|------|------|
| 审核人 | 操作管理员 |
| 审核时间 | 操作时间 |
| 审核结果 | 通过/驳回 |
| 审核意见 | 审核备注 |

| 处理结果 | 已解决/跟进中/无法解决 |
| 处理备注 | 处理说明 |

## 四、数据模型

### 4.1 核心实体

```
Doctor (医生)
├── id: 医生ID
├── name: 姓名
├── phone: 手机号
├── avatar: 头像
├── gender: 性别
├── age: 年龄
├── department_id: 科室ID
├── title: 职称
├── hospital: 医院
├── rating: 评分
├── service_count: 服务次数
├── response_time: 响应时间
├── status: 状态
├── created_at: 创建时间
└── updated_at: 更新时间

DoctorAudit (入驻审核)
├── id: 审核ID
├── doctor_id: 医生ID
├── id_card_front: 身份证正面
├── id_card_back: 身份证反面
├── certificate: 医师资格证书
├── license: 医师执业证书
├── title_certificate: 职称证书
├── work_proof: 在职证明
├── status: 审核状态
├── audit_opinion: 审核意见
├── auditor_id: 审核人
├── audit_time: 审核时间
└── created_at: 创建时间

DoctorSchedule (排班)
├── id: 排班ID
├── doctor_id: 医生ID
├── date: 排班日期
├── morning_enabled: 上午是否排班
├── morning_max: 上午最大问诊数
├── afternoon_enabled: 下午是否排班
├── afternoon_max: 下午最大问诊数
├── evening_enabled: 晚上是否排班
├── evening_max: 晚上最大问诊数
├── consultation_types: 问诊类型
├── status: 状态
└── created_at: 创建时间

Department (科室)
├── id: 科室ID
├── name: 科室名称
├── parent_id: 父级科室ID
├── icon: 图标
├── sort_order: 排序
├── status: 状态
└── description: 描述

DoctorReview (评价)
├── id: 评价ID
├── doctor_id: 医生ID
├── user_id: 患者ID
├── consultation_id: 问诊ID
├── rating: 评分
├── content: 评价内容
├── reply: 医生回复
├── reply_time: 回复时间
├── status: 状态
└── created_at: 创建时间
```

## 六、状态机

### 6.1 医生状态

```
待审核 → 审核通过 → 正常
        ↓
      审核驳回 → 待审核（重新提交）
      
正常 → 停诊（临时）
正常 → 禁用（违规）
停诊 → 正常（恢复）
禁用 → 正常（解封）
```

### 6.2 审核状态

```
待审核 → 审核中 → 审核通过
                 ↓
               审核驳回
```

### 6.3 排班状态

```
已排班 → 正常出诊
       → 停诊
       → 已完成
```
