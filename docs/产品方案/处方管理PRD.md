## 一、需求背景

### 1.1 现状问题

- 处方审核缺乏系统化管理，合规风险高
- 处方药销售必须凭处方，需严格审核流程
- 处方数据统计缺失，无法监控处方质量
- 缺乏处方模板管理，医生开方效率低

### 1.2 需求目标

- 实现处方全流程审核管理，确保合规
- 提供用药合理性检查，降低用药风险
- 支持处方模板管理，提升医生效率
- 提供处方数据统计，监控处方质量

## 二、功能概述

### 2.1 功能范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 处方列表 | 处方信息查询、筛选、状态管理 | P0 |
| 处方审核 | 合规审核、用药合理性检查 | P0 |
| 处方详情 | 处方内容、药品明细、患者信息 | P0 |
| 处方模板 | 常用处方模板管理 | P2 |
| 处方统计 | 处方量、审核通过率、退方率 | P1 |

### 2.2 用户角色

| 角色 | 权限 |
|------|------|
| 审核管理员 | 处方审核 |
| 运营管理员 | 处方列表、统计、模板管理 |
| 超级管理员 | 全部权限 |

### 2.3 合规要求

根据《药品网络销售监督管理办法》：
- 处方药销售必须凭处方
- 处方需经执业药师审核
- 特殊药品（麻醉、精神、毒性、放射性）不得网售
- 处方保存期限不少于5年

### 3.2 处方审核

#### 3.2.1 功能说明

对医生开具的处方进行合规性和用药合理性审核。

#### 3.2.2 审核流程

```
医生开方 → 系统预审 → 人工审核 → 审核通过/驳回 → 患者购药
```

#### 3.2.3 系统预审

**自动检查项：**

| 检查项 | 检查规则 | 处理方式 |
|--------|---------|---------|
| 处方完整性 | 必填字段是否完整 | 不完整则驳回 |
| 药品库存 | 药品是否有库存 | 无库存则提醒 |
| 配伍禁忌 | 药品之间是否存在配伍禁忌 | 存在则预警 |
| 剂量检查 | 药品剂量是否在合理范围 | 超量则预警 |
| 特殊药品 | 是否包含禁售药品 | 包含则驳回 |
| 处方权限 | 医生是否有该药品处方权限 | 无权限则驳回 |

**预审结果：**
- 通过：进入人工审核
- 预警：标记预警项，人工重点审核
- 驳回：直接驳回，说明原因

#### 3.2.4 人工审核

**审核详情页面：**

```
处方审核
├── 处方基本信息
│   ├── 处方编号、处方类型
│   ├── 患者信息（姓名、性别、年龄）
│   ├── 医生信息（姓名、科室）
│   ├── 诊断信息
│   └── 关联问诊信息
├── 药品明细
│   ├── 药品名称、规格
│   ├── 用法用量
│   ├── 频次、疗程
│   ├── 数量、金额
│   └── 药品说明书链接
├── 系统预审结果
│   ├── 预审状态
│   └── 预警项列表
├── 患者病史
│   ├── 过敏史
│   ├── 用药史
│   └── 既往病史
└── 审核操作
    ├── 审核结果
    ├── 审核意见
    └── 提交审核
```

**审核表单：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 审核结果 | 单选 | 是 | 通过/驳回 |
| 审核意见 | 文本域 | 条件 | 驳回时必填，最多500字 |
| 修改建议 | 文本域 | 否 | 给医生的修改建议 |

#### 3.2.5 审核要点

**合规性审核：**
- 处方格式是否规范
- 医生签名是否有效
- 处方日期是否有效（处方有效期3天）
- 是否包含禁售药品

**用药合理性审核：**
- 诊断与用药是否匹配
- 剂量、频次是否合理
- 是否存在配伍禁忌
- 是否与患者过敏史冲突
- 疗程是否合理

**特殊人群审核：**
- 儿童用药剂量是否适当
- 老年人用药是否注意肝肾功能
- 孕妇用药是否安全

#### 3.2.6 审核记录

| 字段 | 说明 |
|------|------|
| 审核人 | 审核药师 |
| 审核时间 | 审核完成时间 |
| 审核结果 | 通过/驳回 |
| 审核意见 | 审核备注 |
| 预审结果 | 系统预审结果 |

## 四、数据模型

### 4.1 核心实体

```
Prescription (处方)
├── id: 处方ID
├── prescription_no: 处方编号
├── user_id: 患者ID
├── patient_id: 就诊人ID
├── doctor_id: 医生ID
├── consultation_id: 关联问诊ID
├── type: 处方类型（普通/急诊/慢病）
├── diagnosis: 诊断信息
├── status: 状态
├── total_amount: 处方总金额
├── audit_opinion: 审核意见
├── auditor_id: 审核人ID
├── audit_time: 审核时间
├── created_at: 创建时间
└── updated_at: 更新时间

PrescriptionItem (处方明细)
├── id: 明细ID
├── prescription_id: 处方ID
├── drug_id: 药品ID
├── drug_name: 药品名称
├── specification: 规格
├── manufacturer: 厂家
├── usage: 用法（口服/外用/注射）
├── dosage: 用量（每次剂量）
├── frequency: 频次（每日几次）
├── duration: 疗程（天数）
├── quantity: 数量
├── unit_price: 单价
├── amount: 金额
└── notes: 注意事项

PrescriptionTemplate (处方模板)
├── id: 模板ID
├── name: 模板名称
├── doctor_id: 创建医生ID
├── department_id: 适用科室ID
├── diagnosis: 适用诊断
├── drugs_json: 药品明细JSON
├── usage_notes: 用法说明
├── precautions: 注意事项
├── use_count: 使用次数
├── status: 状态
├── created_at: 创建时间
└── updated_at: 更新时间

PrescriptionAudit (审核记录)
├── id: 审核ID
├── prescription_id: 处方ID
├── auditor_id: 审核人ID
├── result: 审核结果（通过/驳回）
├── opinion: 审核意见
├── pre_check_result: 预审结果JSON
├── audit_time: 审核时间
└── created_at: 创建时间

DrugInteraction (药品配伍禁忌)
├── id: 禁忌ID
├── drug_a_id: 药品A
├── drug_b_id: 药品B
├── severity: 严重程度（高/中/低）
├── description: 禁忌说明
└── created_at: 创建时间
```

## 六、状态机

### 6.1 处方状态流转

```
待审核 → 审核通过 → 已发药
   ↓
审核驳回 → 已取消
```

### 6.2 审核规则

| 规则 | 说明 |
|------|------|
| 处方有效期 | 处方开具后3天内有效 |
| 审核时效 | 待审核处方2小时内完成审核 |
| 特殊药品 | 麻醉、精神、毒性、放射性药品禁止网售 |
| 处方保存 | 处方数据保存不少于5年 |

## 七、预警机制

### 7.1 预警规则

| 预警类型 | 触发条件 | 通知方式 |
|---------|---------|---------|
| 待审核超时 | 待审核>2小时 | 站内消息+短信 |
| 配伍禁忌 | 处方包含禁忌药品组合 | 审核页面预警 |
| 超剂量 | 药品剂量超过标准 | 审核页面预警 |
| 过敏冲突 | 药品与患者过敏史冲突 | 审核页面预警 |
| 禁售药品 | 包含禁止网售药品 | 自动驳回+通知 |
