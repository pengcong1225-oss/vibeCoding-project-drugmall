# 检测页面需求文档

## 1. 页面概述

**页面名称**: 做检测 (检测服务页面)  
**页面类型**: 移动端H5页面  
**所属模块**: 药品商城 - 检测服务

## 2. 页面目标

为用户提供便捷的居家检测试剂盒购买服务，包括呼吸道检测、妇科检测等品类，支持快速下单购买。

## 3. 布局结构

### 3.1 整体布局

```
┌─────────────────────────────────────┐
│  状态栏                              │
├─────────────────────────────────────┤
│  顶部导航栏 (返回/标题/定位/购物车)   │
├─────────────────────────────────────┤
│  搜索栏                              │
├─────────────────────────────────────┤
│  分类标签栏                          │
├─────────────────────────────────────┤
│  轮播Banner (居家自检推广)           │
├─────────────────────────────────────┤
│  区块标题 (看一看/精选检测项目)       │
├─────────────────────────────────────┤
│  话题标签 + 商品列表                  │
│  ├─ 话题1: 呼吸道感染早知道          │
│  │   └─ 商品卡片横向滚动             │
│  ├─ 话题2: 妇科隐患，早测早安心      │
│  │   └─ 商品卡片横向滚动             │
├─────────────────────────────────────┤
│  底部Tab导航                         │
└─────────────────────────────────────┘
```

### 3.2 组件详细说明

#### 顶部导航栏
- **高度**: 44px
- **背景色**: #FFD93D (明亮黄)
- **元素**:
  - 左侧: 返回箭头 `<`
  - 中间: "看病买药" 标题 + 定位图标 + "宜昌美术馆"
  - 右侧: 购物车图标

#### 搜索栏
- **高度**: 48px
- **样式**: 圆角搜索框，白色背景
- **占位文字**: "布洛芬"
- **右侧**: 相机图标 + 搜索按钮

#### 分类标签栏
- **标签**: 推荐 | 问医生 | **做检测**(选中) | 成人情趣 | 滋补保健
- **选中样式**: 黄色背景胶囊
- **高度**: 40px

#### Banner区域
- **背景**: 渐变黄色 (#FFD93D → #FFE066)
- **左侧文案**:
  - 标签: 🏠 居家自检
  - 主标题: 自测15分钟出结果
  - 按钮: [立即查看]
- **右侧**: 检测试剂盒产品图片

#### 商品列表区块
- **区块标题**: "看一看" + [精选检测项目]标签
- **话题标签**: #话题名称 + 🔥热度标签
- **商品卡片布局**: 横向滚动列表

#### 商品卡片
- **尺寸**: 约 280px × 120px
- **结构**:
  ```
  ┌────────────────────────────┐
  │ ┌────┐                     │
  │ │    │ [商品标题]           │
  │ │图片│ [月售xxx]            │
  │ │    │ ¥xx.x  [预计送达]    │
  │ └────┘                     │
  └────────────────────────────┘
  ```

#### 底部Tab导航
- **高度**: 56px + safe-area
- **背景**: 白色
- **Tab项**:
  - 买药 (图标+文字)
  - 小团健康管家 (中间凸起按钮)
  - 我的 (图标+文字)

## 4. 配色方案

| 变量名 | 色值 | 用途 |
|--------|------|------|
| --color-primary | #FFD93D | 主色调，导航栏、按钮、标签 |
| --color-secondary | #FF6B6B | 辅色调，价格、促销 |
| --color-bg | #FFF9E6 | 页面背景色，暖黄色 |
| --color-card | #FFFFFF | 卡片背景 |
| --color-text-primary | #333333 | 主要文字 |
| --color-text-secondary | #666666 | 次要文字 |
| --color-text-tertiary | #999999 | 辅助文字 |
| --color-tag-bg | #FFF3CD | 标签背景 |

## 6. 交互说明

### 6.1 点击交互
- 分类标签: 点击切换，高亮显示
- 商品卡片: 点击进入商品详情页
- Banner: 点击跳转活动页
- 底部Tab: 切换页面

### 6.2 滚动交互
- 商品列表: 横向滚动，支持惯性滑动
- 页面: 纵向滚动，顶部导航固定

## 7. 数据需求

### 7.1 话题列表
```typescript
interface Topic {
  id: string;
  name: string;
  tag: string;
  hotLabel?: string;

```

```typescript
interface Product {

  monthlySales: string;

}
```

- 设计稿宽度: 375px (iPhone标准)
- 适配范围: 320px - 428px
