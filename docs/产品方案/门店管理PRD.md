# 门店管理 PRD

**文档版本**: v1.0  
**创建日期**: 2026-04-22  
**文档状态**: 待评审

---

## 一、需求背景

### 1.1 现状问题

- 患者端有药店详情页面，但缺乏统一管理后台
- 门店入驻审核流程不规范
- 门店资质证照管理缺失
- 门店药品库存无法统一管理
- 门店经营数据无法统计分析

### 1.2 需求目标

- 实现门店全生命周期管理（入驻、审核、运营）
- 规范门店资质审核，确保合规经营
- 提供门店药品库存管理
- 提供门店经营数据统计

## 二、功能概述

### 2.1 功能范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 门店列表 | 门店信息查询、筛选、状态管理 | P1 |
| 门店详情 | 门店完整信息、资质、统计数据 | P1 |
| 门店审核 | 入驻审核、资质审核 | P1 |
| 门店药品 | 门店药品关联、库存管理 | P1 |
| 门店统计 | 订单量、销售额、配送范围 | P2 |

### 2.2 用户角色

| 角色 | 权限 |
|------|------|
| 审核管理员 | 门店入驻审核 |
| 运营管理员 | 门店列表、药品管理、统计 |
| 超级管理员 | 全部权限 |

### 2.3 合规要求

根据《药品经营质量管理规范》(GSP)：
- 门店需持有《药品经营许可证》
- 门店需通过GSP认证
- 处方药销售需凭处方
- 药品储存需符合温度要求

```
门店提交申请 → 资质初审 → 证照验证 → 审核通过/驳回 → 开通门店
```

| 审核状态 | 待审核/审核中/已通过/已驳回 |
| 操作 | 审核、查看详情 |

#### 3.3.4 审核详情

**基本信息：**
| 字段 | 说明 |
|------|------|
| 门店名称 | 门店名称 |
| 门店类型 | 连锁/单体 |
| 联系人 | 联系人姓名 |
| 联系电话 | 联系电话 |
| 邮箱 | 电子邮箱 |

| 门店简介 | 门店介绍 |

|------|--------|

| 药品经营许可证 | 到期日期 |
| GSP认证证书 | 到期日期 |

#### 3.3.5 审核操作

**审核表单：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 审核结果 | 单选 | 是 | 通过/驳回 |
| 审核意见 | 文本域 | 条件 | 驳回时必填，最多500字 |

**审核通过后：**
- 门店状态变更为"营业中"
- 发送审核通过通知
- 门店可在患者端展示

**审核驳回后：**
- 门店状态保持"待审核"
- 发送驳回通知，说明驳回原因
- 门店可修改后重新提交

## 六、状态机

### 6.1 门店状态

```
待审核 → 审核通过 → 营业中
        ↓
      审核驳回 → 待审核（重新提交）
      
营业中 → 停业（临时）
营业中 → 禁用（违规）
停业 → 营业中（恢复）
禁用 → 营业中（解封）
```

### 6.2 资质状态

```
未提交 → 待审核 → 已通过
                 ↓
               已过期（证照到期）
               已驳回
```

## 七、预警机制

### 7.1 预警规则

| 预警类型 | 触发条件 | 通知方式 |
|---------|---------|---------|
| 资质过期 | 证照到期前30天 | 站内消息+短信 |

| 资质过期 | 证照已过期 | 站内消息+短信，自动下架 |
