## 一、需求背景

### 1.1 现状问题

- 问诊业务缺乏统一监控和管理
- 问诊分配依赖医生自主接单，效率不均
- 异常问诊（超时、投诉）无法及时发现和处理
- 问诊数据统计缺失，无法评估业务健康度

### 1.2 需求目标

- 实现问诊全流程可视化管理
- 支持智能分配和手动分配问诊
- 异常问诊及时预警和处理
- 提供问诊数据统计和分析

## 三、功能详细设计

### 3.1 问诊列表

#### 3.1.1 功能说明

展示平台所有问诊记录，支持搜索、筛选和状态管理。

#### 3.1.2 列表字段

| 字段 | 说明 |
|------|------|
| 问诊ID | 唯一标识 |
| 问诊编号 | 业务编号 |
| 患者 | 患者昵称（脱敏） |
| 医生 | 医生姓名 |
| 科室 | 问诊科室 |
| 问诊类型 | 图文/视频/电话/AI导诊 |
| 症状描述 | 患者主诉（截断显示） |
| 问诊费用 | 问诊金额 |
| 状态 | 待接诊/问诊中/待支付/已完成/已取消/退款中 |
| 创建时间 | 问诊创建时间 |
| 响应时间 | 医生首次响应时间 |
| 操作 | 查看详情、分配医生、退款 |

#### 3.1.3 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 问诊编号 | 文本搜索 | 精确匹配 |
| 患者手机号 | 文本搜索 | 精确匹配 |
| 医生 | 下拉多选 | 按医生筛选 |
| 科室 | 下拉多选 | 按科室筛选 |
| 问诊类型 | 下拉多选 | 图文/视频/电话 |
| 状态 | 下拉多选 | 按状态筛选 |
| 创建时间 | 日期范围 | 按时间筛选 |
| 金额区间 | 范围选择 | 按金额筛选 |

#### 3.1.4 状态说明

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 待接诊 | 患者已提交，等待医生接诊 | 分配医生、取消 |
| 问诊中 | 医生已接诊，正在问诊 | 查看详情 |
| 待支付 | 问诊结束，等待患者支付 | 查看详情 |
| 已完成 | 问诊完成且已支付 | 查看详情 |
| 已取消 | 问诊已取消 | 查看详情 |
| 退款中 | 退款申请处理中 | 审核退款 |
| 已退款 | 退款已完成 | 查看详情 |

#### 3.1.5 操作功能

| 操作 | 说明 |
|------|------|
| 查看详情 | 跳转问诊详情页 |
| 分配医生 | 手动分配医生（待接诊状态） |
| 取消问诊 | 取消问诊（待接诊状态） |
| 退款 | 发起退款（问诊中/已完成状态） |
| 导出 | 导出问诊列表 |

### 3.3 问诊分配

#### 3.3.1 功能说明

支持手动分配和智能分配问诊给医生。

#### 3.3.2 手动分配

**分配流程：**
```
选择问诊 → 选择医生 → 确认分配 → 通知医生
```

**分配表单：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 问诊 | 选择 | 是 | 待分配的问诊 |
| 医生 | 选择 | 是 | 可分配的医生列表 |
| 分配原因 | 文本 | 否 | 分配说明 |

**可分配医生筛选：**
- 同科室医生
- 状态为"正常"的医生
- 当前未达最大接诊数的医生
- 在线状态的医生优先

#### 3.3.3 智能分配规则

**规则配置：**

| 规则 | 说明 | 权重 |
|------|------|------|
| 科室匹配 | 优先分配同科室医生 | 高 |
| 在线状态 | 优先分配在线医生 | 高 |
| 负载均衡 | 优先分配当前问诊数少的医生 | 中 |
| 评分优先 | 优先分配评分高的医生 | 低 |
| 响应时间 | 优先分配响应快的医生 | 中 |

**分配策略：**
- 轮询分配：按顺序轮流分配
- 负载均衡：分配给当前问诊最少的医生
- 评分优先：分配给评分最高的医生
- 自定义：按配置规则分配

#### 3.3.4 分配记录

| 字段 | 说明 |
|------|------|
| 问诊ID | 问诊编号 |
| 原医生 | 原分配医生（如有） |
| 新医生 | 新分配医生 |
| 分配方式 | 手动/自动 |
| 分配人 | 操作管理员（手动分配） |
| 分配时间 | 分配时间 |
| 分配原因 | 分配说明 |

### 3.5 异常问诊

#### 3.5.1 功能说明

监控和处理异常问诊，包括超时、投诉、退款等。

#### 3.5.2 异常类型

| 类型 | 触发条件 | 处理方式 |
|------|---------|---------|
| 超时未接诊 | 提交后30分钟无医生接诊 | 自动分配/人工介入 |
| 超时未回复 | 问诊中10分钟无回复 | 提醒医生/转接 |
| 投诉问诊 | 患者发起投诉 | 客服处理 |
| 退款问诊 | 退款申请 | 审核退款 |
| 异常取消 | 频繁取消 | 标记关注 |

#### 3.5.3 异常列表

**列表字段：**
| 字段 | 说明 |
|------|------|
| 问诊ID | 问诊编号 |
| 异常类型 | 超时/投诉/退款/取消 |
| 患者 | 患者昵称 |
| 医生 | 医生姓名 |
| 异常描述 | 异常详情 |
| 发生时间 | 异常发生时间 |
| 处理状态 | 待处理/处理中/已处理 |
| 操作 | 查看详情、处理 |

#### 3.5.4 异常处理

**处理流程：**
```
异常触发 → 系统预警 → 客服处理 → 处理完成
```

**处理表单：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 处理方式 | 下拉 | 是 | 重新分配/退款/补偿/其他 |
| 处理说明 | 文本域 | 是 | 处理详情 |
| 补偿金额 | 数字 | 否 | 补偿金额（如有） |

## 四、数据模型

### 4.1 核心实体

```
Consultation (问诊)
├── id: 问诊ID
├── consultation_no: 问诊编号
├── user_id: 患者ID
├── doctor_id: 医生ID
├── department_id: 科室ID
├── type: 问诊类型（图文/视频/电话）
├── symptom: 症状描述
├── patient_id: 就诊人ID
├── allergy_history: 过敏史
├── medication_history: 用药史
├── images: 患者上传图片
├── fee: 问诊费用
├── status: 状态
├── response_time: 响应时间（秒）
├── duration: 问诊时长（秒）
├── start_time: 开始时间
├── end_time: 结束时间
├── created_at: 创建时间
└── updated_at: 更新时间

ConsultationMessage (问诊消息)
├── id: 消息ID
├── consultation_id: 问诊ID
├── sender_type: 发送者类型（patient/doctor/system）
├── sender_id: 发送者ID
├── content: 消息内容
├── message_type: 消息类型（text/image/system/prescription）
├── images: 图片URL列表
├── created_at: 创建时间
└── updated_at: 更新时间

ConsultationAssign (问诊分配)
├── id: 分配ID
├── consultation_id: 问诊ID
├── from_doctor_id: 原医生ID
├── to_doctor_id: 新医生ID
├── assign_type: 分配方式（manual/auto）
├── assigner_id: 分配人ID
├── reason: 分配原因
└── created_at: 创建时间

ConsultationException (异常问诊)
├── id: 异常ID
├── consultation_id: 问诊ID
├── exception_type: 异常类型
├── description: 异常描述
├── status: 处理状态
├── handler_id: 处理人ID
├── handle_method: 处理方式
├── handle_note: 处理说明
├── compensation_amount: 补偿金额
├── handled_at: 处理时间
└── created_at: 创建时间
```

## 六、状态机

### 6.1 问诊状态流转

```
待接诊 → 问诊中 → 待支付 → 已完成
   ↓        ↓
 已取消   已取消
   ↓        ↓
  退款中 → 已退款
```

### 6.2 超时规则

| 场景 | 超时时间 | 触发动作 |
|------|---------|---------|
| 待接诊超时 | 30分钟 | 系统预警，自动分配或人工介入 |
| 问诊中未回复 | 10分钟 | 提醒医生，超时30分钟转接 |
| 待支付超时 | 24小时 | 自动取消问诊 |

---

## 七、预警机制

### 7.1 预警规则

| 预警类型 | 触发条件 | 通知方式 |
|---------|---------|---------|
| 超时未接诊 | 待接诊>30分钟 | 站内消息+短信 |
| 超时未回复 | 问诊中>10分钟无回复 | 站内消息 |
| 差评预警 | 评分≤2星 | 站内消息 |
| 投诉预警 | 患者发起投诉 | 站内消息+短信 |
| 退款预警 | 退款申请 | 站内消息 |

### 7.2 预警处理

- 预警消息推送到消息中心
- 支持设置免打扰时段
- 支持预警升级（超时未处理自动升级）
