## 一、需求背景

### 1.1 现状问题

- 首页Tab、轮播图、金刚位等内容硬编码在代码中
- 每次调整首页内容需要前端发版
- 运营人员无法自主配置首页展示内容
- 无法进行A/B测试和精准营销

### 1.2 需求目标

- 实现首页内容可视化配置，无需发版即可调整
- 支持多Tab独立配置，灵活管理各Tab内容
- 支持定时上下架，自动化运营
- 支持版本管理和快速回滚

## 三、功能详细设计

### 3.1 全局设置

#### 3.1.1 功能说明

配置首页全局样式和基础参数。

#### 3.1.2 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 页面标题 | 文本 | 药康购 | App标题栏显示 |
| 背景颜色 | 颜色选择器 | #F5F5F5 | 全局背景色 |
| 模块间距 | 数字(16) | 12 | 模块之间的间距(px) |
| 圆角大小 | 数字(12) | 8 | 卡片圆角(px) |
| 主色调 | 颜色选择器 | #0891B2 | 全局主色 |
| 辅助色 | 颜色选择器 | #22D3EE | 全局辅助色 |
| 小字体 | 数字(12) | 12 | 小字号(px) |
| 中字体 | 数字(14) | 14 | 常规字号(px) |
| 大字体 | 数字(16) | 16 | 标题字号(px) |

#### 3.1.3 交互说明

- 表单式配置，修改后实时预览
- 点击"保存"按钮保存为草稿
- 点击"重置"恢复上次发布配置

### 3.2 Tab管理

#### 3.2.1 功能说明

管理首页Tab导航，支持增删改查和排序。

#### 3.2.2 列表页面

**展示方式：** 表格列表

**列表字段：**
| 字段 | 说明 |
|------|------|
| Tab ID | 唯一标识 |
| Tab名称 | 显示名称 |
| 图标 | 默认图标预览 |
| 主色调 | 颜色预览 |
| 关联模块数 | 该Tab包含的模块数量 |
| 排序 | 显示顺序 |
| 状态 | 启用/禁用 |
| 操作 | 编辑、删除、上移、下移 |

**操作按钮：**
- 新增Tab
- 批量启用/禁用
- 批量删除

#### 3.2.3 新增/编辑Tab

**表单字段：**

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|---------|------|
| Tab ID | 文本 | 是 | 英文+数字，唯一 | 如：recommend |
| Tab名称 | 文本 | 是 | 最多10字 | 显示名称 |
| 图标 | 图片上传 | 是 | PNG/SVG，120x120 | 默认状态图标 |
| 激活图标 | 图片上传 | 否 | PNG/SVG，120x120 | 选中状态图标，不填则使用默认图标 |
| 主色调 | 颜色选择器 | 是 | HEX格式 | Tab主题色 |
| 渐变配置 | 文本 | 否 | CSS渐变语法 | 头部渐变，如：linear-gradient(180deg, #0891B2 0%, #22D3EE 100%) |
| 背景色 | 颜色选择器 | 是 | HEX格式 | 内容区背景色 |
| 头部背景图 | 图片上传 | 否 | PNG/JPG，750x300 | 头部装饰背景图 |
| 关联模块 | 多选 | 是 | 至少选择1个 | 从模块池中选择 |
| 排序 | 数字 | 是 | 正整数 | 数值越小越靠前 |
| 状态 | 开关 | 是 | - | 启用/禁用 |

#### 3.2.4 交互说明

- 支持拖拽排序
- 删除Tab前需确认，提示"删除后关联模块不会被删除"
- 禁用Tab在App端不显示，但配置保留

### 3.3 模块管理

#### 3.3.1 功能说明

管理首页所有模块，支持可视化配置。

#### 3.3.2 列表页面

**展示方式：** 按Tab分组的卡片列表

**模块类型：**
| 类型 | 说明 | 核心配置 |
|------|------|---------|
| 轮播图 | 图片轮播展示 | 图片列表、播放设置 |
| 金刚位 | 网格功能入口 | 图标、名称、跳转 |
| 广告位 | 广告图片展示 | 图片、布局、跳转 |
| 专题区域 | 专题内容展示 | 标题、布局、内容 |
| 商品流 | 商品瀑布流 | 数据源、排序规则 |
| 服务网格 | 服务入口网格 | 图标、名称、跳转 |
| 公告栏 | 滚动公告 | 公告内容 |
| 领券中心 | 优惠券展示 | 优惠券选择 |
| 限时抢购 | 倒计时抢购 | 活动时间、商品 |
| 新品首发 | 新品展示 | 商品筛选规则 |

#### 3.3.3 新增模块

**步骤：**
1. 选择模块类型
2. 填写模块基础信息
3. 配置模块内容
4. 选择关联Tab
5. 保存

**基础信息字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 模块名称 | 文本 | 是 | 模块标题 |
| 模块副标题 | 文本 | 否 | 补充说明 |
| 模块类型 | 下拉 | 是 | 选择模块类型 |
| 布局方式 | 下拉 | 是 | 垂直/水平/网格/瀑布流 |
| 背景颜色 | 颜色选择器 | 否 | 模块背景色 |
| 圆角大小 | 数字 | 否 | 模块圆角 |
| 上边距 | 数字 | 否 | 默认0 |
| 下边距 | 数字 | 否 | 默认12 |
| 左右边距 | 数字 | 否 | 默认12 |
| 关联Tab | 多选 | 是 | 在哪些Tab显示 |
| 排序 | 数字 | 是 | 模块显示顺序 |
| 状态 | 开关 | 是 | 启用/禁用 |

#### 3.3.4 交互说明

- 支持拖拽排序
- 支持复制模块（快速创建相似模块）
- 模块删除前需确认

### 3.8 发布管理

#### 3.8.1 功能说明

管理首页配置的发布流程，支持版本管理和回滚。

#### 3.8.2 发布流程

```
编辑配置 → 保存草稿 → 预览效果 → 提交发布 → 发布上线
```

#### 3.8.3 版本列表

**展示方式：** 表格列表

**列表字段：**
| 字段 | 说明 |
|------|------|
| 版本号 | 自动生成，如v1.0.0 |
| 版本说明 | 本次更新内容描述 |
| 创建人 | 操作人姓名 |
| 创建时间 | 配置创建时间 |
| 发布时间 | 配置发布时间 |
| 状态 | 草稿/已发布/已回滚 |
| 操作 | 预览、发布、回滚、删除 |

#### 3.8.4 发布操作

**发布确认：**
- 显示本次变更摘要（新增/修改/删除的内容）
- 确认发布后，配置实时生效
- 发布记录操作日志

**回滚操作：**
- 选择历史版本进行回滚
- 回滚后生成新版本
- 回滚记录操作日志

#### 3.8.5 预览功能

**预览方式：**
- 生成预览链接，可在手机浏览器查看
- 生成预览二维码，扫码查看
- 预览环境使用预览配置，不影响线上

## 四、数据模型

### 4.1 核心实体关系

```
HomePageConfig (首页配置)
├── PageConfig (页面基础配置)
├── TabConfig[] (Tab配置列表)
│   └── sectionIds[] (关联模块ID)
├── SectionConfig[] (模块配置列表)
│   └── content (模块内容)
│       ├── BannerContent (轮播图内容)
│       ├── KingKongContent (金刚位内容)
│       ├── AdSlotContent (广告位内容)
│       ├── TopicContent (专题内容)
│       └── ...
└── StyleConfig (样式配置)
```

### 6.3 缓存策略

```typescript
// 配置缓存
const CACHE_KEY = 'home_page_config'
const CACHE_EXPIRE = 5 * 60 * 1000 // 5分钟

async function getConfig() {
  const cached = localStorage.getItem(CACHE_KEY)
  if (cached) {
    const { data, timestamp } = JSON.parse(cached)
    if (Date.now() - timestamp < CACHE_EXPIRE) {
      return data
    }
  }
  
  const config = await API.getHomePageConfig()
  localStorage.setItem(CACHE_KEY, JSON.stringify({
    data: config,
    timestamp: Date.now()
  }))
  return config
}
```
