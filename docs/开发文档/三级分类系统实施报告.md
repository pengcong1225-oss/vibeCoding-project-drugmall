# 三级分类系统实施报告

**日期**: 2026-04-28  
**状态**: ✅ 已完成

---

## 📋 需求说明

从首页金刚位一级分类进入分类页后：
1. **左侧加载当前一级分类的下属二级分类**，默认选中第一个
2. **选中左侧二级分类后**，在右侧顶部加载该二级分类下属的三级分类，默认选中第一个
3. **加载选中的三级分类下属商品**

---

## 🗄️ 数据库设计

### 分类表结构 (dm_category)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 分类ID（主键） |
| name | VARCHAR | 分类名称 |
| parent_id | BIGINT | 父分类ID（NULL表示一级分类） |
| icon | VARCHAR | 图标 |
| sort | INT | 排序 |
| status | INT | 状态（1-启用，0-禁用） |
| is_deleted | BOOLEAN | 逻辑删除标记 |

### 三级分类层级

```
Level 1 (一级分类 - 金刚位入口)
├─ Level 2 (二级分类 - 左侧边栏)
│  ├─ Level 3 (三级分类 - 顶部标签栏)
│  │  └─ 商品列表
```

### 数据示例

**一级分类** (parent_id = NULL):
- ID: 1 - 药品
- ID: 2 - 医疗器械
- ID: 3 - 保健品

**二级分类** (parent_id = 一级分类ID):

- ID: 301 - 蛋白粉 (parent_id=3)

**三级分类** (parent_id = 二级分类ID):
- ID: 1011 - 感冒药 (parent_id=101)
- ID: 1012 - 退烧药 (parent_id=101)
- ID: 2011 - 上臂式血压计 (parent_id=201)
- ID: 3011 - 乳清蛋白粉 (parent_id=301)

**商品** (category_id = 三级分类ID):
- 感康复方氨酚烷胺片 (category_id=1011)

```java
private DrugCategoryVO convertToCategoryVO(DrugCategory category) {
    DrugCategoryVO vo = new DrugCategoryVO();
    vo.setId(String.valueOf(category.getId()));
    vo.setName(category.getName());
    vo.setParentId(category.getParentId() != null ? String.valueOf(category.getParentId()) : null); // ✅ 新增
    vo.setIcon(category.getIcon());
    vo.setSort(category.getSort());
    vo.setStatus(category.getStatus());
    return vo;
}
```

### 3. 前端重构

**文件**: `frontend/src/views/category/index.vue`

#### 核心逻辑变更

**旧逻辑**（两级分类）:
- 左侧：一级分类
- 顶部：二级分类
- 下方：商品列表

**新逻辑**（三级分类）:
- 左侧：**二级分类**（根据URL参数中的一级分类ID动态加载）
- 顶部：**三级分类**（根据选中的二级分类ID动态加载）
- 下方：**商品列表**（根据选中的三级分类ID加载）

#### 关键代码

**1. 数据定义**:
```typescript
// 所有分类数据（扁平列表）
const allCategories = ref<DrugCategory[]>([])

// 当前选中的一级分类ID（从URL参数获取）
const activeLevel1Id = ref('')

// 当前选中的二级分类ID（左侧边栏）
const activeLevel2Id = ref('')

// 当前选中的三级分类ID（顶部标签栏）
const activeLevel3Id = ref('')
```

**2. 计算属性**:
```typescript
// 二级分类列表（左侧边栏）- 一级分类的子分类
const level2Categories = computed(() => {
  if (!activeLevel1Id.value) return []
  return allCategories.value.filter(c => c.parentId === activeLevel1Id.value)
})

// 三级分类列表（顶部标签栏）- 二级分类的子分类
const level3Categories = computed(() => {
  if (!activeLevel2Id.value) return []
  
  const subs = allCategories.value.filter(c => c.parentId === activeLevel2Id.value)
  
  // 添加"全部"选项
  return [{ id: 'all', name: '全部', parentId: activeLevel2Id.value }, ...subs]
})
```

**3. 自动选中逻辑**:
```typescript
onMounted(async () => {
  await fetchCategories()
  
  // 从URL参数获取一级分类ID
  const categoryId = route.query.id as string
  if (categoryId) {
    activeLevel1Id.value = categoryId
    
    // 自动选中第一个二级分类
    if (level2Categories.value.length > 0) {
      activeLevel2Id.value = level2Categories.value[0].id
      
      // 自动选中第一个三级分类
      const level3Subs = allCategories.value.filter(c => c.parentId === activeLevel2Id.value)
      if (level3Subs.length > 0) {
        activeLevel3Id.value = level3Subs[0].id
      }
    }
  }
})
```

**4. 切换二级分类**:
```typescript
const selectLevel2 = (id: string) => {
  activeLevel2Id.value = id
  
  // 自动选中该二级分类下的第一个三级分类
  const level3Subs = allCategories.value.filter(c => c.parentId === id)
  if (level3Subs.length > 0) {
    activeLevel3Id.value = level3Subs[0].id
  } else {
    activeLevel3Id.value = ''
  }
}
```

**5. 监听变化自动加载商品**:
```typescript
watch([activeLevel2Id, activeLevel3Id], () => {
  fetchDrugs()
})
```
