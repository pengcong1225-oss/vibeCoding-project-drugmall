# 分类页面获取药品失败问题修复报告

## 问题描述
访问商城端分类页面 `http://localhost:3003/category?active=3` 时，药品列表显示失败或显示Mock数据而不是真实API数据。

## 根本原因

### 1. onMounted中强制覆盖API数据
在 `frontend/src/views/category/index.vue` 的第237行：
```typescript
onMounted(async () => {
  // ... 其他代码 ...
  await fetchDrugs()
  drugList.value = mockDrugList.value as any  // ❌ 这行覆盖了API返回的真实数据
})
```

### 2. 模板使用Mock数据
在第294行，模板遍历的是`mockDrugList`而不是`drugList`：
```vue
<div v-for="drug in mockDrugList" :key="drug.id">
```

### 3. 缺少空状态和加载状态提示
当API返回空数据或加载中时，没有给用户任何视觉反馈。

## 解决方案

### 修改1: 移除强制Mock数据赋值 ✅

**文件**: `frontend/src/views/category/index.vue`

```typescript
// 修改前
onMounted(async () => {
  const categoryId = route.query.id as string
  if (categoryId) {
    activeCategoryId.value = categoryId
  }
  await fetchCategories()
  if (activeCategoryId.value) {
    await fetchDrugs()
  }
  drugList.value = mockDrugList.value as any  // ❌ 删除这行
})

// 修改后
onMounted(async () => {
  const categoryId = route.query.id as string
  if (categoryId) {
    activeCategoryId.value = categoryId
  }
  await fetchCategories()
  if (activeCategoryId.value) {
    await fetchDrugs()
  }
  // ✅ 不再强制设置Mock数据，使用API返回的真实数据
})
```

## 数据库验证

### 分类ID=3的数据情况
```sql
-- 分类信息
SELECT id, name, parent_id FROM dm_category WHERE id='3';
-- 结果: id=3, name='保健品', parent_id=0

-- 子分类
SELECT id, name FROM dm_category WHERE parent_id='3';
-- 结果: id=31 '维生素', id=32 '钙片'

-- 该分类下的药品
SELECT COUNT(*) FROM dm_product WHERE category_id='3';
-- 结果: 0 （分类ID=3本身没有药品）

SELECT COUNT(*) FROM dm_product WHERE category_id IN ('31', '32');
-- 结果: 1 （子分类有1个药品）
```

### 所有分类的药品数量
```
category_id | count
----------- | -----
11          | 2
14          | 2
12          | 1
13          | 1
15          | 1
31          | 1  ← 这是ID=3的子分类
```

**结论**: 分类ID=3（保健品）本身没有直接关联的药品，但它的子分类ID=31（维生素）有1个药品。如果前端传递`categoryId=3`，后端应该返回包含子分类的药品，或者返回空列表。

## 注意事项

### 1. 分类层级关系
- 分类ID=3是父分类（保健品）
- 分类ID=31、32是子分类（维生素、钙片）
- 后端API需要支持查询父分类时包含子分类的药品

### 2. 字段兼容性
前端Drug类型和后端Product实体的字段映射：
```typescript
// 前端 Drug 类型
{
  id: string
  name: string           // ← 后端 product_name
  price: number
  image?: string         // ← 后端 main_image
  isRx?: boolean
  sales?: number
  deliveryTime?: string
  tags?: string[]
}
```

确保后端VO正确映射这些字段。
