## 三、IM服务集成

### 集成架构

```
frontend-doctor/
├── src/
│   ├── types/
│   │   └── im.ts                    # IM类型定义
│   ├── api/
│   │   └── im.ts                    # IM API接口
│   ├── utils/
│   │   ├── request.ts               # HTTP请求封装
│   │   └── im.ts                    # 腾讯IM SDK工具类
│   └── views/
│       └── consultation/
│           └── chat.vue             # 问诊聊天页面（已集成IM）
```

### 核心功能

#### 1. 类型定义 (`types/im.ts`)
- `UserSigVO` - 用户签名信息
- `IMConversationVO` - 会话信息
- `MessageVO` - 消息信息
- `ChatMessage` - 聊天消息显示格式
- `ConsultationInfo` - 问诊会话信息

#### 2. API接口 (`api/im.ts`)
- `getUserSig()` - 获取IM登录凭证
- `getConversations()` - 获取会话列表
- `enterConversation()` - 进入会话
- `getMessages()` - 获取消息历史
- `sendMessage()` - 发送消息
- `getUnreadCount()` - 获取未读消息总数

#### 3. IM工具类 (`utils/im.ts`)
**核心方法：**
- `init(userId, userType)` - 初始化IM SDK
- `sendTextMessage(toUserId, text)` - 发送文本消息
- `sendImageMessage(toUserId, file)` - 发送图片消息
- `getConversationList()` - 获取会话列表
- `getMessageList(conversationID)` - 获取消息列表
- `setMessageRead(conversationID)` - 设置消息已读

**事件监听：**
- `onMessageReceived` - 收到新消息
- `onConversationListUpdate` - 会话列表更新
- `onSdkReady` - SDK Ready
- `onKickedOut` - 被踢下线
- `onNetStateChange` - 网络状态变化

#### 4. 聊天页面 (`views/consultation/chat.vue`)
**功能特性：**
- 自动初始化IM SDK
- 加载历史消息
- 实时接收新消息
- 发送文本消息
- 发送图片消息（支持5MB以内）
- 消息已读标记
- 自动滚动到底部
- 加载状态和空状态处理
- 降级方案（IM失败时显示模拟数据）

### 使用示例

```typescript
// 初始化IM服务
import { imService } from '@/utils/im'

// 在组件中初始化
onMounted(async () => {
  const success = await imService.init('doctor_001', 'doctor')
  if (success) {
    // 监听新消息
    imService.on('onMessageReceived', (event) => {
      console.log('收到新消息:', event)
    })
  }
})

// 发送消息
const message = await imService.sendTextMessage('patient_001', '您好')

// 获取消息列表
const messages = await imService.getMessageList('C2C_patient_001')

// 清理
onUnmounted(() => {
  imService.off('onMessageReceived', handler)
  // imService.logout() // 可选
})
```

## 四、开发建议

### 1. 环境配置
在 `.env.development` 中配置API基础路径：
```
VITE_API_BASE_URL=http://localhost:8080/api
```

### 2. 腾讯IM SDK
- SDK通过CDN动态加载，无需npm安装
- SDK文档：https://web.sdk.qcloud.com/im/doc/

### 3. 测试建议
- 测试IM功能前，确保后端服务正常运行
- 检查腾讯IM控制台配置是否正确
- 使用不同浏览器或无痕模式测试多用户聊天

### 4. 生产部署
- 修改 `application.yml` 中的腾讯IM配置为生产环境
- 确保 `mock-mode: false` 使用真实IM服务
- 配置HTTPS以支持腾讯IM SDK

## 五、注意事项

1. **IM初始化时机**
   - 建议在应用启动时初始化IM服务
   - 或在进入聊天页面时按需初始化

2. **消息处理**
   - 消息发送失败时会恢复输入内容
   - 历史消息加载失败会显示模拟数据

3. **性能优化**
   - 图片限制5MB以内
   - 消息列表支持滚动加载（待实现）
   - 建议实现消息分页加载

4. **安全性**
   - UserSig由后端生成，避免前端暴露密钥
   - Token存储在localStorage，建议使用更安全的存储方式
