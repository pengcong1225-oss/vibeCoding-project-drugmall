 * 获取医生未读消息列表

/**
 * 获取最近的患者消息（用于首页展示）

## ⚠️ 注意事项

1. **向后兼容**: 保留硬编码数据作为fallback，防止API失败时页面空白
2. **错误处理**: 所有API调用都需要try-catch，显示友好错误提示
3. **加载状态**: 添加loading状态，提升用户体验
4. **缓存策略**: 考虑使用缓存减少API调用频率
5. **分页处理**: 列表数据需要支持分页加载
