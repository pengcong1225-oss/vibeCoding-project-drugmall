### 2. 待办数量计算

**后端逻辑** (`DoctorServiceImpl.java` 第154-166行):
```java
public DoctorTodoCountVO getTodoCount(String doctorId) {
    DoctorStatsVO stats = getStats(doctorId);
    DoctorTodoCountVO todoCount = new DoctorTodoCountVO();
    
    // 待办 = 待接诊 + 待审核处方
    int pendingConsultations = stats.getPending() != null ? stats.getPending() : 0;  // 4
    int pendingPrescriptions = countPendingPrescriptions(doctorId);  // 0
    todoCount.setTodoCount(pendingConsultations + pendingPrescriptions);  // 4 + 0 = 4
    
    // TODO: 从消息表获取未读消息
    todoCount.setUnreadCount(3);  // 硬编码
    return todoCount;
}
```

**后端SQL查询**:
```sql
-- 查询待审核处方

-- 结果: 0

-- 查询待接诊问诊
SELECT COUNT(*) FROM dm_consultation WHERE doctor_id = 'DOC001' AND status = 'pending'
-- 结果: 4
```

**API返回数据**:
```json

  "todoCount": 4,    // 待接诊(4) + 待审核处方(0)
  "unreadCount": 3   // 硬编码的未读消息数
}
```

```java
// DoctorServiceImpl.java
public List<TodoItemVO> getTodos(String doctorId) {
    List<TodoItemVO> todos = new ArrayList<>();
    
    // 1. 待回复患者咨询
    long pendingConsultations = consultationMapper.selectCount(
        new LambdaQueryWrapper<Consultation>()
            .eq(Consultation::getDoctorId, doctorId)
            .eq(Consultation::getStatus, "pending")
    );
    todos.add(new TodoItemVO("warning", "orange", "待回复患者咨询", 
                             pendingConsultations + "条待回复", "去回复"));
    
    // 2. 待审核处方
    long pendingPrescriptions = prescriptionMapper.selectCount(
        new LambdaQueryWrapper<Prescription>()
            .eq(Prescription::getDoctorId, doctorId)
            .eq(Prescription::getStatus, "pending")
    );
    todos.add(new TodoItemVO("prescription", "blue", "待审核处方", 
                             pendingPrescriptions + "张待审核", "去审核"));
    
    // 3. 待完善病历
    todos.add(new TodoItemVO("file", "gray", "待完善病历", 
                             "待开发", "去完善"));
    
    // 4. 即将过期随访
    todos.add(new TodoItemVO("clock", "red", "即将过期随访", 
                             "待开发", "去随访"));
    
    return todos;
}
```
