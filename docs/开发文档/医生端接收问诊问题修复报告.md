# 医生端接收问诊问题修复报告

## 🐛 问题描述

**现象**: 患者发起问诊后，医生端没有接收到问诊请求

**根本原因**: 
1. `PatientConsultationController.createConsultation()` 方法返回的是硬编码的模拟数据，**没有调用Service层保存到数据库**
2. `getMessages()` 和 `sendMessage()` 方法硬编码了医生ID为"DOC001"，导致无法正确获取聊天记录

---

## ✅ 修复内容

### 1. 修复问诊创建API

**文件**: `backend/src/main/java/com/drugmall/controller/PatientConsultationController.java`

**修改前** (第73-93行):
```java
@PostMapping
public Result<ConsultationVO> createConsultation(...) {
    // ❌ 只是返回模拟数据，没有保存到数据库
    ConsultationVO vo = new ConsultationVO();
    vo.setId("C" + System.currentTimeMillis());
    vo.setPatientId(CURRENT_PATIENT_ID);
    // ... 设置其他字段
    return Result.success(vo);
}
```

**修改后**:
```java
@PostMapping
public Result<ConsultationVO> createConsultation(
        @RequestParam String doctorId,
        @RequestParam(defaultValue = "text") String type,
        @RequestParam String symptom) {
    log.info("患者发起问诊: doctorId={}, type={}, symptom={}", doctorId, type, symptom);
    // ✅ 调用Service层真实方法，保存到数据库
    ConsultationVO vo = consultationService.createConsultation(CURRENT_PATIENT_ID, doctorId, type, symptom);
    return Result.success(vo);
}
```

**关键改动**:
- ✅ 调用 `consultationService.createConsultation()` 方法
- ✅ 问诊记录会真正保存到 `dm_consultation` 表
- ✅ 默认问诊类型从 `"image"` 改为 `"text"`（与Service层保持一致）

### 2. 修复聊天记录获取API

**修改前** (第86行):
```java
@GetMapping("/{id}/messages")
public Result<List<MessageVO>> getMessages(@PathVariable String id) {
    // ❌ 硬编码医生ID
    return Result.success(consultationService.getMessages("DOC001", id));
}
```

**修改后**:
```java
@GetMapping("/{id}/messages")
public Result<List<MessageVO>> getMessages(@PathVariable String id) {
    // ✅ 从问诊记录中获取真实的医生ID
    ConsultationDetailVO detail = consultationService.getConsultationDetail(CURRENT_PATIENT_ID, id);
    String doctorId = detail != null ? detail.getDoctorId() : "DOC001";
    return Result.success(consultationService.getMessages(doctorId, id));
}
```
