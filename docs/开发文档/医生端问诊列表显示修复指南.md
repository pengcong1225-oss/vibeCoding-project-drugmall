# 医生端问诊列表显示修复指南

##  问题原因

**根本原因**：后端 `ConsultationServiceImpl.convertToConsultationVO()` 方法中，患者姓名字段被硬编码为空字符串，导致前端无法显示患者信息。

```java
// 修复前
vo.setPatientName(""); // ❌ 空字符串
vo.setPatientAge(0);
vo.setPatientGender("");
```

---

## ✅ 修复内容

### 后端修改

**文件**: `backend/src/main/java/com/drugmall/service/impl/ConsultationServiceImpl.java`

#### 1. 添加PatientMapper注入

```java
@Autowired
private PatientMapper patientMapper;
```

#### 2. 修复 convertToConsultationVO 方法

```java
// 从患者表查询真实信息
if (c.getPatientId() != null) {
    try {
        Patient patient = patientMapper.selectById(c.getPatientId());
        if (patient != null) {
            vo.setPatientName(patient.getName() != null ? patient.getName() : "患者" + c.getPatientId());
            vo.setPatientAge(patient.getBirthday() != null ? 
                java.time.Period.between(patient.getBirthday(), java.time.LocalDate.now()).getYears() : 0);
            vo.setPatientGender(patient.getGender() != null ? 
                (patient.getGender() == 1 ? "男" : "女") : "未知");
        } else {
            vo.setPatientName("患者" + c.getPatientId());
            vo.setPatientAge(0);
            vo.setPatientGender("未知");
        }
    } catch (Exception e) {
        log.warn("查询患者信息失败: patientId={}", c.getPatientId(), e);
        vo.setPatientName("患者" + c.getPatientId());
        vo.setPatientAge(0);
        vo.setPatientGender("未知");
    }
}
```

## 📊 数据库验证

执行以下SQL确认患者信息：

```sql
-- 查询问诊记录及关联的患者信息
SELECT 
    c.id as consultation_id,
    c.patient_id,
    p.name as patient_name,
    p.gender,
    p.birthday,
    c.type,
    c.status,
    LEFT(c.symptom, 50) as symptom_preview,
    c.create_time
FROM dm_consultation c
LEFT JOIN dm_patient p ON c.patient_id = p.id
WHERE c.doctor_id = 'DOC001' AND c.status = 'pending'
ORDER BY c.create_time DESC;
```

**预期结果**：应该返回4条记录，每条都有患者姓名、性别等信息。

##  可能的问题排查

### 问题1：仍然看不到患者姓名

**检查**：
1. 浏览器是否强制刷新（Ctrl + F5）
2. 查看Network标签，确认API返回的patientName是否为空
3. 查看后端日志，确认是否有SQL查询患者表

### 问题2：患者信息显示"患者5"而不是真实姓名

**原因**：患者ID=5在dm_patient表中不存在或name字段为空

**解决**：
```sql
-- 检查患者表
SELECT * FROM dm_patient WHERE id = 5;

-- 如果没有记录，需要添加测试数据
INSERT INTO dm_patient (user_id, name, gender, birthday, phone)
VALUES (1, '张三', 1, '1999-01-01', '13900000001');
```

### 问题3：问诊列表完全为空

**检查**：
1. 后端日志是否有SQL错误
2. 数据库中医生的问诊记录是否存在
3. 医生ID是否匹配（DOC001）
