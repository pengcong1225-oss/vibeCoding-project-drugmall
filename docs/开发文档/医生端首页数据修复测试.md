### 5. 数据库验证

执行以下SQL查询验证数据：

```sql
-- 查询待接诊问诊数量
SELECT COUNT(*) as pending_count 
FROM dm_consultation 
WHERE doctor_id = 'DOC001' AND status = 'pending';

-- 查询所有问诊状态分布
SELECT status, COUNT(*) as count 
FROM dm_consultation 
WHERE doctor_id = 'DOC001' 
GROUP BY status;

-- 查询待审核处方数量
SELECT COUNT(*) as pending_prescription_count 
FROM dm_prescription 
WHERE doctor_id = 'DOC001' AND status = 'pending';
```
