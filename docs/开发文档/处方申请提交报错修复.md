# 处方申请提交报错 - 患者ID为null问题修复

**日期**: 2026-04-28  
**问题**: 提交处方申请时系统报错  
**状态**: ✅ 已修复（后端+前端）

---

## 🔍 问题分析

### 错误现象
用户填写完处方申请信息后，点击"提交申请"按钮，系统报错。

### 根本原因

通过排查发现，问题出在**患者ID字段为null**：

1. **后端问题**:
   - `Patient` Entity的id是 `Long` 类型
   - `PatientVO` 的id是 `String` 类型
   - `BeanUtils.copyProperties` 无法自动转换 Long → String
   - 导致返回给前端的患者数据中 `id` 字段为 `null`

2. **前端问题**:
   - 提交时执行 `parseInt(applyState.value.selectedPatient.id)`
   - `parseInt(null)` 返回 `NaN`
   - 后端校验 `@NotNull` 失败，报错

### 错误流程

```
用户提交申请
  ↓
前端: parseInt(null) → NaN
  ↓
后端: @NotNull校验失败
  ↓
报错: "患者ID不能为空"
```

---

## ✅ 修复方案

### 修复1：后端 - PatientVO的ID转换

**文件**: `backend/src/main/java/com/drugmall/service/impl/UserServiceImpl.java`

**修复前**:
```java
private PatientVO convertToPatientVO(Patient patient) {
    if (patient == null) {
        return null;
    }
    PatientVO vo = new PatientVO();
    BeanUtils.copyProperties(patient, vo);
    return vo;  //  id字段为null，因为Long无法自动转String
}
```

**修复后**:
```java
private PatientVO convertToPatientVO(Patient patient) {
    if (patient == null) {
        return null;
    }
    PatientVO vo = new PatientVO();
    BeanUtils.copyProperties(patient, vo);
    // 手动设置ID（Long转String）
    vo.setId(patient.getId() != null ? String.valueOf(patient.getId()) : null);
    return vo;  // ✅ id字段正确转换
}
```

**修改位置**: 第469-476行

##  相关技术点

### 1. BeanUtils.copyProperties的限制

`BeanUtils.copyProperties` 只能复制**类型相同**的属性。当源对象和目标对象的属性类型不同时（如 `Long` vs `String`），需要手动转换。

**解决方案**:
```java
// 先复制相同类型的属性
BeanUtils.copyProperties(patient, vo);
// 再手动转换不同类型
vo.setId(patient.getId() != null ? String.valueOf(patient.getId()) : null);
```

### 2. 类型安全的前端校验

在提交前进行数据校验，避免无效数据发送到后端：

```typescript
// 校验患者ID
if (!applyState.value.selectedPatient.id) {
  throw new Error('患者ID无效')
}

// 确保转换成功
const patientId = parseInt(applyState.value.selectedPatient.id)
if (isNaN(patientId)) {
  throw new Error('患者ID格式错误')
}
```

### 3. 前后端类型对应

| 后端 (Java) | 前端 (TypeScript) | 说明 |
|------------|------------------|------|
| Long | string | 数据库ID通常用字符串 |
| Integer | number | 数值类型 |
| Boolean | boolean | 布尔类型 |
| String | string | 字符串类型 |
