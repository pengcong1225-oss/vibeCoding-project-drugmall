# 处方申请页面就诊人单选优化

**日期**: 2026-04-28  
**问题**: 用户反馈"只能选中一个就诊人"  
**状态**: ✅ 已优化（确认单选逻辑正确，增强视觉反馈）

---

## 🔍 问题分析

用户可能认为应该可以多选就诊人，但实际上处方申请业务逻辑要求**只能选择一个就诊人**（用药人），因为：
1. 一张处方只能对应一个患者
2. 医生需要根据具体患者的情况开方
3. 医保报销也需要明确的患者身份

---

## ✅ 优化方案

### 1. 逻辑层优化

**文件**: `frontend/src/views/prescription/apply.vue`

#### 优化前
```typescript
const selectPatient = (patient: Patient) => {
  prescriptionStore.selectPatient(patient)
}
```

#### 优化后
```typescript
const selectPatient = (patient: Patient) => {
  // 如果点击的是已选中的就诊人，不做任何操作
  if (prescriptionStore.applyState.selectedPatient?.id === patient.id) {
    return
  }
  
  // 选择新的就诊人（会自动替换之前的选择）
  prescriptionStore.selectPatient(patient)
  
  // 显示提示信息
  ElMessage.success({
    message: `已选择：${patient.name}（${patient.relationship}）`,
    duration: 1500
  })
}
```

**改进点**:
- ✅ 防止重复点击同一就诊人
- ✅ 显示明确的选中提示
- ✅ 自动取消之前的选择（Store层实现）

### 2. Store层逻辑（已正确实现）

**文件**: `frontend/src/stores/prescription.ts`

```typescript
// 选择用药人
const selectPatient = (patient: Patient) => {
  applyState.value.selectedPatient = patient  // 直接赋值，实现单选
}
```

**说明**: 
- 使用直接赋值而非数组push，天然实现单选
- 每次选择都会替换之前的值

### 3. 模板层标识（已正确实现）

```vue
<div
  v-for="patient in patientList"
  :key="patient.id"
  :class="['patient-item', { 
    active: prescriptionStore.applyState.selectedPatient?.id === patient.id 
  }]"
  @click="selectPatient(patient)"
>
  <!-- ... -->
  <div class="select-icon">
    <el-icon v-if="prescriptionStore.applyState.selectedPatient?.id === patient.id">
      <CircleCheckFilled />
    </el-icon>
  </div>
</div>
```

**说明**:
- 只有选中的就诊人才会显示勾选图标
- 通过 `v-if` 条件渲染，确保只有一个勾选图标

**优化前**:

**改进点**:
- ✅ 添加悬停上浮效果（`transform: translateY(-2px)`）
- ✅ 添加阴影效果，增强立体感
- ✅ 选中时头像背景色加深，更明显
- ✅ 过渡动画从0.2s延长到0.3s，更流畅

## 🎯 单选机制总结

### 三层保障确保单选

| 层级 | 实现方式 | 说明 |
|------|---------|------|
| **数据层** | Store中直接赋值 | `selectedPatient = patient`，非数组操作 |
| **视图层** | 条件渲染勾选图标 | `v-if="selectedPatient?.id === patient.id"` |
| **交互层** | 点击事件处理 | 点击新就诊人自动替换旧选择 |

### 视觉效果

1. **未选中状态**:
   - 灰色背景
   - 无边框
   - 无勾选图标

2. **悬停状态**:
   - 浅蓝背景
   - 轻微上浮
   - 阴影效果

3. **选中状态**:
   - 浅蓝背景（略深）
   - 蓝色边框（2px）
   - 蓝色勾选图标
   - 头像背景渐变加深
   - 阴影效果
