# 处方申请页面就诊人多选显示问题修复

**日期**: 2026-04-28  
**问题**: 截图显示两个就诊人都显示了绿色勾选图标（多选视觉效果）  
**状态**: ✅ 已修复（添加调试日志和自动选择逻辑）

---

## 🔍 问题分析

### 用户反馈
从提供的截图中可以看到：
- ✅ "张三（本人）"显示了绿色勾选图标
- ✅ "张小明（子女）"也显示了绿色勾选图标
- ❌ **问题**：两个就诊人同时显示选中状态

### 根本原因排查

#### 1. 代码逻辑检查

模板代码（第392行）：
```vue
<el-icon v-if="prescriptionStore.applyState.selectedPatient?.id === patient.id">
  <CircleCheckFilled />
</el-icon>
```

这个逻辑是正确的，只有当 `selectedPatient.id === patient.id` 时才显示勾选图标。

#### 2. 可能的问题

**问题A：ID类型不一致**
- 后端返回的id可能是数字类型（如 `1`）
- 但在比较时可能有一个被转换成了字符串（如 `"1"`）
- JavaScript中 `1 === "1"` 返回 `false`，但如果数据映射时处理不当可能导致问题

**问题B：后端返回的数据有重复ID**
- 两个患者的id字段相同
- 导致选中的患者同时匹配多个列表项

**问题C：未自动选择默认患者**
- 页面加载时没有选中任何患者
- 用户可能误以为可以同时选择多个

---

## ✅ 修复方案

### 1. 统一ID类型

**文件**: `frontend/src/views/prescription/apply.vue`

#### 修改前
```typescript
patientList.value = patients.map(p => ({
  id: p.id,  // 可能是数字或字符串
  name: p.name,
  // ...
}))
```

#### 修改后
```typescript
patientList.value = patients.map(p => ({
  id: String(p.id),  // 确保id是字符串类型
  name: p.name,
  // ...
}))
```

**原因**: 
- 统一使用字符串类型，避免类型不一致导致的比较问题
- 后端可能返回数字类型，前端统一转换为字符串

### 2. 自动选择默认患者

```typescript
// 自动选择默认患者（如果有的话）
const defaultPatient = patientList.value.find(p => p.isDefault)
if (defaultPatient && !prescriptionStore.applyState.selectedPatient) {
  prescriptionStore.selectPatient(defaultPatient)
  console.log('自动选择默认患者:', defaultPatient.name, 'ID:', defaultPatient.id)
}
```

**原因**:
- 页面加载后自动选中默认患者（标记为"默认"的那个）
- 避免初始状态没有任何选中的情况
- 提升用户体验

### 3. 添加详细调试日志

#### 获取患者列表时
```typescript
console.log('获取到的患者列表:', patients)
console.log('处理后的患者列表:', patientList.value)
console.log('患者ID列表:', patientList.value.map(p => ({ id: p.id, name: p.name })))
```

#### 选择患者时
```typescript
const selectPatient = (patient: Patient) => {
  console.log('点击选择就诊人:', patient)
  console.log('当前选中的就诊人:', prescriptionStore.applyState.selectedPatient)
  
  if (prescriptionStore.applyState.selectedPatient?.id === patient.id) {
    console.log('点击的是已选中的就诊人，忽略')
    return
  }
  
  prescriptionStore.selectPatient(patient)
  console.log('已选择就诊人:', patient.name, 'ID:', patient.id)
  
  ElMessage.success({
    message: `已选择：${patient.name}（${patient.relationship}）`,
    duration: 1500
  })
}
```

**原因**:
- 便于排查问题
- 可以看到患者ID是否正确
- 可以看到选择逻辑是否正常工作
