## 🛠️ 强制修复步骤

### 步骤1：完全清除浏览器缓存

#### Chrome/Edge浏览器
1. 按 `Ctrl + Shift + Delete` 打开清除浏览数据
2. 选择"所有时间"
3. 勾选：
   - ✅ 缓存的图片和文件
   - ✅ Cookie和其他网站数据
4. 点击"清除数据"

#### 或者使用硬刷新
1. 打开处方申请页面
2. 按 `Ctrl + F5`（Windows）或 `Cmd + Shift + R`（Mac）
3. 或者按 `F12` 打开开发者工具
4. 右键点击刷新按钮，选择"清空缓存并硬性重新加载"

### 步骤2：检查前端开发服务器

确保前端开发服务器正在运行并监听了文件变化：

```bash
# 在 frontend 目录下
npm run dev
```

查看控制台输出，确保：
- ✅ 没有编译错误
- ✅ 显示"vite x.x.x ready in xxx ms"
- ✅ 显示本地访问地址（如 http://localhost:3003）

### 步骤3：验证代码是否生效

#### 3.1 打开浏览器开发者工具
按 `F12` 打开开发者工具

#### 3.2 检查Console日志

**如果没有看到这些日志** → 说明代码没有重新加载，返回步骤1

## 🔧 如果问题仍然存在

### 方案A：启用调试标记

我已经添加了一个隐藏的调试标记，可以显示每个患者的选中状态。

1. 打开文件：`frontend/src/views/prescription/apply.vue`
2. 找到第408行左右：
```vue
<!-- <span style="font-size: 10px; color: red;">{{ isPatientSelected(patient.id) ? '✓' : '×' }}</span> -->
```
3. 取消注释（删除 `<!--` 和 `-->`）：
```vue
<span style="font-size: 10px; color: red;">{{ isPatientSelected(patient.id) ? '✓' : '×' }}</span>
```
4. 保存文件
5. 刷新页面

现在每个就诊人卡片右侧会显示：
- **✓** (红色) = 选中
- **×** (红色) = 未选中

这样可以直观地看到 `isPatientSelected()` 函数的判断结果。

### 方案B：检查后端数据

可能是后端返回的患者数据有问题。

在Console中执行：
```javascript
// 获取患者列表
fetch('/v1/user/patients')
  .then(res => res.json())
  .then(data => {
    console.log('原始API响应:', data)
    console.log('患者ID:', data.map(p => p.id))
    console.log('ID是否唯一:', new Set(data.map(p => p.id)).size === data.length)
  })
```

**如果ID不唯一** → 说明后端数据有问题，需要修复后端

### 方案C：完全重建组件

如果以上都不行，可能需要完全重建选择逻辑。

## 💡 常见问题

### Q1: 为什么代码修改了但没有生效？
**A**: 浏览器缓存了旧的JavaScript文件。需要硬刷新（Ctrl + F5）或清除缓存。

### Q2: 如何确认代码真的被加载了？
**A**: 在Console中看日志。如果没有看到我们添加的日志，说明代码没有被重新加载。

### Q3: 为什么两个都显示绿色边框？
**A**: 可能的原因：
1. 浏览器缓存了旧代码
2. CSS样式有问题（但我们已检查过，样式是正确的）
3. `isPatientSelected()` 函数返回了错误的值

### Q4: 如何临时调试？
**A**: 启用调试标记（方案A），可以看到每个患者的选中状态（✓ 或 ×）。
