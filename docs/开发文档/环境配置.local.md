# DrugMall 本地环境配置

## 测试环境数据库配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| host | localhost | 数据库主机 |
| port | 3306 | 数据库端口 |
| username | root | 数据库用户名 |
| password | qwer1234 | 数据库密码 |

## 使用方式

在 `application-local.yml` 中引用：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/drugmall_dev?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: qwer1234
```
