```sql
CREATE TABLE `dm_product_specification` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '规格ID',
  `product_id` BIGINT NOT NULL COMMENT '药品ID',
  `spec_name` VARCHAR(100) NOT NULL COMMENT '规格名称',
  `spec_code` VARCHAR(50) DEFAULT NULL COMMENT '规格编码',
  `price` DECIMAL(10,2) NOT NULL COMMENT '售价',
  `original_price` DECIMAL(10,2) DEFAULT NULL COMMENT '原价',
  `stock` INT NOT NULL DEFAULT 0 COMMENT '库存',
  `bar_code` VARCHAR(50) DEFAULT NULL COMMENT '条形码',
  `is_default` TINYINT DEFAULT 0 COMMENT '是否默认规格 0-否 1-是',
  `sort_order` INT DEFAULT 0 COMMENT '排序',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态 0-禁用 1-启用',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_product_id` (`product_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='药品规格表';
```

#### 2.5 Service层实现

在`DrugServiceImpl.java`中：

1. 注入`ProductSpecificationMapper`
2. 在`getDrugDetail`方法中查询规格列表
3. 在`convertToDrugVO`方法中添加医保字段映射

```java
@Autowired
private ProductSpecificationMapper specificationMapper;

// 在getDrugDetail中
List<ProductSpecification> specs = specificationMapper.selectList(
    new LambdaQueryWrapper<ProductSpecification>()
        .eq(ProductSpecification::getProductId, productId)
        .eq(ProductSpecification::getStatus, 1)
        .orderByAsc(ProductSpecification::getSortOrder)
);
detail.setSpecifications(specs.stream()
    .map(this::convertToSpecVO)
    .collect(Collectors.toList()));

// 转换方法
private DrugSpecificationVO convertToSpecVO(ProductSpecification spec) {
    DrugSpecificationVO vo = new DrugSpecificationVO();
    vo.setId(spec.getId());
    vo.setSpecName(spec.getSpecName());
    vo.setSpecCode(spec.getSpecCode());
    vo.setPrice(spec.getPrice());
    vo.setOriginalPrice(spec.getOriginalPrice());
    vo.setStock(spec.getStock());
    vo.setBarCode(spec.getBarCode());
    vo.setIsDefault(spec.getIsDefault());
    return vo;
}
```

## 🔄 数据流程

```
药品详情页加载
  ↓
调用 API: GET /v1/drugs/{id}
  ↓
后端 DrugController.getDrugDetail()
  ↓
DrugService.getDrugDetail()
  ↓
查询 dm_product 表（包含医保字段）
  ↓
查询 dm_product_specification 表（规格列表）
  ↓
返回 DrugDetailVO {
  drug: DrugVO {
    medicalInsuranceCode,
    isLongPrescription,
    insuranceCategory,
    specifications: [...]
  },
  ...
}
  ↓
前端接收数据
  ↓
渲染医保信息（如有）
  ↓
渲染规格列表（支持切换）
  ↓
用户点击规格 → 更新选中状态
  ↓
价格、库存等信息同步更新
```
