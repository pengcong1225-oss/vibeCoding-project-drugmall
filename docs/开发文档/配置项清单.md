## 7. MCP工具推荐

### 7.1 什么是MCP

MCP（Model Context Protocol）是Anthropic推出的开放协议，用于标准化AI模型与外部工具、数据源之间的集成。通过MCP，AI助手可以安全地访问本地文件、数据库、API等资源。

### 7.2 推荐的MCP工具

#### 文件系统访问

| 工具 | 用途 | 安装 |
|------|------|------|
| filesystem | 安全的文件读写 | `npm install -g @modelcontextprotocol/server-filesystem` |

#### 数据库访问

| 工具 | 用途 | 安装 |
|------|------|------|
| sqlite | SQLite数据库操作 | `npm install -g @modelcontextprotocol/server-sqlite` |
| postgresql | PostgreSQL数据库操作 | `npm install -g @modelcontextprotocol/server-postgres` |

#### 开发工具

| 工具 | 用途 | 安装 |
|------|------|------|
| git | Git操作 | `npm install -g @modelcontextprotocol/server-git` |
| github | GitHub API访问 | `npm install -g @modelcontextprotocol/server-github` |
| fetch | HTTP请求 | `npm install -g @modelcontextprotocol/server-fetch` |

#### 办公工具

| 工具 | 用途 | 安装 |
|------|------|------|
| puppeteer | 网页自动化 | `npm install -g @modelcontextprotocol/server-puppeteer` |
| brave-search | 网络搜索 | `npm install -g @modelcontextprotocol/server-brave-search` |
