## 3. 配置管理策略

### 3.1 配置分层架构

```
配置管理体系
│
├── 基础设施层（Infrastructure）
│   ├── Docker Compose配置
│   ├── Kubernetes YAML
│   ├── Nginx配置
│   └── 网络策略
│
├── 应用配置层（Application）
│   ├── Spring Boot YAML
│   ├── Vue 环境变量
│   ├── 日志配置
│   └── 缓存策略
│
├── 业务配置层（Business）
│   ├── 字典数据
│   ├── 流程配置
│   ├── 规则引擎
│   └── 模板管理
│
└── 安全配置层（Security）
    ├── 密钥管理
    ├── 证书配置
    ├── 访问控制
    └── 审计日志
```

### 3.2 配置中心选型（零成本）

| 工具 | 类型 | 许可证 | 适用场景 | 推荐指数 |
|------|------|--------|----------|----------|
| **Spring Cloud Config** | 配置中心 | Apache-2.0 | Spring生态，Git后端 | ⭐⭐⭐⭐⭐ |
| **Apollo** | 配置中心 | Apache-2.0 | 携程开源，功能丰富 | ⭐⭐⭐⭐⭐ |
| **Nacos** | 配置+服务 | Apache-2.0 | 阿里开源，云原生 | ⭐⭐⭐⭐⭐ |
| **Consul** | 配置+服务 | MPL-2.0 | HashiCorp，多语言 | ⭐⭐⭐⭐ |
| **etcd** | 键值存储 | Apache-2.0 | K8s原生，高可用 | ⭐⭐⭐⭐ |

**推荐方案**：使用 **Nacos** 作为统一配置中心
- 支持动态配置推送
- 内置服务注册发现
- 友好的Web控制台
- 完善的权限控制

```bash
#!/bin/bash
# vault-init.sh - Vault初始化脚本

# 启动Vault
docker run -d \
  --name vault \
  --cap-add=IPC_LOCK \
  -p 8200:8200 \
  -v $(pwd)/vault/data:/vault/data \
  -v $(pwd)/vault/config:/vault/config \
  hashicorp/vault:1.15

# 等待Vault启动
sleep 5

# 导出环境变量
export VAULT_ADDR='http://127.0.0.1:8200'

# 初始化Vault（仅首次）
vault operator init -key-shares=5 -key-threshold=3 > vault-keys.txt

# 提取根令牌和解除封印密钥
ROOT_TOKEN=$(grep "Initial Root Token" vault-keys.txt | awk '{print $4}')
UNSEAL_KEY_1=$(grep "Unseal Key 1" vault-keys.txt | awk '{print $4}')
UNSEAL_KEY_2=$(grep "Unseal Key 2" vault-keys.txt | awk '{print $4}')
UNSEAL_KEY_3=$(grep "Unseal Key 3" vault-keys.txt | awk '{print $4}')

echo "Vault初始化完成！"
echo "Root Token: $ROOT_TOKEN"
echo "请妥善保管 vault-keys.txt 文件"
```
