# DrugMall 患者端 UI 设计规范 V2.0

## 概述

本文档为 DrugMall 患者端（用户端）的完整 UI 设计规范，基于淡蓝色主题风格（#3B8CFF, #5CA1FF），定义了设计系统、页面规范、组件规范和交互规范。

**文档版本**: V2.0  
**更新日期**: 2024-12-08  
**适用平台**: 移动端 H5 / 微信小程序 / App  

---

## 1. 设计系统

### 1.1 色彩系统

#### 1.1.1 主色调

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 主色 | `#3B8CFF` | 主要按钮、强调元素、选中状态 |
| 主色-浅 | `#5CA1FF` | 渐变、hover状态、辅助元素 |
| 主色-更浅 | `#8CBCFF` | 背景、禁用状态 |
| 主色渐变 | `linear-gradient(135deg, #5CA1FF 0%, #3B8CFF 100%)` | 头部背景、重要按钮 |

#### 1.1.2 功能色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 成功/绿色 | `#00C9A7` | 成功提示、在线状态、送达时间 |
| 警告/橙色 | `#FF9500` | 警告提示、限时标签 |
| 错误/红色 | `#FF4D4F` | 错误提示、价格、删除操作 |
| 信息/蓝色 | `#1890FF` | 信息提示、链接 |

#### 1.1.3 中性色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| 文字-主要 | `#333333` | 标题、重要文字 |
| 文字-次要 | `#666666` | 正文、描述文字 |
| 文字-辅助 | `#999999` | 提示、说明文字 |
| 文字-禁用 | `#CCCCCC` | 禁用状态文字 |
| 文字-白色 | `#FFFFFF` | 深色背景上的文字 |
| 背景-页面 | `#F5F7FA` | 页面背景 |
| 背景-卡片 | `#FFFFFF` | 卡片背景 |
| 背景-灰色 | `#F8F9FA` | 输入框背景、分隔区域 |
| 边框-浅色 | `#EEEEEE` | 分割线、边框 |
| 边框-中等 | `#E8E8E8` | 输入框边框 |

#### 1.1.4 主题色使用示例

```scss
// SCSS 变量定义
$primary-blue: #3B8CFF;
$primary-blue-light: #5CA1FF;
$accent-green: #00C9A7;
$price-red: #FF4D4F;
$tag-orange: #FF7A45;
$text-primary: #333333;
$text-secondary: #666666;
$text-tertiary: #999999;
$bg-gray: #F5F7FA;
$border-color: #EEEEEE;

// 渐变使用
.header-gradient {
  background: linear-gradient(180deg, $primary-blue-light 0%, $primary-blue 100%);
}

.btn-gradient {
  background: linear-gradient(135deg, $primary-blue 0%, $primary-blue-light 100%);
}
```
